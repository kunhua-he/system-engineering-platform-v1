# 制品产物 —— 可装载整包的落点

`构建装配/制品产物/<制品标识>/`。**生成物，禁手改**：要改就改源
（`构建装配/上线切换/构建制品.py`）再重出。形状与判据全文见 `构建装配/上线切换/形状.md` §一。

## 制品标识

`<提交哈希 12 位>-<构建指纹 16 位>`。

构建指纹 = `sha256(规范文本)[:16]`，规范文本 = profile + 变体 + 工具链 + 扩展根声明指纹 +
装配器指纹 + 逐行「相对路径 `sha256(内容)`」（按路径排序）
⇒ **不含时间、不含绝对路径、不含机器名**：同一份源在两台机器上产出同一个标识。

## 一份制品里有什么

| 件 | 是什么 |
|---|---|
| `制品清单.json` | 身份与内容：制品标识 · 提交哈希 · 工作区脏 · 构建指纹与算法 · 工具链 · profile · 流量端口与来源 · 启动入口与启动命令 |
| `网关` | 底座网关可执行件（`启动入口`，清单里的 `启动命令` 指着它） |
| `扩展根声明.json` | 本次装配用的扩展根声明（快照 —— 制品要自洽，不能依赖出制品那一刻的仓状态） |
| `扩展/<扩展根>/<扩展>/…` | 扩展本体的**装配副本**（可装载库）。扩展本体在扩展根里、各自成仓，这里只是副本 |

## 不可变

目标目录已存在即**拒绝重建**（不是覆盖）。要重出请换变体名，或先**显式**删掉那一份 ——
删是显式动作，装配器不替你做这个决定。

## 与「当前 / 已装载」的分工

流量指向（`当前.json`）与已装载清单（`已装载/<标识>.json`）**不在本目录**：它们落在
**运行数据根**（机器相关的运行状态，判据 ⑳）。本目录是**产出**，那份是**运行状态**
⇒ 删掉本目录里的某一份，指向它的「当前」指针就悬空了（指针本身不会跟着变）。

## 本件为什么入库

本目录整体被 `.gitignore` 忽略（二进制与可重生成件不入库），**本文件是那条例外的唯一对象** ——
它是**散文**，不是产物。散文不许住在「会被 `git clean -xdf` 清掉」的目录里。
