## 六、认领流程

### 认领任务
1. 打开对应任务书（`01_*.md` ~ `07_*.md`）
2. 在任务书末尾标注：
   ```
   **任务状态**：已认领  
   **agent名**：<你的名字>  
   **开始时间**：<YYYY-MM-DD HH:MM>
   ```
3. 开始工作

### 完成任务
1. 提交产物（文件放到指定位置）
2. 在任务书末尾标注：
   ```
   **完成时间**：<YYYY-MM-DD HH:MM>  
   **实际耗时**：<X小时>  
   **验收状态**：通过/待修正
   ```
3. 通知依赖你的小队

### 任务协调
- 有依赖关系的任务，上游完成后通知下游
- 遇到阻塞问题，及时在任务书里标注
