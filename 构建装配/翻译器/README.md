# 老项目翻译器

将老项目（系统工程平台/）自动翻译成V1契约声明，接入扩展装载机制。

---

## 一、快速开始

### 查看任务书
```bash
cd 构建装配/翻译器/任务书
cat README.md
```

### 认领任务
打开对应任务书（`01_*.md` ~ `07_*.md`），按流程认领。

## 四、使用说明

### 翻译单个模块
```bash
python3 构建装配/翻译器/老项目模块翻译.py --模块 <模块名>
```

### 批量接入
```bash
bash 构建装配/翻译器/批量接入.sh
```

### 验证翻译结果
```bash
# 契约验证
python3 测试验证/契约一致性/扫实现.py

# 门禁验证
python3 构建装配/一键验证/闸0.py
```

## 五、关键设计

### 号段分配
- 能力号命名空间全宽 `[0,9999]`（`契约声明/号段图.json`）—— **不存在 10000+ 区段**
- 老项目单元落进号段图既有各段（模块 7000–7999 · 技能 8000–8999 · 核心支持库 1000–1999 · 三方封装 2000–6999 …）
- 逐单元对应关系只住工具面：`号段分配表.json` 的 `模块映射`（149 条）
- ★ 每段须逐段核判据 ㊻（底座代码里的字面数字占号）

### 命名修复
- 确定性映射：机械替换（一条→某条记录）
- 上下文映射：根据上下文选择候选（结果→编目结果/查询结果）

### 依赖处理
- 按依赖层级顺序接入（0层→1层→2层→...）
- 循环依赖需人工打破
