# 系统工程平台V1接入索引

先读项目根`AGENTS.md`的「先读短路线」，再按任务取权威正文；不要先通读全部历史参考。

- 协作与验证时点：`v1_context`，`操作=取条款`，`参数={"文档路径序号表":[{"文档路径":"项目文档/开发规范/开发规范.md","序号":10}]}`。
- 续做：`v1_task`的`取检查点`；待办：`v1_context`的`取未完成`；不重开已存在任务。
- 扩展实现：`扩展装载/开发标准/接入导航.md`，再读目标包声明与用法；语言选择查`README.md`§四。
- 工具：项目`.mcp.json`及当前`tools/list`；每个工具空`操作`取最短例，调用形状只用`开工ID/操作/参数`，不从旧文抄接口。
- 写盘：`v1_edit`；生成物：原生成器经`v1_task`记账；规则源：正式命令在施工树修改后记账。整批齐备再统一验证与收口。
- 失败时先读实际错误、按符号定位；只在相关故障出现时加载本技能`references/`中的对应专题，不把故障案例当日常施工步骤。

本技能只管路由；规范只住项目权威源，不保留另一套时限、版本、推送、代理模型或逐项全验规则。
