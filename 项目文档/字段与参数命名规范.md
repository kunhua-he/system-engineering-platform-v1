# 字段与参数命名规范

这份文件管「名字怎么取、参数怎么定义」：组件声明字段、4929 操作名、操作参数、查询参数、状态回传字段、事件字段，全部适用。
管「传什么、传几个」的是《组件传参与预设约定》，两份不重叠；冲突时命名以本文为准。

盘面数据：全库现有声明字段 144 个（19 个组件）、组件操作侧参数 36 个。本文的规矩照这份真实盘面定，不是凭空写的。

---

## 一、十条硬规矩

1. **全中文**。只用汉字（可带数字），禁英文、拼音、缩写。`__` 开头的双下划线前缀只留给底座内部状态（`__选中`、`__检查状态`、`__排序键`），业务不许写。
2. **一概念一名**。同一个概念全库只能有一种写法；出现第二种写法就是缺陷，不是「别名」。唯一例外是第八节列的易语言官方兼容写法。
3. **词性分工**。声明字段是名词（`列宽`、`条目行高`）；操作是动宾（`设置列宽`、`插入行`）；查询是 `取` + 名词（`取列宽`）。
4. **尺寸不带单位**。像素值一律只写数字，不写 `px`、不写 `像素`；百分比与表达式写字符串原样透传（`"100%"`、`"calc(100% - 120px)"`）。
5. **逻辑只认真/假**。字段名表达开关时按第四节选前缀，不许一个开关叫「可X」另一个叫「允许X」。
6. **定位一律 X序号**。行列定位统一 `行序号`、`列序号`，从 0 开始。`位置` 是另一个概念（插入点/起点），不许拿来当序号用，也不许反过来。
7. **枚举一律带尾巴**。取值范围是固定枚举的字段，名字必须是 `X方式`、`X模式`、`X类型` 三者之一。禁裸用 `种类`、`样式`、`方式`、`类型` 当枚举字段名。
8. **图片只有三种写法**。单张 `图片`，成组 `图片组`，特定用途前缀加在前面（`状态图片组`、`表头图片组`）。禁 `图形`、`图像`。
9. **正文一律叫文本**。用户可见正文用 `文本`（`结束编辑文本`、`占位文本`）。`文字` 只作修饰语（`表头文字颜色`）；`内容` 只给复合块（聊天流 `内容`）；`标题` 只指标题位置。
10. **兼容只做映射**。易语言官方名已对齐的字段保留原名（`报表列`、`单一选择`、`整行选择`、`是否有检查框`、`现行选中项`、`始终显示选择项`、`允许编辑`），内部映射到规范字段；兼容名只能映射，不许各自维护一份状态。

## 二、参数定义方式（照易语言的做法抄）

易语言的支持库里，每个参数都是独立一条，固定说三件事：名字、用途一句话、**省略时用什么值**。缺省值按类型定死，随手写是不允许的。原包 `iext.fne` 里这类「如果本参数被省略，默认值为 X」的说明有 30 处，缺省值清一色是这五种：

- 整数 → `0`
- 索引 → `-1`（表示无、不指定、或插到尾部）
- 逻辑 → `假`
- 文本 → `空文本`
- 枚举 → `#第一个常量`（`#左对齐`、`#普通按钮`、`#凹入`）

它的句子也有固定套路：

- 设置类：「设置指定表项或子项的标题…如果本参数被省略，默认值为空文本」
- 取类：「返回指定列的对齐方式…如指定列不存在，返回 0」
- 参数用途：「本参数指定报表列的宽度，单位为像素。如果本参数被省略，默认值为 50」
- 特殊值：「指定新表项插入时的位置索引…如果提供 -1，则插入到列表框的尾部」

### 2.1 参数卡四件套（照抄这套结构）

我们每个参数必须写全四项，缺一项不算定义：

1. **名字**
2. **类型**：文本 / 数值 / 逻辑 / 数组 / 对象
3. **缺省**：省略时取什么；没有默认就写「必填」
4. **取值范围或特殊值含义**：含 `-1`、`0` 这类哨兵值代表什么

不合格的写法（现在文档里就有）：`取标题`：`行序号,列序号=0`。名字有了，类型没写、范围没写、`列序号` 省略时为什么是 0 也没说。

合格的写法：

- `行序号` · 数值 · 必填 · 0 至行数减 1；不存在的行报 4921
- `列序号` · 数值 · 缺省 0 · 0 至列数减 1；省略时取第 0 列
- `文本` · 文本 · 缺省空文本 · 任意文本，按 HTML 转义写入；空串等于清空
- `批准` · 逻辑 · 缺省真 · 真 = 采用本次改动；假 = 放弃并保留候选文本
- `位置` · 数值 · 缺省 -1 · -1 表示追加到尾部；0 至行数为合法插入点，越界报 4921

### 2.2 缺省值对照表（类型定死，不许自由发挥）

- 数值：缺省 `0`；若是定位序号，则「必填」或「-1 = 不指定」
- 文本：缺省空文本
- 逻辑：缺省 `真` 或 `假`，必须写明是哪一个
- 数组：缺省空数组
- 对象：缺省不写（继承缺省外观）
- 枚举：缺省写枚举里的第一个值，并标明取值全集

### 2.3 特殊值规矩

- `-1` 只用在查询返回值上（未命中返回 -1），**不用来表示"追加到尾部"**。尾部由「不写」表达：`位置` 省略就是追加到尾部。理由：不写 = 继承缺省，已经是底座通行规则，再让 `-1` 也表达一次，同一个意思就有两条路。
- 唯一允许的负数参数值是 `列序号: -1`（`查找表项` 表示查全部列），照抄易语言，写进参数卡，别处不许再出现负数。
- 不引入 `-2`、`-3` 这类魔法值。易语言用 `-2` 表示「按列标题宽度自动」，我们改成文本值 `自适应`，一眼能懂、也不占数值域。
- 空串与不写要区分：**空串 = 清空；不写 = 不动**（继承上一次或继承缺省）。

### 2.4 参数顺序

定位在前、值在中、标志在后，与易语言一致：

- `行序号` → `列序号` → `文本` → `批准`
- `行序号` → `图片` → `状态图片` → `缩进` → `检查状态`

新增参数只能往尾部加，不许插进已有位置中间（插进去会让位置调用全线错位）。

### 2.5 撞车规矩（易语言名被占用时）

同一个名字在别处已被占用，就加主体限定，不许抢、也不许另造近义词。真实案例：

- 易语言树型框的行高属性叫 `行高`，但 `行高` 在我们这里已经是通用文字外观的**行距倍数**（0.8–3.0）。表格行高再叫 `行高`，声明 `"行高":48` 会被外观校验判成越界报 4922。所以表格这一层叫 `条目行高`，操作参数仍叫 `行高`（操作参数与声明字段不在同一个命名空间）。

判断顺序：先查《组件参数总表》有没有同名 → 有就加主体（`条目行高`、`表头文字颜色`）→ 主体也撞再换后缀（`行高` → `条目行高`）。

### 2.6 易语言词与我们词的映射（已按此表改名，一对一）

- 表项索引 → `表项索引`（我们原来叫 行序号，已改）
- 列索引 → `列索引`（原来叫 列序号，已改）
- 图片索引 → `图片索引`（原来叫 图片，已改）
- 表项数值 → `表项数值`（原来叫 数值，已改）
- 缩进数目 → `缩进数目`（原来叫 缩进，已改）
- 插入位置 → `插入位置`（原来叫 位置，已改）
- 起始位置 → `起始位置`（本来一致）
- 标题 → `标题`（原来叫 文本，已改）
- 是否精确匹配 → `是否精确匹配`（原来叫 精确匹配，已改）
- 对齐方式 → `对齐方式`（原来叫 列对齐，已改）
- 检查框状态 → `检查框状态`（原来叫 检查状态，已改）
- 提示文本 → `提示文本`（原来叫 提示，已改）
- 图片居右 → `图片居右`（原来叫 居右，已改）

取向：**易语言有的，一律用它的名字**；我们重构出来的（`行数据`、`批准`、`排列方式`、`事件名`、`目标位置`）按同一构词规则造，带主体、带后缀，不裸用单字。

## 三、后缀与组合规矩

名字由「主体 + 后缀」组成，后缀从下表里挑，不自造：

- 颜色 → `X颜色`，主体在前：`表头文字颜色`、`单元格文字颜色`、`行悬停背景`、`选中描边`
- 度量 → `X字号`、`X字重`、`X圆角`、`X间距`、`X直径`、`X行高`：`项字号`、`气泡圆角`、`图标间距`
- 成组外观 → `X外观`，值是对象：`表格外观`、`气泡外观`、`菜单外观`
- 序号 → `X序号`：`行序号`、`列序号`
- 数量 → `X数`：`列数`、`选中数`、`每页行数`
- 标识 → `X标识`：`页面标识`、`标识`
- 地址 → `X地址`：`提交地址`、`打开地址`

禁用组合：「宽度」「高度」写 `宽`、`高`（尺寸类一律单字）；不写「的颜色」「的大小」这类口语句式。

## 四、前缀表（开关与状态）

1. **能力开关 → `可X`**：`可排序`、`可关闭`、`可移动`、`可最小化`、`可最大化`、`可选中`、`可拖排序`。新增开关一律用 `可X`，不用 `允许X`、不用 `能X`、不用 `是否X`。
2. **状态查询 → `是否X`**：`是否有检查框`。只用于「这是不是某种状态」，且是易语言官方叫法时保留。
3. **自动行为 → `自动X`**：`自动排列图标`、`自动填充`。
4. **禁止的开关前缀**：`使能`、`启用`、`开关`、`is`、`enable`。

---

## 五、操作与事件命名

- 设置：`设置X`。`置X` 只作易语言兼容别名，与 `设置X` 同语义同实现，别名表维护，不新增第二份代码。
- 查询：`取X`（`取列宽`、`取表项数值`）。查询结果统一进 4930 的 `查询结果`，不开第二返回协议。
- 动作：`插入X`、`追加X`、`删除X`、`移动X`、`清空X`、`切换X`。动作必须带宾语，禁裸动词。
- 事件：`X被Y`（`表头被单击`）或 `X改变`（`当前表项被改变`、`检查框状态被改变`）。
- 返回：查询类未命中按类型给固定值（数值 -1 或 0、文本空文本、数组空数组），不返 null 冒充。

## 六、取名四步

1. **先查有没有**：在《组件参数总表》全文搜概念词，已有就复用，不改名、不造同义词。
2. **定词性**：字段名词、操作动宾、查询取+名词。
3. **套后缀**：从第三节的表里挑，挑不到说明这个概念是新的，先加进表再用。
4. **写参数卡**：按第二节四件套写全名字、类型、缺省、范围。
5. **过检查**：按第七节跑一遍，命中禁用词就重取。

## 七、机器检查规则

以下规则可写成检查脚本，进编译器闸门；命中即报，不许静默放过。

- 字段名必须匹配 `^[\u4e00-\u9fff][\u4e00-\u9fff0-9]*$`（`__` 前缀除外），长度 2–8 个汉字。
- 禁用字段名全集（整名比对）：`种类`、`样式`、`方式`、`图形`、`图像`、`data`、`value`、`type`、`size`、`style`。
- 禁用定位名：`索引`、`键`、`项`、`第几个`（`位置` 合法，但只表示插入点/起点）。
- 禁用开关前缀（前缀比对）：`是否`（除 `是否有检查框`）、`启用`、`使能`、`开关`。
- 枚举字段的值域必须写在《组件参数总表》里；值域出现英文（`primary`、`danger`）即报。
- 参数卡完整性：每个操作参数必须能在《表格方法参数卡》里查到四件套，查不到即报。
- 同义组互斥：`文字/文本/内容`、`图标/图形/图片`、`行/项/条目/表项`、`方式/模式/种类/样式` 四组里，同一组件内只用一种写法。

### 保留例外（不是违规，写在这里防止以后被误改）

- `位置` / `起始位置`：表示插入点与查找起点，和「索引」不是同一概念，照易语言原样保留（通用移动操作的 `位置` 同理）。
- `类型`：组件类型标识，是结构字段不是枚举字段。
- `宽 / 高`：文档里合写的说法，实际字段就是 `宽`、`高`。
- `允许编辑`：易语言官方名，保留。
- 属性名直当操作名机制（`{"值": …}`）：属性赋值通道，`值` 是属性值的占位名，属通用机制。
- `__` 前缀字段：底座内部状态，业务不许写、也不许改名。

## 九、改名纪律

- 改名一次性收敛：改字段、改调用方、改文档、改预设在同一批完成，**不留新旧两套、不留映射继承层**（易语言官方兼容写法除外）。
- 改名必须同步四处：源码、`组件参数总表.md`、`用法说明`、验收证据里的调用样例。
- 改名后跑：单测全绿 + 平台落库 + 扩展指纹 + 候选口真实 HTTP 抽验，缺一项不算完成。
