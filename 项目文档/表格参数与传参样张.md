# 表格（对齐易语言超级列表框）· 参数与传参设计

这一份是超级列表框对齐样张：先看传参和完整原子能力，再看 Web 与官方成员如何映射。
所有已经写入“已实现”的字段与操作都按当前源码真实读取与状态回传记录；官方 Windows 特有能力若在 Web 端采用等价表达，明确写出等价落点。

---

## 一、先给结论

- 当前表格已纳入完整超级列表框映射：**声明属性、行/列操作、查询、选择、编辑、事件和状态回传**均走现有 4928–4931 四个能力号。
- 官方成员共 **75 个**（31 个属性、35 个方法、9 个事件）；其中窗口通用属性由通用组件承接，Windows 图标视图/热点/编辑等能力用同一表格组件的 Web 字段与句柄操作表达。
- 这不是把 75 个名字机械复制成 75 个能力号：同一语义只保留一个底座入口，调用方通过操作名和参数选择原子动作。
- 现在最简写法只要 **4 个字段**就能出一张可排序、可翻页、吸顶表头的表格。

## 二、现在能传的参数（代码真实读取）

### 必填两项

- `列` · 数组 · 作用：表头，按顺序一列一个名字 · 取值：字符串数组 · 缺了就报 `4922 内容不合法`
- `行` · 数组 · 作用：数据行 · 取值：每行是数组，单元格按 `列` 的顺序对应；空值写 `null`（排序时排最后）

### 行为字段（不写就用默认）

- `可排序` · 逻辑 · 默认 `假` · 真时每个表头显式显示 ▲ 升序与 ▼ 降序按钮，点击指定方向后交回底座重算
- `每页行数` · 数值 · 默认 `0`（不分页）· 取值 0 至 500；大于 0 时出翻页条
- `表头固定` · 逻辑 · 默认 `假` · 真时表头吸顶
- `最大高度` · 数值 · 默认无 · 取值 80 至 4000 · **仅当 `表头固定` 为真时必须给**，否则报内容不合法
- `斑马纹` · 逻辑 · 默认 `假` · 真时隔行底色
- `斑马纹色` · 颜色 · 默认走 CSS 变量 · 例 `#f7f9fc`

### 外观字段（一个对象，里面 7 个键）

- `表头背景` · 颜色
- `表头文字颜色` · 颜色
- `单元格文字颜色` · 颜色
- `边框颜色` · 颜色
- `行悬停背景` · 颜色
- `字号` · 数值（像素，1 至 200）
- `单元格内边距` · 数值或间距段

外观走 CSS 变量，不写在每个单元格上——一张表 200 行也不会把样式撑爆。

### 内部状态（V4 不要写）

`__排序键` / `__升序` / `__页码` / `__组件句柄`
这四个由底座写、底座读。V4 想改排序或翻页，调 `4929`，不要直接塞这四个键。

## 三、传参长什么样（三档）

### 第一档：最简（推荐，4 个字段）

```json
{
  "类型": "表格",
  "预设": "数据表",
  "列": ["名称", "大小字节", "类型"],
  "行": [
    ["合同.pdf", 20480, "文档"],
    ["图片.png", 105819424, "图片"],
    ["说明.txt", 1024, "文档"]
  ]
}
```

`预设：数据表` 内置了：可排序、每页 20 行、表头固定、最大高度 480、斑马纹。
所以要变的只有「列」和「行」这两件真正属于业务的事。

### 第二档：常用（不用预设，5 到 6 个字段）

```json
{
  "类型": "表格",
  "列": ["名称", "大小字节"],
  "行": [["合同.pdf", 20480], ["图片.png", 105819424]],
  "可排序": true,
  "每页行数": 20,
  "表头固定": true,
  "最大高度": 480
}
```

### 第三档：带外观

```json
{
  "类型": "表格",
  "列": ["名称", "大小字节"],
  "行": [["合同.pdf", 20480]],
  "可排序": true,
  "斑马纹": true,
  "斑马纹色": "#f7f9fc",
  "表格外观": {
    "表头背景": "#f5f7fa",
    "表头文字颜色": "#606266",
    "字号": 13,
    "单元格内边距": "10px 12px"
  }
}
```

### 页面里跟别的组件一起摆

```json
{
  "页面标识": "文件管理",
  "根": {
    "类型": "列",
    "子": [
      {"类型": "行", "子": [
        {"类型": "按钮", "预设": "主按钮", "文字": "刷新"},
        {"类型": "输入", "预设": "搜索框", "名称": "关键词"}
      ]},
      {"类型": "表格", "预设": "数据表", "列": ["名称", "大小"], "行": []}
    ]
  }
}
```

## 四、流程图

### 4.1 从声明到出界面

```text
V4 写页面声明（JSON）
   │  类型 / 预设 / 列 / 行
   ▼
4928 渲染组件树
   │
   ├─ ① 取预设 ──→ 预设表铺底，节点字段压上去（同名以节点为准）
   │
   ├─ ② 校验外观 ──→ 颜色、字号、宽高越界直接拒（不 clamp）
   │
   ├─ ③ 签组件句柄 ──→ 每个节点一个 data-hs-h，起点 100000
   │
   ├─ ④ 排一次序 ──→ 有 __排序键 就按它排（数按数比、文按文比，空值垫后）
   │
   ├─ ⑤ 切当前页 ──→ 按 每页行数 切，算出总页数
   │
   └─ ⑥ 出片段 ──→ <table> + 表头操作属性 + 翻页条 + 引导脚本
          │
          ▼
       V4 把片段贴进页面（浏览器只搬运，不算数）
```

### 4.2 点表头方向按钮排序（走句柄，不重载整页）

```text
用户点「名称」列头的 ▲ 或 ▼ 方向按钮的 ▲
   │
   ▼
浏览器引导脚本：找最近的 data-hs-h → 拿到句柄 100000
   │  交回 {句柄, 操作:"排序", 参数:{键:"名称",升序:true}}
   ▼
V4 /组件操作  ← 只转发，不加逻辑
   │
   ▼
4929 操作组件 · 排序
   │
   ├─ 取该句柄的节点副本（组件实例登记表）
   ├─ 记 __排序键、按按钮写 __升序、页码回 1
   ├─ 重渲染这一个节点（不碰别的组件）
   └─ 回 {片段, 句柄组}
          │
          ▼
   浏览器：把这一段片段外层替换回原位（整页不刷新）
```

### 4.3 翻页

```text
点「下一页」
   │  交回 {句柄, 操作:"翻页", 参数:{页码:2}}
   ▼
4929 · 翻页 → 改 __页码 → 重渲染该表 → 回片段 → 原位替换
```

### 4.4 句柄的一生

```text
渲染 ──→ 签发句柄（登记节点副本 + 归属）
   │
   ├─ 操作（改副本）──→ 同步给父容器（否则父容器照旧画旧的）
   │
   └─ 释放 4931 ──→ 从登记表摘掉
                        │
                        └─ 再操作同一句柄 → 4924 组件句柄无效
```

## 五、超级列表框原子能力边界

对照官方帮助的 31 项专有属性、35 个方法、9 个自有事件，统一落在 `类型:"表格"` 内。另有 8 项通用属性，不重复造控件。不新增能力号：4928 渲染、4929 操作、4930 状态、4931 释放。

这是 Web 等价接口，不是 Windows 二进制接口复制：图片传同源 URL 或 null，不传操作系统图片句柄；列对齐用 `左/中/右`；列宽用像素或 `自适应`；事件回到状态，不直接执行业务回调。查询和插入索引均从 4930 的 `查询结果` 读，不改变统一片段返回协议。

```text
业务声明／操作参数
  → 4928／4929
    → 实例边界统一字段与初始选择
    → 底座计算排序、分页、行列及图片坐标
    → 返回组件片段
      → 公共脚本原位替换、聚焦、滚动
事件 → 同一 4929 → 事件状态 → 4930 读取
释放 → 4931 → 再调用报 4924
```

## 六、完整字段和方法

### 6.1 属性映射

- 数据：`报表列/表项` 对应 `列/行`，在实例入口统一，后续查询与修改均读同一份数据。
- 视图：`视图模式` 取 `报表/列表/小图标/大图标`；不把官方的列表类型与组件的 `类型:"表格"` 混用。
- 图标排列：`图标对齐方式` 取 `上/左`，另支持 Web 扩展 `中/右`；`自动排列图标` 控制弹性网格与定宽布局。`排列图标` 可以不传参数。
- 字体和颜色：`字体` 可给名称字符串或 `{名称,大小,加粗}`；`文字颜色/文本颜色`、`文本背景色`、`背景/背景颜色` 和 `表格外观` 各有实际样式落点。`表格外观.单元格背景` 独立控制单元格底色。
- 边框：`边框` 使用 CSS 边框文本；`显示表格线` 控制横纵分格线；`无表头` 隐藏表头。
- 标题：`标题自动换行` 同时应用于表项标题与表头。`表头可单击` 的声明别名为 `可排序`，关闭排序时仍保留独立表头单击事件。
- 行高：`条目行高` 写 20–200 的整数像素后按固定高度显示；固定高度下单行截断，不被换行长文撑高；不写则保留内容行高。
- 列：`列宽` 每项 40–2000 像素或 `自适应`；`列对齐方式` 每项 `左/中/右`。`表列可拖动` 支持拖动换列序；表头右沿拖动改单列列宽、下沿拖动改整体行高（20–200），拖中实时预览、松手经 `设置列宽`/`设置行高` 写回，不依赖 `表列可拖动`。
- 排序交互与尺寸收敛：可排序列常显两个独立按钮，▲ 固定升序、▼ 固定降序；重复点同一方向不反转，标题只记录单击事件。`自适应` 由底座按该列全部行里最宽的内容算出确定像素值，一次定死后写进片段；浏览器不测量、不缓存、不重算，排序、翻页、编辑都不会改列宽。尺寸只由显式像素、拖列换位、右沿拖宽或声明结构变更决定。整表按各列宽度之和定宽，窄容器横向滚动；`换页` 为假时不分页、全部行一次展示（`换页` 缺省为真，`每页行数` 为 0 也等于全部展示）。验收用真实 DOM 对比每次操作前后列宽及表宽，并验证双按钮方向、窄容器横向滚动和鼠标拖宽。
- 图片：`图片组`、`状态图片组`、`表头图片组` 是与行或列等长的同源 URL/null 数组。子项图片由 `置图片` 的 `列索引` 指定，行列结构变动时同步图片坐标。
- 热点：`热点跟踪` 控制悬停跟踪及高亮；`手形指针` 控制行指针；`标注热点/标注非热点` 分别控制悬停与非悬停下划线，可同时开启。
- 选择：`选择模式` 取 `不选/单选/多选/整行`；也接受 `单一选择/整行选择` 声明。`现行选中项` 用原始表项索引初始化；`始终显示选择项` 为假时失焦隐藏高亮，不删除选中状态。
- 检查：`勾选列/是否有检查框` 只控制检查框；`检查框状态` 为逐行逻辑值或 0/1 数组。检查与选择独立，`取当前状态图片` 在检查框模式返回 0/1，不能用选择状态冒充检查状态。
- 排序：`排序方式` 支持比较类型 `自动/文本/数值/日期`，也接受官方方向名称 `不排序/正向/逆向`。比较类型与方向需要分开时用 `排序方式` 加 `排序方向:"升序/降序"`。数值支持大小单位；日期必须为有效日历日期，空值在两个方向均排最后。
- 编辑：`允许编辑` 打开双击编辑；`结束编辑文本` 是运行时只读结果，从 4930 读取，不是输入框提示。`进入编辑/结束编辑` 的 `批准:false` 分别拒绝进入或放弃改值，结束时仍可读取候选文本；默认批准。
- 滚动：`平面滚动条` 给滚动容器平面细滚动条；`表头固定` 配 `最大高度` 保持表头吸顶，分页条在滚动区外。
- 通用：`左/上/宽/高`（也接收 `左边/顶边/宽度/高度`）使用数值像素；`标记` 挂在组件根；`可视:false` 隐藏；`禁止:true` 使浏览器组件不可交互；`鼠标指针` 为 `默认/手形/文本/等待/禁止`；这些开关不影响显式程序调用。

### 6.2 35 方法及参数

所有行列索引从 0 开始。排序、翻页保留原始行身份；插入、删除同步选择序号、检查状态、图片和缩进。无效输入先校验，拒绝后不得把坏状态写进实例。

- `取标题`：`表项索引,列索引=0`。
- `置标题`：`表项索引,列索引=0,标题`，也接受通用单元格参数 `值`。
- `取图片/置图片`：`表项索引,列索引=0`；写入另给 `图片:同源URL/null`。
- `取当前状态图片/置状态图片`：`表项索引`；检查框模式写 `图片:0/1`，普通状态图片写 URL/null。
- `取缩进数目/置缩进数目`：`表项索引`；写 `缩进数目`，默认 0。
- `取表项数值/置表项数值`：`表项索引`；写整数 `数值`，默认 0。
- `取被选择表项`：无参，查询结果为整数数组。
- `取已选择表项数`：无参，查询结果为整数。
- `是否被选择/选择表项/取消表项选择`：`表项索引`。取消其他单选行不清掉当前行。
- `取表项数`：无参，返回当前数据行数。
- `插入表项`：`行数据`，可选 `位置,数值,图片,状态图片,缩进,检查状态`；省略位置为追加；查询结果为插入索引。
- `删除表项`：`表项索引`。
- `全部删除`：无参，连同图片、检查、数值、缩进和编辑状态一起清空。
- `查找表项`：`文本,起始位置=0,是否精确匹配=true,列索引=0`；列索引 -1 查全部列，非精确为前缀匹配，未找到返回 -1。
- `查找表项数值`：`数值=0,起始位置=0`，未找到返回 -1。
- `保证显示`：`表项索引`，按当前排序定位目标页并真实滚动到目标行。
- `排列图标`：无参；可选 `排列方式:上/左/中/右`。
- `取列标题/取列对齐方式/取列宽/取列图片/图片是否居右`：`列索引`；未指定外观时分别使用实际声明缺省，不用 null 冒充 `false/左/auto`。
- `置列标题`：`列索引,标题`。
- `置列宽`：`列索引,列宽`。
- `置列图片`：`列索引,图片`；图片居右使用同一 4929 的 `设置列图片居右`，传 `列索引,居右`。
- `取列数`：无参。
- `插入列`：`标题`，可选 `位置,列宽,列对齐,图片,居右`；查询结果为插入索引。
- `删除列`：`列索引`。
- `进入编辑`：`表项索引,列索引=0,批准=true`。配套 `结束编辑` 传行列索引、文本及批准；`取消编辑` 放弃编辑。

### 6.3 九事件

`当前表项被改变`、`表项被激活`、`表头被单击`、`表项跟踪`、`左键单击表项`、`右键单击表项`、`开始编辑`、`结束编辑`、`检查框状态被改变`。

事件统一写入 `最后事件` 与有界 `事件记录`（最近 32 条），含稳定表项索引、列索引及检查或编辑参数。纯记录事件回空片段，不重绘表格，避免鼠标悬停产生重绘循环。业务回调仍由调用方决定；底座不主动请求业务地址。

### 6.4 验收范围

源码单测、平台检查、逐方法 HTTP 和浏览器交互分开记证据。静态成员映射不等于运行通过，查询能回值也不代替拖动、编辑、滚动与事件的真实浏览器验证。当前制品与最新验收结果以组件收敛裁决的验收段为准。

## 七、真实渲染输出（拿最简那档跑的）

传 `{"类型":"表格","预设":"数据表","列":[…],"行":[…]}`，底座回：

```text
<div class="hs-tree-node hs-card 斑马纹 表头固定" data-hs-h="本次句柄">
  <div class="hs-table-scroll" style="max-height:480px;overflow:auto">
    <table class="hs-table" style="width:360px;table-layout:fixed" data-固定列宽="1">
      <colgroup><col style="width:240px"><col style="width:120px"></colgroup>
      <thead><tr><th>名称
        <button data-hs-op="排序" data-hs-key="名称" data-排序升序="true">▲</button>
        <button data-hs-op="排序" data-hs-key="名称" data-排序升序="false">▼</button>
      </th>…</tr></thead>
      <tbody><tr><td>合同.pdf</td><td>20480</td></tr>…</tbody>
    </table>
  </div>
  …分页条在滚动区外…
</div>
<script>…引导脚本：点方向按钮 → 找最近 data-hs-h → 交回 {句柄, 操作, 参数}…</script>
```

注意两点：

- 示例省略非关键属性；句柄由本次渲染签发，方向按钮向上找最近的带句柄容器，不硬编码句柄。
- 片段末尾自带引导脚本，V4 不用管；同一页只注入一份公共脚本。

教学演示以 `/tmp/表格demo/demo.py` 为现行主文件。`演示设置.py` 放常调参数，`底座交互_固定.py` 与 `启动服务_固定.py` 承担固定转发和 HTTP 支撑。本轮能力补齐不改教学 demo，也不再拆文件或增加独立 JSON。

页面声明 = {
