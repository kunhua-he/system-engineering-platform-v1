# 网页界面组件参数总表

本文是 4928 渲染组件树的字段权威清单，逐类型列出代码真正读取的键、取值范围与缺省行为。
来源只有一处：`网页界面支持库/src` 下的渲染代码（组件树分派器与各组件实现、外观属性、视觉基准、交互脚本）。
代码没校验的上限一律写「未设上限（代码无校验）」，代码没读的键不列。

## 口径

- 字段一行一条，形如：字段名 · 类型 · 作用 · 取值 · 缺省。
- 类型只有五种：文本 / 数值 / 逻辑 / 对象 / 数组。逻辑值在 JSON 里就是 `true` / `false`。
- 「尺寸类」字段（宽、高、圆角、内边距、最小高、栏宽、左、上）：写数字按 px 处理，写字符串原样使用（如 `"100%"`、`"calc(100% - 120px)"`）。
- 取值越界、类型不符、枚举不认识，一律回「内容不合法」，不静默忽略、不截断、不回落默认观感。
- 只有「数量超上限」才回「资源受限」：深度超 32 层、节点超 2000 个、原样片段超 200000 字节、聊天消息超 300 条。
- 渲染树有两条出口：`整页: true` 出完整 HTML（带文档头与中性样式），否则出片段（外层一个 `hs-tree` 包裹）。

## 一、节点公共字段（19 种类型全部可带，共 12 个）

- 类型 · 文本 · 作用：节点分派键，决定交给哪个组件实现 · 取值：只认 19 个词——表单容器、输入、按钮、行、列、网格、侧栏、分区、画布、标题、图标、文字、分隔条、表格、表单、聊天流、窗口、悬浮层、原样；其他值报内容不合法 · 缺省：必填，不写或写错都报内容不合法
- 子 · 数组 · 作用：子节点表，递归渲染；容器的内容都从这里出 · 取值：节点对象组成的数组 · 缺省：不写或不是数组时按空表处理，容器渲染成空壳，不报错
- 打开窗口 · 文本 · 作用：点击该节点打开同标识的窗口（展开并置顶），同时给节点套一层 `display:contents` 的触发壳 · 取值：合法标识（字母、数字、`-`、`_`、汉字，字符数 ≤ 32）· 缺省：不写则该节点不可开窗
- 切换显隐 · 文本 · 作用：点击该节点切换同标识悬浮层的显隐 · 取值：合法标识（同上）；悬浮层自身禁写此字段，写了对悬浮层报内容不合法 · 缺省：不写则无此行为
- 提示文案 · 文本 · 作用：点击该节点弹一条轻提示 · 取值：任意文本（输出时转义），未设上限（代码无校验）· 缺省：不写则不挂提示
- 确认文案 · 文本 · 作用：点击该节点先弹确认框，确认后才继续 · 取值：任意文本（输出时转义），未设上限（代码无校验）· 缺省：不写则不挂确认
- 右键菜单 · 数组 · 作用：给节点挂右键菜单，菜单项只认四种通用动作 · 取值：菜单项对象数组，每项可带 文本（显示文字）、打开窗口（窗口标识）、切换显隐（悬浮层标识）、打开地址（直接跳转）、提示（轻提示文字）；内容未设上限（代码无校验），空数组等于没挂 · 缺省：不写或不是数组则不挂右键菜单
- 可拖 · 逻辑 · 作用：让节点成为可拖动项，组内可换位 · 取值：真 / 假；为真时才读 `拖动键` · 缺省：假（不可拖）
- 拖动键 · 文本 · 作用：拖动项的稳定标识，顺序回传时按它拼顺序串 · 取值：任意文本，未设上限（代码无校验）；不写时由脚本按文本摘要临时生成 · 缺省：不出该属性
- 拖放组 · 文本 · 作用：把若干可拖节点归入同一换位组，组内拖放结束后回传新顺序 · 取值：合法标识（同上）· 缺省：不写则节点不参与拖放换位
- 顺序回传地址 · 文本 · 作用：拖放换位后把新顺序 POST 到该地址 · 取值：必须以 `/` 开头（同源路径）；只有写了 `拖放组` 才会被读取和校验 · 缺省：不写则只把顺序写在容器上，不回传
- 容器样式 · 文本 · 作用：片段出口最外层 `hs-tree` 包裹层的内联样式，只对根节点生效 · 取值：任意 CSS 文本，未设上限（代码无校验）· 缺省：不写则外层无内联样式

补充两条渲染次序（都用公共字段拼出来）：
- `打开窗口` 优先级最高：写了它就直接套开窗壳并返回，该节点上的 `切换显隐` 与提示/确认/右键/拖放都不再挂。
- 否则按 `切换显隐` → 提示/确认/右键/拖放 的顺序挂载；都没写则节点原样输出，不套壳。

另有一条不靠声明的自动行为：每个渲染出来的节点都由底座自动签发一个组件句柄，写在片段首个标签的 `data-hs-h` 上（不额外套包装层）。这是底座给的行为，不是可声明字段；重渲染时节点带着 `__组件句柄` 回来即复用同一句柄。

## 二、通用外观字段（所有节点都校验，共 21 个）

这 21 个字段在**每个节点**进入渲染时都过一遍校验（类型或范围不对即报内容不合法），但只有走通用样式拼装的类型才会真正把值写进样式。
会应用的 12 类：表单容器、行、列、网格、侧栏、分区、画布、悬浮层、窗口、图标、文字、分隔条。
不应用的 5 类：标题、表格、表单、聊天流、原样（它们的实现不走通用样式拼装，写了也不产生样式，但不报错）。
输入与按钮不走本节，改走第三节「控件外观字段」。

尺寸类字段（宽、高、圆角、内边距、最小高）：数字按 px，字符串原样。

- 宽 · 尺寸类 · 作用：节点宽度 · 取值：数字或任意 CSS 长度文本，未设上限（代码无校验）· 缺省：不出该属性（由组件中性样式决定）
- 高 · 尺寸类 · 作用：节点高度 · 取值：同上，未设上限（代码无校验）· 缺省：不出该属性
- 间距 · 数值 · 作用：子项间距，拼成 `gap` · 取值：数值（只认数字，写字符串不生效也不报错），未设上限（代码无校验）· 缺省：不出该属性
- 内边距 · 尺寸类 · 作用：内边距 · 取值：数字或 CSS 长度文本（多段如 `"10px 12px"`），未设上限（代码无校验）· 缺省：不出该属性
- 背景 · 文本或对象 · 作用：纯色 / 线性渐变 / 背景图三种形态 · 取值：见下方「背景三形态」· 缺省：不写或写 `null` 则不设背景
- 文字颜色 · 文本 · 作用：文字色 · 取值：`#RGB` / `#RRGGBB` / `#RRGGBBAA` 三种形状之一，其他报内容不合法 · 缺省：不出该属性
- 边框颜色 · 文本 · 作用：边框色 · 取值：同上三种十六进制形状 · 缺省：不出该属性
- 圆角 · 尺寸类 · 作用：圆角半径 · 取值：数字或 CSS 长度文本，未设上限（代码无校验）· 缺省：不出该属性
- 边框 · 文本 · 作用：整条边框声明（含线宽与线型）· 取值：任意 CSS 文本，未设上限（代码无校验），不做白名单 · 缺省：不出该属性
- 溢出 · 文本 · 作用：溢出处理 · 取值：任意 CSS 文本（如 `hidden`、`auto`），未设上限（代码无校验）· 缺省：不出该属性
- 最小高 · 尺寸类 · 作用：高度下限 · 取值：数字或 CSS 长度文本，未设上限（代码无校验）· 缺省：不出该属性
- 字体大小 · 数值 · 作用：字号（px）· 取值：1 至 200，越界报内容不合法 · 缺省：不出该属性
- 字重 · 数值 · 作用：字粗 · 取值：100 至 900；此处不要求整百，只有控件路径（输入/按钮）才要求整百 · 缺省：不出该属性
- 行高 · 数值 · 作用：行高倍数 · 取值：0.8 至 3.0 · 缺省：不出该属性
- 字距 · 数值 · 作用：字间距（px）· 取值：-5 至 20 · 缺省：不出该属性
- 模糊 · 数值 · 作用：背景模糊（px），与饱和合成一条 `backdrop-filter` · 取值：0 至 80 · 缺省：0（与饱和同时为 0 则不出滤镜）
- 裁剪行数 · 数值 · 作用：文本最多显示几行后省略（挂成 `--hs-clamp` 变量，目前只有图标名称用）· 取值：1 至 6 · 缺省：不出该属性（中性样式按 2 行）
- 层 · 数值 · 作用：`z-index` 层级 · 取值：0 至 200 · 缺省：不出该属性
- 饱和 · 数值 · 作用：背景饱和度（%），与模糊合成一条滤镜 · 取值：50 至 300 · 缺省：0（不出滤镜）
- 阴影 · 文本 · 作用：阴影档位 · 取值：只认 无 / 轻 / 中 / 重 / 浮层 / 窗口，其他报内容不合法；`无` 等于不出阴影 · 缺省：不写则不出阴影
- 文字阴影 · 文本 · 作用：文字阴影档位 · 取值：只认 无 / 轻 / 中；`无` 等于不出阴影 · 缺省：不写则不出文字阴影

#### 背景三形态

- 纯色：字符串，只认 `#RGB` / `#RRGGBB` / `#RRGGBBAA`。
- 线性渐变：对象，`类型` 必须是 `线性渐变`；子键 `角度`（数值，-360 至 360，缺省 135）、`颜色节点`（数组，2 至 16 项，每项 `颜色` 为十六进制、`插入位置` 为 0 至 100 且不得比前一项小；缺了任一项报内容不合法）。
- 图片：对象，`类型` 必须是 `图片`；子键 `资源` 为同源路径（必须以 `/` 开头，禁 `//`、`..`、冒号）。铺法固定为 cover 居中。
- 对象里 `类型` 不是这两个词，报内容不合法。

## 三、控件外观字段（只有输入与按钮走这套，共 9 个）

输入与按钮的样式由独立的控件样式路径拼装。**2026-11-02 收敛后与第二节口径一致**：`字号` 与 `字体大小` 互为回退、值域都是 1 至 200；`字重` 100 至 900 任意值（不再要求整百）；`内边距` 两条路径都接受纯数字与带单位段。

- 宽 · 尺寸类 · 作用：控件宽度 · 取值：数字或 CSS 长度文本 · 缺省：不出该属性（输入框默认 100%，按钮由内边距撑开）
- 高 · 尺寸类 · 作用：控件高度 · 取值：数字或 CSS 长度文本 · 缺省：不出该属性（中性样式：输入 32px、按钮 32px）
- 圆角 · 尺寸类 · 作用：控件圆角 · 取值：数字或 CSS 长度文本 · 缺省：不出该属性（中性样式 4px）
- 边框颜色 · 文本 · 作用：控件边框色 · 取值：三种十六进制形状之一，其他报内容不合法 · 缺省：不出该属性
- 背景 · 文本或对象 · 作用：控件底色（纯色 / 渐变 / 图片，规则同第二节背景三形态）· 取值：同上 · 缺省：不出该属性
- 文字颜色 · 文本 · 作用：控件文字色 · 取值：三种十六进制形状之一 · 缺省：不出该属性
- 字号 · 数值 · 作用：控件字号（px）· 取值：1 至 200（与「字体大小」互为回退）· 缺省：不出该属性（中性样式 14px）
- 字重 · 数值 · 作用：控件字粗 · 取值：100 至 900 任意值（收敛后不再要求整百）· 缺省：不出该属性
- 内边距 · 文本 · 作用：控件内边距 · 取值：一至四段、每段为数字加 `px` / `%` / `em` / `rem` 单位，总字符数 ≤ 40；纯数字（如 `"12"`）合法 · 缺省：不出该属性

## 四、树定义外层字段（不在节点上，共 4 个）

- 根 · 对象 · 作用：整棵树的根节点 · 取值：一个节点对象 · 缺省：必填，缺了报内容不合法
- 整页 · 逻辑 · 作用：出完整 HTML 还是片段 · 取值：真 = 完整页面（带文档头、中性样式），假或不写 = 片段 · 缺省：假
- 页面标题 · 文本 · 作用：整页模式的 `<title>` · 取值：任意文本（转义）· 缺省：空标题
- 页面标识 · 文本 · 作用：这次渲染的归属串，释放与回收组件实例时按它 · 取值：任意文本，未设上限（代码无校验）· 缺省：自动生成 `渲染-<时间戳>-<序号>`

## 五、容器类组件

### 行（7 个字段）

横向排列。`垂直对齐` 管交叉轴，`水平对齐` 管主轴；两者用的都是同一套对齐词。

- 垂直对齐 · 文本 · 作用：交叉轴对齐（行内即上下对齐）· 取值：只认 居中 / 终点 / 两端；其他词（含不写）一律按起点 · 缺省：起点
- 水平对齐 · 文本 · 作用：主轴对齐（行内即左右分布）· 取值：居中 / 终点（靠右）/ 两端（散开）；其他按起点 · 缺省：起点
- 放大 · 对象 · 作用：子图标悬停放大（列队式 Dock 效果）· 取值：子键 `峰值` 数值 1.0 至 2.5（缺省 1.0）、`半径` 数值 20 至 400（缺省 120）；写非对象报内容不合法 · 缺省：不写则不出放大行为
- 筛选区 · 文本 · 作用：把该容器标记为「可被筛的那片区域」· 取值：字符数 ≤ 64，禁引号与 `<` · 缺省：不写则不是筛选区
- 筛选值 · 文本 · 作用：该节点的分类值，供按钮按分类筛 · 取值：同上 · 缺省：不出该属性
- 筛选目标 · 文本 · 作用：指向被筛容器（输入框专用）· 取值：同上 · 缺省：不出该属性
- 筛选分类 · 文本 · 作用：按钮点击后的分类名（按钮专用）· 取值：同上；值为 `全部` 时不按分类筛 · 缺省：不出该属性

注意：这四个筛选字段是「取第一个非空值」的实现，同一节点上同时写多个只会生效一个（判定顺序为 筛选区、筛选值、筛选目标、筛选分类）。

### 列（7 个字段）

纵向排列。与行相反：`水平对齐` 管交叉轴，`垂直对齐` 管主轴（分布）。

- 水平对齐 · 文本 · 作用：交叉轴对齐（列内即左右对齐）· 取值：居中 / 终点 / 两端；其他按起点 · 缺省：起点
- 垂直对齐 · 文本 · 作用：主轴分布（列内即上下分布）· 取值：居中 / 终点 / 两端；其他按起点 · 缺省：起点
- 放大 · 对象 · 作用：子图标悬停放大 · 取值：`峰值` 1.0 至 2.5（缺省 1.0）、`半径` 20 至 400（缺省 120）· 缺省：不写则无
- 筛选区 · 文本 · 作用：标记为被筛区域 · 取值：≤ 64 字符，禁引号与 `<` · 缺省：无
- 筛选值 · 文本 · 作用：分类值 · 取值：同上 · 缺省：无
- 筛选目标 · 文本 · 作用：指向被筛容器 · 取值：同上 · 缺省：无
- 筛选分类 · 文本 · 作用：分类按钮的分类名 · 取值：同上 · 缺省：无

### 网格（7 个字段）

等分网格；只有交叉轴对齐，没有主轴分布。

- 列数 · 数值 · 作用：等分几列 · 取值：整数，超出 1 至 24 会被夹到边界（不是报错）；小数、字符串等非整数一律按 3 · 缺省：3
- 垂直对齐 · 文本 · 作用：单元格交叉轴对齐 · 取值：居中 / 终点 / 两端；其他按起点 · 缺省：起点
- 放大 · 对象 · 作用：子图标悬停放大 · 取值：`峰值` 1.0 至 2.5、`半径` 20 至 400 · 缺省：不写则无
- 筛选区 · 文本 · 作用：标记为被筛区域 · 取值：≤ 64 字符，禁引号与 `<` · 缺省：无
- 筛选值 · 文本 · 作用：分类值 · 取值：同上 · 缺省：无
- 筛选目标 · 文本 · 作用：指向被筛容器 · 取值：同上 · 缺省：无
- 筛选分类 · 文本 · 作用：分类按钮的分类名 · 取值：同上 · 缺省：无

### 侧栏（4 个字段）

左侧菜单栏 + 右侧主区。不做放大与筛选（实现里没接这两个）。

- 栏宽 · 尺寸类 · 作用：左栏固定宽度 · 取值：数字按 px，字符串原样，未设上限（代码无校验）· 缺省：232px
- 标题 · 文本 · 作用：左栏顶部的分组小标题 · 取值：任意文本（转义）· 缺省：不写则不出标题行
- 菜单 · 数组 · 作用：左栏菜单条目表 · 取值：条目对象数组，每项见下；不写或不是数组则为空菜单 · 缺省：空菜单
- 菜单外观 · 对象 · 作用：左栏底色、菜单项文字/激活色、项字号/圆角/内边距，全部挂成 CSS 变量，中性样式用变量兜底 · 取值：见下方子键表；写非对象报内容不合法 · 缺省：不写则全部走中性缺省

菜单条目子键（每个条目可带）：
- 名称 · 文本 · 作用：条目显示文字 · 取值：任意文本（转义）；不写则显示空 · 缺省：空
- 图标 · 文本 · 作用：条目左侧图标（emoji 或字符，直接作文本输出）· 取值：任意文本（转义）· 缺省：不写则不出图标位
- 打开地址 · 文本 · 作用：给了就渲染成链接 · 取值：必须以 `/` 开头，禁 `//`、`..`、冒号，违规报内容不合法 · 缺省：不写则渲染成不可跳转的展示项
- 激活 · 逻辑 · 作用：高亮该条目 · 取值：真 / 假 · 缺省：假

菜单外观子键（7 个）：
- 栏底色 · 文本 · 作用：左栏底色（`--hs-menu-panel`）· 取值：十六进制颜色 · 缺省：#f7f8fa

## 十、缺口（代码里没有、但界面上会需要的组件类型）

以下类型在分派器里没有对应分支，写了会直接报内容不合法；其中几条在中性样式里已经备好了样式，却缺组件类型，属于最该补的。

- 下拉选择：中性样式里已有整套选择框样式，组件树却没有对应类型，只能用输入框加筛选按钮凑；缺选项表、缺初值、缺多选。
- 多行文本域：输入只有文本框/密码框/数字框/邮箱四种单行种类，没有多行输入；表单组件把每个字段都渲染成单行框，长文本无处写。
- 勾选、单选、开关：没有勾选框、单选框、开关三种状态控件；现状是拿按钮的 `可选中` 当开关用，缺提交值与必选约束。
- 文件夹树 / 树形列表：没有树类型，也没有展开箭头、层级缩进、选中路径；侧栏菜单只有一层条目，做文件浏览器只能靠原样手写 HTML 绕开。
- 通用列表：只有二维数组的表格与对话气泡，缺「一列卡片式列表项」（图标 + 主标题 + 副标题 + 右侧操作）。
- 菜单（下拉 / 工具栏 / 菜单栏）：右键菜单是脚本按节点上的数组临时生成的，没有声明式下拉菜单、工具栏、菜单栏类型；也没有选中态回传。
- 对话框：中性样式已备标题、正文、动作区三件套，组件树却只有悬浮层与窗口，缺标准确认框、信息框、输入框弹窗（带确定/取消回调）。
- 进度条：没有进度类型，也没有环形进度、百分比、不确定态；上传、导入、批处理这类界面表达不了。
- 标签页 / 分段控件：没有分页切换容器，缺页签头、选中页、页内容按需渲染。
- 图片 / 头像：图标能出图片，但没有独立图片类型，缺宽高比、裁切模式、懒加载、加载失败兜底。
- 分页器：分页条只在表格内部生成，没有可独立使用的分页组件，自定义列表无法复用同一套翻页交互。
- 加载态 / 骨架屏：没有旋转指示器、骨架占位、空态（聊天流以外的空态无处表达）。
- 徽标 / 标签（badge、chip）：没有小标签类型，只能拿文字加背景色凑，缺数字角标与状态点。
- 折叠面板 / 步骤条 / 面包屑：分区不能折叠，缺手风琴、步骤进度、层级导航三种结构性组件。

## 十一、自检与计数
