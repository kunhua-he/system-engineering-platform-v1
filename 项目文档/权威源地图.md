# 权威源地图

> 本件是「去哪里取权威」的**唯一落点表**（一份，不双写）。
> 机器局部件（如运行数据根的《派腿前置》）不再复述本图，只留一行指针。
> 判据 六六（权威地图路径存在）逐行核本图声明的路径 —— 删 / 改即红。
> 机判清单住库 `规则` 表 `类` = `权威地图`（一行一个权威件），本件是它的散文面。

## 一 取法

- 读法统一（网关三字段）：`{"操作":"取条款","参数":{"文档路径序号表":[{"文档路径":"<路径>","序号":N}]}}`。
- **唯一台账**：库 `开发工具/信息核心/信息核心.db` 的 `未完成` 表（库即存本；只记未完成 · 做完即删 · 不是引用源）。四栏 = `号 · 缺什么 · 落点 · 验证命令`；改完重跑 `信息核心.py 建库` 即刷新。
- **一条铁律**：微修只认台账负债。台账之外的任何记录（反馈库判词 / 报告 / 待核清单 / 临时发现）一律是未审核，须裁决进台账后才可动手（库 `规则` 表 强制台账-25）。
