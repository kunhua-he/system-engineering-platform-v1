# 易语言超级列表框能力对照

## 取证来源（全部真源，不用二手清单）

- 支持库二进制：`易语言源码调研/缓存/原包_e/lib/iext.fne`。命令名、参数说明、属性说明、事件说明都在这份二进制的中文资源区里，本对照逐条从该区解出。
- 命令内部名：同一文件里的 `iext_fnLV*` 导出符号表（35 条）。
- 官方例程：`lib/iext/samples/超级列表框演示.e`、`samples/易模块/超级列表框_模块.e`。
- 底座侧真源：`项目文档/组件参数总表.md` 的「表格（完整超级列表框字段）」、`组件操作/表格操作.rs` 与 `表格查询.rs` 的原子分派、`组件操作/表格事件.rs` 的事件白名单。

## 四、口径差异 5 项（设计取舍，不是缺功能）

- 列宽魔法值：易语言 `-1` 按数据最宽、`-2` 按标题最宽；底座统一写 `自适应`，按全部行一次算成固定像素并固化，编辑后不再回弹。
- 排序入口：易语言靠 `排序方式` 属性自动排序；底座用 `可排序` 打开表头常显 ▲/▼，由用户或 `排序` 原子指定方向，且明确 `排序方式` 比较口径。
- 视图类型：易语言 `普通列表框`；底座叫 `列表`，其余三种名称一致。
- 图标对齐取值：易语言 `顶部对齐 / 左边对齐`；底座 `上 / 左 / 中 / 右`，语义等价、写法不同。
- 事件返回：易语言在事件子程序里读 `现行选中项` 取上下文；底座把表项索引、列索引等直接写进事件记录并回传状态。

## 五、底座多出易语言没有的

- 分页：`每页行数` / `换页`，底座算页、只回当前页片段。
- 斑马纹与斑马纹色、表头吸顶（`表头固定` + `最大高度`）。
- 行高原子：`设置行高` / `取行高`（20–200），并支持表头下沿拖动。
- 提示类：`设置表项提示` / `取表项提示`、`设置列提示`（落 title，长内容不用撑宽列）。
- 图标间距：`图标间距`（0–40，缺省 8），替代易语言只能靠图片本身留白。
- 编辑框：双击就地编辑，输入框绝对定位铺满单元格，进编辑前后行高列宽零变化；`取编辑框` 可查正在编辑哪一格。
- 列拖动、行高拖动、`移动列`、`清空表格`、`取行高`、`取表项间距` 等运行时原子。

## 六、结论

易语言超级列表框的 35 条命令、36 条属性、9 条事件，共 80 项能力在底座全部有对应落点，其中 75 项同名或近似同名，5 项为口径差异。差异都写在第四节，没有「还没做」的项。底座另有分页、吸顶、提示、图标间距、行高拖动等易语言本身没有的能力。
