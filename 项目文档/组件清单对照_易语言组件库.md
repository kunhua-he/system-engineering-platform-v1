## 一、易语言的界面组件（从 51 槽里挑出带界面的）

窗口族：

- `窗口`：容器之根，有标题栏、最小化/最大化/关闭、可嵌套子组件
- `菜单`：窗口菜单栏与弹出菜单
- `通用对话框`：打开/保存/选色/选字体这类系统弹窗

输入族：

- `编辑框`：单行/多行文本、密码框、只读
- `组合框`：可编辑的下拉框
- `选择框`：复选框
- `单选框`：单选按钮
- `列表框`：单列条目列表
- `选择列表框`：可勾选的条目列表
- `日期框`：日期选择
- `月历`：日历面板
- `调节器`：上下箭头微调数字

文件族（**这就是「文件夹」在易语言里的真实形态，是三种而不是一种**）：

- `驱动器框`：选盘符
- `目录框`：选目录（树）
- `文件框`：选文件

按钮族：

- `按钮`
- `图形按钮`：带图标的按钮
- `超级链接框`：超链接样式的可点击文本

显示族：

- `标签`：静态文本
- `图片框`：贴图
- `影像框`：播放影像/动图
- `画板`：自由绘制的画布
- `外形框`：纯边框/分组的外框
- `分组框`：带标题的分组容器
- `选择夹`：选项卡容器

数值与滚动族：

- `进度条`：进度
- `滑块条`：拖动取值的滑杆
- `横向滚动条` / `纵向滚动条`：滚动
- `调节器`（见上）

表格与数据族：

- `表格`：二维表
- `报表`：打印/报表视图
- `字段信息` / `数据源` / `数据库提供者`：数据绑定（非纯界面）

系统与装饰：

- `时钟`：定时触发
- `颜色选择器`
- `打印机` / `打印设置信息`
- `字体`：字体对象
- `对象` / `变体型` / `变体类型`：通用值类型

## 二、与我们现有底座节点类型的对照

已能对上（六类，已有能力可直接用）：

- `窗口` ↔ 窗口
- `画板` ↔ 画布
- `分组框` / `外形框` ↔ 分区
- `标签` ↔ 文字 / 标题
- `按钮` ↔ 按钮（含主要/成功/警告/危险变体）
- `编辑框` ↔ 输入（文本框 / 密码框 / 数字框 / 邮箱）
- `表格` / `报表` ↔ 表格

缺口（易语言有、我们没有，共 22 类，按业务价值排）：

第一档（做业务界面立刻要用）：

- `目录框`：目录树（文件管理现在拿表格凑，最该补）
- `文件框`：文件选择
- `列表框` / `选择列表框`：通用列表、可勾选列表
- `组合框`：下拉选择
- `选择框` / `单选框`：勾选与单选
- `选择夹`：选项卡（多页签界面）
- `菜单`：右键菜单与下拉菜单（现有 `右键菜单` 只是挂 JSON，没有组件本体）
- `进度条`：长任务可视反馈
- `状态条`：底部状态栏

第二档（体验增强）：

- `滑块条`、`横向滚动条`、`纵向滚动条`
- `日期框`、`月历`
- `图片框`、`影像框`
- `超级链接框`、`图形按钮`
- `颜色选择器`、`调节器`
- `驱动器框`

第三档（系统件，非界面主路）：

- `时钟`（定时器，可在底座侧做成组件级定时）
- `通用对话框`
- `字体`（现在是通用外观字段，够用）

## 三、从易语言学到的三条做法

1. **组件名直接沿用中文口语**（`编辑框`、`目录框`、`选择夹`），不造英文抽象名。用户一看就知道是什么。
2. **每个组件自带属性 + 方法 + 事件**，属性是「可以赋值的键」，方法是「可以调的动作」——这正是「属性名可直接当操作名」的出处，不是我们发明的语法。
3. **文件类拆成三种**（驱动器/目录/文件），不塞进一个万能组件。粒度细了，传参反而简单。
