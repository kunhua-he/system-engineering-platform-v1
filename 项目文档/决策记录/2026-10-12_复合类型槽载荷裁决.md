# 复合类型槽载荷裁决（2026-10-12）

## 一 为什么要裁

`契约声明` 的 `0103.json` 原文写着：

> 返回用的结构类型：固定占一个标签，不逐值结构顺排；值结构差异由 元素表 表达
> （**元素表 形状未定义，见下「待裁」**）

即：`100 列表` · `101 字典` · `102 JSON值` · `103 结果结构` 四个标签**只有声明，没有运行期形态**。
实测旁证两条：

- `对外接口面/调用接口面/src/协议报文/槽编码.rs` 认的类型标签只有 `0/1/2/3/4/5/6/4294967295`
- 全仓「读 103 槽的消费方」= 0 处；`渲染数据表.py` 把 `元素表` 一律渲染成 `core::ptr::null()`

后果：老项目 715 条能力里 **713 条返回结果型** ⇒ 不裁这个形状，「老能力端到端跑通」一条也做不到。

## 二 裁定：槽载荷 = 自描述 TLV

```text
槽（指针槽）
  类型标签  = 100 / 101 / 102 / 103（四者共用一个载荷形状，区别只在形状校验）
  槽标志位  = 引用位必置；交出所有权位由分配方决定
  槽字节长度 = 载荷字节数
  槽值      = 指向载荷的地址

载荷
  元素个数 : u32 大端
  元素     : 元素个数 个，顺序排列

元素
  名称长度 : u32 大端（可为 0）
  名称     : UTF-8 字节，长度 = 名称长度
  类型标签 : u32 大端
  值       : 按类型标签递归，见下

值（按类型标签）
  1 整数      : 8 字节大端
  2 双精度    : 8 字节大端（IEEE754 位型）
  3 逻辑型    : 8 字节大端（0 或 1）
  4 文本      : 长度 u32 大端 + UTF-8 字节
  5 字节集    : 长度 u32 大端 + 原始字节
  6 句柄      : 8 字节大端
  100/101/102/103 : 长度 u32 大端 + 子载荷（递归，允许任意深度）
  0 无值      : 0 字节
```

四个标签的区别**只在形状校验**，不在载荷形状：

- `100 列表` —— 元素名称一律空串（位置即序号）；名称非空即拒
- `101 字典` —— 元素名称非空；名称空串即拒
- `102 JSON值` —— 不限（标量也合法，此时元素个数 1 · 名称为空串）
- `103 结果结构` —— 元素名称非空（字段名）；重复名称即拒

## 三 为什么这么裁

- **大端** —— 与既有约定一致：段 20 载荷的平台身份长度就是 `u16 大端`。
- **自描述 + 定长前缀** —— 解码只需一次线性扫，不需要先读声明；嵌套靠长度前缀跳过，
  不依赖递归下降解析器。解码器可以**只解它认识的那几层**，其余原样跳过。
- **四标签共用形状** —— 一个编解码器守四个标签；形状校验做成一张按标签的小表，
  以后加标签（如 `104`）只加一行，不动编解码主体。
- **名称长度可为 0** —— 列表不需要名称，硬塞名字会逼调用方编名字。
- **不收 `Result` 包壳** —— 载荷就是值本身；成败由槽（空槽 / 类型标签）与调用回执表达。

## 四 被否决的做法

- **把 103 塞成文本槽（标签 4 + JSON 字节）** —— 否决。理由：类型标签会被抹平，
  调用方无法靠标签判形状，只能猜 JSON 形状；且与本仓「靠类型标签区分，不靠形状猜」的
  既有口径直接冲突（该口径原文见 `槽编码.rs` 顶部注释）。
- **逐值结构各占一个标签** —— 否决。理由：标签空间会被值结构撑爆，
  且同一个能力换个字段就要换标签；`0103.json` 原话已明确「固定占一个标签，不逐值结构顺排」。
- **在槽里存 Rust 结构体裸内存** —— 否决。理由：跨进程 / 跨语言不可读，
  与「过线的槽」定位冲突（`跨语言适配/适配器实现/src/协议传值/线协议.rs` 已把过线槽限定为可搬运形状）。
- **元素表 用声明期指针表** —— 否决。理由：运行期值结构是数据不是声明，
  声明期的 `元素信息` 表只描述**字段名与类型**，不描述**这一次调用的值**。

## 五 落点与影响面（实现时照此走）

- `契约声明` —— 裁定的正文落 `契约声明/格式说明.md` 或等价权威档；`0103.json` 的
  「元素表 形状未定义」一句改指本裁定，不再挂「待裁」。
- `对外接口面/调用接口面/src/协议报文/槽编码.rs` —— 加 `100/101/102/103` 两支：入方向按载荷解码、
  出方向按载荷编码；`4294967295 错误` 那支不动。
- `运行内核` —— 若已有槽搬运/归还路径，需按「载荷是分配出来的字节」补归还口径。
- 与 `0100.json`/`0101.json`/`0102.json` 的 `元素表` 字段语义对齐：声明期元素表 = 字段名 + 类型标签。

## 六 未定项

- **载荷归谁释放** —— 本裁定只定形状，不定归属；实现时按既有 `槽标志::所有权交出`
  口径定「谁分配谁不释放、交出后由接收方释放」。
- **深度上限** —— 递归深度已定 **32**（`复合值载荷.rs::递归深度上界`）。
- **`102 JSON值` 与 `101 字典` 的重叠** —— 两者形状相近。若实现时发现可以合并，
  按「先读实际消费方再合并」的口径处理，不按名称机械合并。

## 八 重裁（2026-10-12 · 收口方自裁）

```text
裁：**100–103 定为「平台复合类型」号，从「扩展自有」里划出来；扩展类型从 104 起。**
   即改 `契约声明/号段图.json` 的 `类型号段`：

     0–7              内核自有（现有 8 个内置标签）
     8–99             内核自有（空余，未占）
     100–103          平台复合类型（列表 · 字典 · JSON值 · 结果结构）——
                      **声明件落 `契约声明/类型声明/`**，扩展侧不留第二份
     104–4294967294   扩展自有（原「100 起」整体上移 4）

为什么这么裁（而不是「把复合类型改成 8–11」）：
  · 100–103 **已在用**（翻译器 · 判据 64 · 生成声明）⇒ 改号是拆自身的承重链；
    而号段图改动只动一句归属文字，且「新增号段」是号段图允许的演进方式之一。
  · 号段图原文「`契约声明/类型声明/` 里全部落在这一段」是**描述现状**（当时确实只有 0–7），
    不是一条禁令；本裁定把描述改成事实。

连带（后续腿）：
  · `契约声明/号段图.json` 的类型号段改归属文字 + `冻结登记.json` 记一条（号段变更）
  · 0100–0103.json 迁进 `契约声明/类型声明/`（说明去掉「待裁」、改指本裁定）；扩展侧删掉
  · `对外接口面/调用接口面/src/常量.rs::类型标签` 补四个常量
  · 重跑生成器出 `声明数据.rs` 的新标签项
  · `槽编码.rs` 入/出各加一支（入方向须新变体 `槽源::载荷 { 标签, 字节 }`）
```

## 九 终裁（2026-10-12 · 落点 ① 执行到一半又撞到一层 · **平台不拥有 100–103**）

```text
§八 那条重裁（把 100–103 划给平台）**是错的**。执行落点 ① 时判据 ④ 翻出第二处：
  另一个扩展也声明了同样的 `100` 与 `103`。

再看内容，两条决定性事实：
  · 该扩展 `类型声明/103.json` 的 `元素表` **不是空的**：18 条，是这个扩展各能力的返回字段
    （名称 + 类型标签 + 说明）
  · 而它的 `能力声明/<号>.json` 只有 `返回类型: 103`，**没有返回字段表**

⇒ 返回字段表**只住在扩展自身的 `类型声明/103.json` 的元素表里**。
  平台把 `100–103` 收上去，等于**把每个扩展的返回字段表弄没地方放**。

⇒ 终裁：**`100–103` 留在扩展自有段**（`号段图.json` 的 `类型号段` 原样不动）；
  每个扩展在自身的 `类型声明/<标签>.json` 里声明这四个号，`元素表` 记该扩展各能力的返回字段。
  实测两个扩展都声明 `100`/`103` 且取值一致 ⇒ 平台按「通用复合标签」处理，
  但**归属仍在扩展** —— 平台不拥有这四个号。

留下来并已进主干的两件（形状住契约，号段不动）：
  · `契约声明/src/契约声明/执行载荷/复合值载荷.rs` —— 形状与编解码住契约层（**这是形状，不是号段**）。
    它把标签当参数收；`列表标签`/`字典标签`/`JSON值标签`/`结果结构标签` 四个常量只是与
    既有取值对齐的便捷常量。
  · `对外接口面/调用接口面/src/常量.rs::类型标签` 的四个常量 —— 同一理由。

落点 ①④ 的后续（**不再迁声明、不改号段图**）：
  · `槽编码.rs` 入 / 出各加一支：入方向须**新变体** `槽源::载荷 { 标签, 字节 }`
    （复用 `槽源::字节` 会把标签写死成字节集，`103` 会变成 `5`）；
  · 验收：HTML 走真实 GET/POST 打 `/接口/调用`，发 `103` / `101` / 嵌套 `103`；
    反向样本给 `101` 一个空名称元素，**必须拒**。
```
