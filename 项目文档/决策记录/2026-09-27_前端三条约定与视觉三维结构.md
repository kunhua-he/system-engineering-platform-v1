## 三 端口环境变量名：全平台唯一名 `V1_GATEWAY_PORT`

**事实**：全仓原有**两个**名：前端 CLI 的 `V1_GATEWAY_PORT`（`命令行界面/常量.py::端口环境变量`）
与部署侧的 `ZCODE_TRAFFIC_PORT`（`构建装配/上线切换/上线切换/制品.py::流量端口`）—— 同一个量两个名。

**裁决**：统一为 `V1_GATEWAY_PORT`；`ZCODE_TRAFFIC_PORT` **并掉，不留兼容别名**。

| 问 | 答 |
|---|---|
| 为什么留 `V1_GATEWAY_PORT` | 它已在冻结件 `接口面形状.md` 第六节被点名，改另一个名要改冻结件字面 |
| 前缀口径 | `V1_` = **平台自有面**（`V1_GATEWAY_PORT` · `V1_RUN_DATA_ROOT`）；`ZCODE_` = **工具侧前缀**，不许漏进运行期 |
| 为什么必须 ASCII | macOS 的 `/bin/sh` 是 bash 3.2，不认中文变量名（同 `决策记录/2026-09-27_运行数据根.md`） |
| 读它的几处 | **两处，就这两处**：CLI 与部署侧；都按三档 `--端口` > 环境变量 > 契约默认端口 |
| 网关自己读吗 | **不读**。`启动网关.rs` 只认命令行 `--端口`；环境变量只是**部署侧覆盖口** |
| 端口唯一来源变了吗 | **没变**。仍是 `契约声明/常量表.json` 的 `接口端口`；环境变量只是覆盖口，不是第二来源 |

**连带**：`接口面形状.md` §六「端口环境变量名」那条里「只有命令行界面一侧读它」这句已**不再成立**（现在两处）—— 已同步改正字面（属新增一行，走旁路登记）。

## 四 CLI 取值语法：落在 `接口面形状.md` 第三节（事实源指 `请求体.py::拼值`）

**事实**：`标签:值` / `@路径` / 裸值 = 文本(4) 这套语法是 CLI 自定的，没有既有件规定。

**裁决**：冻进 `项目文档/设计文档/接口面形状.md` 第三节 新增一节「命令行界面的取值语法（冻结 · 2026-09-27）」。

| 写法 | 发出的槽 |
|---|---|
| `标签:值` | `{"类型标签":<标签>,"值":<按上表成形>}`（标签是十进制数） |
| `@路径` | 字节集槽（`值` = 文件字节的 base64） |
| 裸值（不含 `:`） | 文本槽 |
| `-` / `空` | 空槽 `{"类型标签":0,"值":0}` |

**不复述**：各标签怎么取值（`真`/`假` 归一那类）**只在 `拼值` 一处**，冻结件只指符号。
**已修正一处指向错**：该节原写事实源 `命令行界面.py::拼值`，而 `拼值` 实在 `前端呈现/命令行界面/命令行界面/请求体.py`（`命令行界面.py` 是路由壳，零实现）。

## 五 视觉三维结构：**回退**编辑区的行分隔线（实测推翻原判据）

**原判据（作废）**：「参考图客户区是一张 21px 行距的表 ⇒ 给编辑区补 21px 行分隔线」。
**改前读数**：强边 34898 · 斜面 31884（参考 41320 / 35138）。

**逐像素复核（推翻根据）**：

| 量 | 参考图 | 我方（改前） |
|---|---|---|
| 21px 行线的 x 范围 | **仅 x=318..540**（变量表格区，带 x=318/378/426/462/498/540 六条竖列线 = 一张网格） | x=256..1425（横贯整个编辑区） |
| 主区 x=560..1425 逐行非白占比 | **0%**（一行行线都没有） | 100%（每 21px 一条） |

⇒ 参考图那 21px 行线是**表格控件**的装饰，不是编辑区/画布的。我方主区是 `textarea` 代码编辑区，把表格的行线横贯画上去 = 编出参考图里没有的结构（读数会涨，但那不是对拍）。

**裁决：回退行分隔线**（撤 `.编辑区` 的 `repeating-linear-gradient`）；**保留分带的 3D 刻蚀对**（那部分与参考图同族：每条分带「暗线 + 白高光」一对）。

**改后读数**：见本波回执（`python3 前端呈现/视觉对拍.py` 的强边/斜面两列）。
**如实写清**：强边仍低于参考，而参考图客户区强边里约 9183 落在 x=256..559 的变量表格区，我方那一区是编辑区 ⇒ **结构不同、不是差一块装饰**，这条不追平，属**内容差异**而非「三维结构缺失」。
