# 核心后缀表：制品后缀一律自定义

日期：2026-09-28 ｜ 裁决人：华哥（原话：「支持库的后缀和模块的后缀，不是自定义的吗？……肯定不是用系统级原生的啊。毕竟我们的代码，直接单独解析我们自定义的后缀的就完事了。不然后面每个系统的后缀不同，还要写几个不同的解析器，还更麻烦」「别再搞 `.dylib`/`.so`/`.dll` 了……本质上后缀表，除了 `rs`/`md`/`py` 这种代码文件，但是制品文件，本质上就一定是自定义的。不然，后面会乱个半死。我觉得你应该是要专门做好一个自定义的制品的后缀的统一表。给他一个声明」）

**落点**：`扩展装载/后缀表.json`（**唯一权威**）· 两侧读方 `对外接口面/调用接口面/src/扫扩展根.rs` · `构建装配/上线切换/构建制品/扩展.py`

## 一 裁决：三个核心后缀

| 后缀 | 角色 | 容器 | 谁解析 / 载入 |
|---|---|---|---|
| **`.程序文本`** | 源码（人写 · agent 改） | —（就是文本） | 1101 / 1102 / 1103 |
| **`.支持库制品`** | 支持库制品（`1xxx–6xxx`） | 能力包件（接口说明 `16` + 能力码 `17` + 指纹 `18`） | 底座载入器 |
| **`.模块制品`** | 模块制品（`7xxx`） | 同上三段 | 底座载入器 |
| **`.技能制品`** | 技能制品（`8xxx`） | 能力包件（接口说明 `16` + **技能本体段 `19`** + 指纹 `18`） | 底座载入器 |

**三类扩展是什么**（照易语言的构成核过；逐条见 `扩展装载/后缀表.json`）：

| 种类 | 是什么 | 易语言那边对应什么 |
|---|---|---|
| **支持库** | **最小原子能力**（一个编号一件事）；也可以是一整套体系（一族原子能力） | `.fne`（全树 93 个 · 93/93 导出 `GetNewInf`）：命令表 + 数据类型 + 常量 + 资源（图标等）+ 版本信息 |
| **模块** | **封装 / 组装的原子能力**：用本仓语言写的可复用子程序代码包，导入后像自带命令一样用 | `.ec`：本体是程序文本，发布形态是二进制容器；导入落在使用方工程里，本体留在原处 |
| **技能** | **agent 的用法包**：本体是一份 md，可组装工作流，不含实现 | **易语言没有这一类，是我方新增**（照 agent 的 skill） |

**口径**：后缀是**角色标签** —— 看后缀就知道「这是什么、谁解析它」。**容器格式只有一个**（能力包件），**后缀按种类给**。

## 二 为什么制品后缀必须自定义（华哥的理由）

用系统原生后缀（`.dylib` / `.so` / `.dll`），就是**每个系统一套后缀 + 一套解析器**；我们的代码只认**一个**自定义后缀、只写**一个**解析器，跨系统不变。这与 `能力包件.md` §五「**不用原生共享库当包**」是同一条理由（不跨系统；每个系统一个二进制就是 N 条腿）。

⇒ **`.dylib` / `.so` / `.dll` 从底座的后缀面退休**。代码 / 数据文件的后缀（`.rs` `.md` `.py` `.js` `.json`）不属本表 —— 那是**工具链**的，不是底座定义的。

## 三 `.能力包件` 的地位

**`.能力包件` 是容器格式名，不是文件后缀。** 后缀按种类给：`.支持库制品` / `.模块制品` / `.技能制品`；三者装的都是同一套容器（能力包件）。

## 四 载入面：三个种类 · 一个容器 · 一个 codec

| 项 | 定死 |
|---|---|
| **码段装什么** | 支持库 = **本机机器码**（本体是本机原生实现）· 模块 = **WebAssembly**（本体是 `.程序文本`，由 1106 编译产出）· 技能**没有码段**（本体是 md，装在技能本体段 `19`） |
| **谁解析** | **一个 codec** —— 容器格式只有一个，三个种类都走它；解析出的段按种类各取所需 |
| **`可装载件` 键** | **取消**（华哥 2026-09-28：「口径冲突、不够稳定、或者造成混乱的冲突口径都可以移除掉」）。三个种类都有制品 ⇒ 这个布尔**恒真 = 死键**。扫描面 = **全部 `种类[].目录`** 的每一个直接子目录，找该种类后缀的制品恰好一个 |
| **切面顺序（硬约束）** | 不许先删旧后缀 —— 会把已跑通的运行期热载入打断。顺序：**容器写 → 容器读 → 切扫描面 → 移除旧后缀处理** |

## 五 防回潮

**判据**（按**码位**写，判据自身不落字面）：`U+002E` 紧跟 `dylib` / `so` / `dll` 三者之一 ⇒ 红。另：全仓**不许有第二处后缀表** —— 两个读方都只读 `扩展装载/后缀表.json`，不许自带副本。
