## 一 #14 `POST /接口/声明` 的接线（复核 + 补读数）

**裁定（维持）**：网关**不调**面 —— 两者经**文件系统**解耦。

- 面只写声明根（`声明编写面/声明编写面/落盘.py::新建` / `::覆盖`）；网关只读声明根。
- `POST /接口/声明` 在网关侧维持**结构化「未实现」**（`调用接口面/src/响应.rs::声明未实现`）。
- **不新增跳语言调用腿** —— 那会新增第二条腿（`接口面形状.md` §五 唯一腿）。

**被否决的选项**：① 子进程调 Python 面（每次写声明起一进程，且面成为网关的依赖）；
② 把面重写成 Rust（同一职责两套实现，`开发规范.md` §六 拆件）；
③ 网关内部再实现一遍「读声明根 / 校验 / 落盘」（同一件事第二套实现）；
④ 新增 `POST /接口/导入` 作为第三个转调口（见 §三 #116）。

**读数（本波实测）**：`grep -rn "声明编写面.py\|声明编写面/声明编写面" 对外接口面/调用接口面/` ⇒ **0 命中**（退出码 1）。

## 二 #15 撤回 / 删除路径（裁定已落，源件本波补）

**裁定（维持 · `残留三项裁决.md` §一）**：**面不提供删除**。要停用一条号走**作废登记**（往 `契约声明/作废号表.json`
追加一行五键，含 `号空间`）—— 它是一次**新增**，不是删除（宪法 7「号只增不复用」）。

**为什么不在面里做**：面是**写入面**（一个动作）；删除改的是**已存在的文件**、带**历史语义** ⇒ 让一个面担两种语义。
**为什么不叫「删除」**：号删了**不回收**，本来就不存在「删掉这个号」这个动作，只有「这个号不再使用」。

**本波做了什么**：裁定住在 `决策记录/残留三项裁决.md` §一，而**它指定的落点**
（`接口面形状.md` §四 的旁路区）**当时没写** —— 本波补上（新增一节「面只有写入，没有删除」），
`冻结登记.json` 的旁路**尾部追加**一条（该件是冻结件，新增一节走旁路）。

**读数（本波实测）**：`grep -rn "DELETE" 对外接口面/` ⇒ **0 命中**（退出码 1）。
`grep -rn "删除\|撤回" 对外接口面/调用接口面/src/` ⇒ **1 命中**，但它是**散文注释**
（`对外接口面/调用接口面/src/工具响应_扩展.rs::组列扩展` 里解释「`扩展根` 那个键已从 `扩展根声明.json` 删除」）——
**不是调用路径、不是端点、不新增删除能力**。按实测如实报出，不拿 0 充数。
**反向样本**：给面加 `DELETE /接口/声明` ⇒ 判红。

**连带**：#137（声明编写面没有「作废号」这一路）仍开着 —— 那一条问的是「作废登记要不要也收进面」，
与本条不矛盾（本条只说「不提供删除」），仍留台账。

## 三 #116 agent 的导入口（复核）

**裁定（维持）**：**不新增 `POST /接口/导入`**。agent **直写** `扩展装载/扩展根声明.json`
（把扩展放进对应 `种类[].目录`，并保证该 `种类` 的 `可装载件` 键是布尔）。

**为什么**：① `扩展根声明.json` 本身就是一份文件，agent 写它 = 写文件；再加 HTTP 端点只是给同一件事多开一个门；
② 加端点就是第二条腿（要么网关再实现一遍读写校验，要么跳语言调声明面）；
③ **写文件不需要协议**。

**被否决的选项**：`POST /接口/导入`（递扩展根声明）。

**读数（本波实测）**：`grep -rn "/接口/导入" 对外接口面 前端呈现 运行内核 跨语言适配 契约声明` ⇒ **0 命中**（退出码 1）。

## 五 #122 模块 7xxx 的「流程定义」形状（复核 + 补源件）

**裁定（维持 · `扩展装载与开发标准.md` §3.9）**：`模块声明.json` 里加一个 `流程` 数组，
每项 = `{能力编号, 顺序}`（**两键，没有别的字段**）。**数据流转按 `顺序` 隐式表达**
（上一项的输出即下一项的输入），**不新增「数据流转」字段**。

**为什么**：加「数据流转」就得定「怎么引用上一项的输出槽」（槽号？名字？），而按顺序直连是
**模块 = 组装件**这一形态的题中之义（§3.5 硬边界 1：模块不组合出新原子能力，只把既有能力按顺序串起来）。

**本波做了什么**：裁定在 §3.9，而 §3.1 必备件表 与 `必备件.json` 的模块行**仍写「数据流转」**
（当作独立字段）—— 同一件事两套口径 ⇒ 本波补：两处都改成「数据流转是顺序的隐式后果」。

**读数（本波实测）**：`find . -name "模块声明.json"` ⇒ **0 个**（本仓尚未实现它 —— 本裁决是**先定形状**，
等第一份模块声明落地时照本条写）。
