# 代码地图换 codegraph —— SCIP 那套退场

日期：2026-09-27 ｜ 裁决人：华哥（原话：「那其实用这个就好了吧。**直接下载一个最新版本的下来。到我们底座这**」·
「直接移除掉，替换成 codegraph 不就好了？」）

## 一 裁决

索引器由 **SCIP 那套（四条外部工具）**换成 **`codegraph`（一件）**。本仓**不再自研任何解析** ——
解析归 tree-sitter，落库归索引器，本仓只剩一层**薄读库**。

| 落点 | 换前 | 换后 |
|---|---|---|
| 入口 | `开发工具/代码地图.py`（`建`/`查`/`引用`/`检名`/`状态`，不变） | 同 |
| 模块 | `SCIP前端.py`（353 行）· `建索引.py`（131 行）· `查询.py` · `查名.py` · `落点.py` | **删前两件** · 新增 `索引库.py` · 其余跟着改 |
| 索引产物 | `<运行数据根>/缓存/代码地图/`：`rs.scip` `py.scip` `js.scip` `定义.jsonl` `出现.jsonl` | `<仓根>/.codegraph/codegraph.db`（**索引器自带的库，一份**） |

## 二 为什么换（都是读数）

| 问 | SCIP 那套 | codegraph |
|---|---|---|
| 外部工具 | **4 件**：`rust-analyzer` · `scip-python` · `scip-typescript` · `scip` | **1 件**：`npm i -g @colbymchenry/codegraph` |
| 冷构建 | **12.3 s**（三条腿并发：rs 4.6 · py 12.9 · js 1.4） | **1.0–1.4 s**（560 件 / 6457 节点 / 16306 边） |
| 查（含 Python 启动） | 109 ms | **58–96 ms** |
| 自研解析代码 | 353 行前端（调三条腿 + 读回 protobuf + 转形状）＋ 131 行编排 | **0 行** |
| 落点 | 运行数据根（判据 ⑳ 口径最干净） | **源码树** `.codegraph/`（★ 唯一的代价，见 §三） |
| 引用面 | 编译器级（rust-analyzer / scip-python / scip-typescript） | tree-sitter 级（**少约 7%**，见 §三） |

**归队，不是新发明**：老仓本来就是 codegraph（`<项目根>/.codegraph/codegraph.db`，
nodes 10896 · edges 22788 · files 564 —— 见 `2026-09-27_代码地图.md` §二末）。V1 当初选 SCIP 是**偏离**了老仓，
这次是**归队**。华哥原话「底座用的那个，他那个好像也是 github 下载下来的吧」—— 记的正是这件事。

**旧的四件已卸**（2026-09-27 同日实测）：`npm uninstall -g @sourcegraph/scip-python @sourcegraph/scip-typescript`
（47 个包）＋ `rm ~/.local/bin/scip`。**`rust-analyzer` 留着** —— 它是 Rust 的**语言服务器**，
不是「只为出 SCIP 而生」；把它卸了等于卸掉 Rust 的编辑能力。
卸完复跑：`建` 6423 节点 · `查` 命中 1 · `检名` 两档 0 · 闸 0 退出码 0（都不受影响）。

## 三 ★ 代价（这一条必须记住）

**引用面少约 7%**。实测方法：拿 SCIP 索引与 codegraph 库**同一份源码**上比对 ——
取两边都恰好定义一次的符号 3814 个，随机抽 400 个，剔掉注释行后比「代码行出现位」：

| | 编译器索引（SCIP） | codegraph | 覆盖 |
|---|---|---|---|
| 400 个符号的代码行出现位 | 634 | 592 | **93%** |

缺的是这四类（逐条有实测样本）：

| 类别 | 实测样本 |
|---|---|
| `match` 模式里的枚举变体 | `版本 \| 支持库 \| … \| 子程序` |
| 路径表达式 | `行类::子程序` · `形状错误::新(…)` |
| 方法调用 | `.取文本()` · `.and_then(协议值::取文本)` |
| 常量用在条件 / 字段初始化里 | `if !底座宿主版本.满足(…)` · `实际: 底座宿主版本.主` |

**漏是静默的**：codegraph 自带的 `unresolved_refs`（15489 条）兜不住这几类 ——
实测漏的那几处**一条都不在里面**（它只记带点的 `calls`，如 `底座宿主版本.满足`）。

**影响**：`v1_symbol`（浏览：谁定义了它 / 它还在哪被用）够用；**`v1_replace`（符号级改名）不够** ——
改名会漏改这 7%，改完编译不过。故口径改成：**改完必须跑 `门禁` 编译**，编译红就是「索引漏了几处」，
用 `rg` 按词边界复核后手改。这条已写进 `工具.py` 的工具描述与 `索引库.py` 顶部。

（另：SCIP 把**文档注释里的提及**也算出现位，实测 `运行内核/装载入口/src/判定.rs::底座宿主版本`
那处给出的第一个位置是它的 `///` 注释行 —— 它那面是**超集**，
所以旧 `替换` 会顺手改注释；codegraph 不数注释，这一点反而更贴「只动代码」。）

## 四 顺带修掉一个潜伏 bug：列的口径

旧 `工具.py::_按列换` 按 **UTF-16** 算（`起始列 * 2`），注释写着「SCIP 的 `position_encoding` 是 utf-16」。
**实测 SCIP 给的是 UTF-8 字节偏移**：`use super::零件::{摘要一行, 校输入形状, …}` 这行，
`校输入形状` 的字符下标 **22**、SCIP 报 **34**；`let 输入槽表 = match 校输入形状(…)` 那行，
字符下标 **25**、SCIP 报 **33**（34/33 正是 UTF-8 字节数）。
⇒ **含中文的行一律切错 ⇒ fail-closed 拒绝整批**（没写坏过，因为它是 fail-closed，但一直改不动）。

codegraph 的 `edges.col` **就是字符下标**（同一行报 22 / 25）⇒ 换过来顺手修掉：
`_按列换` 改成普通 Python 切片。
**验证**：`v1_replace` 把 `校输入形状 → 校验输入形状` 真写盘 —— **3 处全改到**（导入 · 调用 · 定义），
`cargo build --workspace` 退出码 **0**。（验证后已 `git checkout` 回退，那次改名不是任务。）

## 五 面的变化（`检名` 的读数要重挂基线）

定义面：SCIP **10385** 条 → codegraph **3973** 条（已剔 `file` 与 `import`）。
**codegraph 不索引 Rust 的函数参数与多数局部变量**（`variable` 只剩 1146 条）⇒ 面**变小**了。

| 档 | 换前 | 换后 | 说明 |
|---|---|---|---|
| 序数代称（**判**） | 0 | **0** | 判据 ㉒ 的对照要求：两套读数一致 |
| 西文单字母（**判**） | 0 | **0** | 同上 |
| 无义单字（读数） | 54 | **16** | 面变小，不是违规变少 |
| 西文（读数） | 1673 | **313** | 同上（旧读数里 359 条是语言强加的，本来就不该在） |

**判的两档没动** —— 这是台账 #225 的对照条件；读数两档下降是**面**变了，不是东西没了。

## 六 判据面的边界（不变）

代码地图**仍不是判据**（它随环境飘：装了 `codegraph` 才有读数）⇒ `构建装配/一键验证/` 里 **0 处**调它。
**规则仍只此一份**：命名口径在 `开发工具/代码地图/查名.py`，判据 ㉒ 也 import 它；
判据 ㉒ 那一侧的**面**仍是零依赖剥器（它要在合成仓上跑，而索引是整仓产出的）。台账 #225 未变。

## 七 五秒硬顶的归属

| 命令 | 归属 | 实测 |
|---|---|---|
| `建` | **环境步**（`报告环境步` 照实报、**不判顶**；**不设超时**） | 1.0–1.4 s |
| `查` / `引用` / `状态` / `检名` | **判顶对象**（`自门禁`） | 58–96 ms |

★ **实测撞过一次**：先写了 `建库超时秒 = 300`，判据 ㊲ 当场红 ——
「环境步也不许配一个 >5 秒的容忍度」（`2026-09-27_MCP适配层.md` §七）。
改成**不设超时**（与仓里 `cargo` / `nm` / 闸 0 起子进程同一口径）。

## 八 源码树里多了一个二进制库（这条代价已认）

`codegraph` 写死要落在工程目录下 ⇒ `<仓根>/.codegraph/`（sqlite，20 MB）**在源码树里**。已认，理由：

1. 判据 ⑳ 的禁名表是 `("数据库", "缓存", "日志", "临时件")` ⇒ `.codegraph` 不在其中，**判据照绿**（实测）；
2. `.gitignore` 忽略它（本机产物，不进版本库）；
3. 它**只由件内容决定，随时可重建**：`python3 开发工具/代码地图.py 建`（实测 1.0 s）；
4. 老仓同形（`<项目根>/.codegraph/`）⇒ 不是本仓开的新头。
