# 导出目标：同一套编译流程，五种出口

上级：`README.md`（宪法 · 号段）／ 落点：`项目文档/设计文档/导出目标.md`
相关：`扩展装载与开发标准.md`（三层扩展）· `代码形态分工.md`（各层形态）· `上线切换/形状.md`（制品）

**一句话**：agent 只填**声明 + 最小代码**，其余（接缝 · 装配 · 编号 · 错误码 · 留痕）全由底座出 ⇒ 产物规范，**不漂移**。

---

## 一 为什么需要它

现在 agent 写代码**五花八门**：同一个业务能力，两次写出来不一样，没有判据能拦。
根因不是 agent 不行，是**没人给它一条「只能这么写」的路**。

底座给这条路：能力先变成**声明**（编号 · 参数行序 · 返回类型 · 可抛错误码），
agent 只写「这个能力做什么」的那几行，剩下全由底座生成。**写不出来的地方，就是漂移不了的地方。**

## 二 五种出口

| 导出目标 | 产物形态 | 类比易语言 | 号段 | 现状 |
|---|---|---|---|---|
| **案例** | 可跑的 demo + 运行回执 | `.e` 源码 | — | 已有（`测试验证/案例/`，5 案例 + 回执绑提交哈希） |
| **支持库** | 动态库，出接缝 `GetPlatformInfo` | `.fne` | `1xxx–6xxx` | 已有（`构建装配/上线切换/`） |
| **模块** | 组合件，复用底座能力、不直连第三方 | `.ec` | `7xxx` | 声明已定，**出口未通** |
| **技能** | **一份 md 描述**（怎么用底座能力做事），不含实现 | 无对应 | `8xxx` | 声明已定，**出口未通** |
| **制品** | 可执行交付件，**agent 可当 skill 直接调** | 编译出的 `.exe` | — | 已有（`制品产物/` + 装载/切换/回退） |

**制品对 agent 的意义**：它就是一个**规范的 skill** —— agent 调它，不用自己写代码。
比现在的 agent skill 强在**有判据**：编号、参数、返回、错误码都是声明出来的，调错会当场报码，不会静默漂。

## 三 三条链

```
① 案例链（要「跑起来看」）
   声明 + 最小代码 ─→ 测试验证/案例/跑案例 ─→ 运行回执.jsonl（绑提交哈希）

② 模块链（agent 自己开发业务封装）
   现成业务能力
        ↓ agent 写「声明 + 最小代码」（复用底座，不重写）
   扩展根目录/组合模块库/（7xxx）
        ↓ 再调底座
   制品

③ 制品链（要「交付出去」）
   扩展根目录/<层>/ ─→ 构建装配/上线切换/构建制品.py ─→ 制品产物/<提交12位>-<指纹16位>/
                                                              ↓ 装载 / 切换 / 回退
                                                          对外接口面/（四端点）
```

三条链**共用一个前端**：`前端呈现/网页应用/`。差别只在**导出目标**这一个选择。

## 四 落点

| 要什么 | 落在哪 | 现状 |
|---|---|---|
| 导出目标这个选择 | 声明里的一个字段 | **缺**（现在是手写 `#[unsafe(export_name)]`，见 §五） |
| agent 导入模块库 / 支持库 / 技能 | — | **缺**（`扩展装载与开发标准.md` 里「导入」零命中） |
| agent 导出 / 下载技能（`8xxx`） | `技能/` 目录 | **缺**（§三 形态已定：一份 md 描述，出口未通） |
| agent 导出制品 | `构建装配/上线切换/构建制品.py` | 半有（只有 CLI，没有 agent 能调的面） |
| agent 调制品 | `上线切换`（装载/切换/回退）+ `对外接口面/` 四端点 | 已有 |
| 前端选出口 | `前端呈现/网页应用/` | 有「编译」「案例库」「支持库」面板，**无「导出目标」选择** |

## 五 手写导出属性是一个已发生的缺陷

`扩展根目录/原子支持库/编译器支持库/src/lib.rs::取平台信息` 现在手写：

```rust
#[unsafe(export_name = "GetPlatformInfo")]
```

`运行内核/装载入口/src/底座静态声明.rs::取平台信息` 也手写过同一个 —— 同二进制里**只解析得到一个**，
底座拿自己的声明做身份自检时比对到扩展那份，**恒假**，`装载(底座声明())` 报 `载入(标识串非法)`。
2026-09-27 已去掉底座侧那个（见 决策记录 §二 裁决 6）。

**根因**：导出这件事**没有声明**，谁都能手写一遍，写重了没人拦。
**正解**：把「导出目标」变成声明字段，由生成器出接缝 —— 手写属性消失，这类缺陷从根上没了。

## 六 不漂移靠什么（四道闸，不靠自觉）

| 闸 | 拦什么 |
|---|---|
| 声明即编号 | 编号由声明定，不是 agent 随手写；重号 / 越号段当场拒 |
| 参数行序即契约 | 参数顺序错了判据能抓 |
| 生成物禁手改 | 派生物（`声明数据.rs` 等）第 1 行盖章，改了下次生成就没了 |
| 生成物指纹 | 源变了生成物没重跑 ⇒ 指纹对不上 |
