# 代码形态分工

上级：系统工程平台 V1 ／ 落点：`项目文档/设计文档/代码形态分工.md`
相关：`语言选型对照.md`（逐语言优劣）· `内核落点.md`（内核定案 Rust）· `多语言兼容实现.md`

**原则**：没有「统一语言」，只有**每个落点用它最擅长的形态**。

**判据不是「这是哪个节点」，而是「这个落点的诉求是什么」**——它最怕什么（怕漂移？怕慢？怕改不动？怕不可读？），就选最不怕它的那个形态。

**★ 同一个节点里可以并存多种形态。** 判据是：**两个部分的最怕点是否不同**——不同就可以用不同形态，哪怕它们在同一个目录里。比如同一个前端里：UI 壳怕迭代慢 ⇒ TypeScript；渲染热点怕帧率 ⇒ 编译到 WebAssembly 的那份；配置怕人读不懂 ⇒ JSON；构建入口怕起不来 ⇒ shell。**四种形态，一个节点，各有各的诉求。**

反过来，**两个部分在做同一件事，就不许有两种形态**（见第五节硬判据 1）。

## 一 分工表（**树上每一个落点都在这**）

**判据不是「这是哪个节点」，而是「这个落点的诉求是什么」**——它最怕什么（怕漂移？怕慢？怕改不动？怕不可读？），就选最不怕它的那个形态。

**★ 完备性判据**：本表必须覆盖 `README.md` 第五节目录树里的**每一个**落点。**树上多一个落点、表里少一行，就是违规**——漏掉的落点会被随手选一个形态，而随手选的形态必然漂移。

### 1 声明与数据

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `契约声明/`（`平台声明.json` · `号段图.json` · `常量表.json` · `能力声明/` · `类型声明/` · `错误码表/` · `通知号段/` · `作废号表.json` · `冻结登记.json`） | **JSON** | 漂移 | 无编译、无运行时、无版本；任何语言都能读；由生成器 + 验证面兜住 |
| `契约声明/` 的编译期常量 | **Rust 常量（生成物）** | 手改漂移 | 它是生成物，改源不改它；有指纹闸 |
| `扩展装载/载入约定/` · `开发标准/` · `扩展根声明.json` | **JSON（数据）** | 判据与实现不同源 | 数据能被验证面直接读；判据就是数据 |
| `跨语言适配/边界协议/` | **数据 + 文档**（符号名与槽结构**就是**形状） | 边界漂移 | 形状是符号名与定长槽，不是代码；写成代码反而多一层要同步 |
| `只读参考/` | **数据，零代码** | 被引用 | 禁 import；它只做参照 |
| `项目文档/` 的 `设计文档/` · `开发规范/` · `决策记录/` | **Markdown** | 漂移 | 本仓的文档就是唯一事实源；改文档比改代码快。**判据与规范住在文档里，不住在代码注释里**——注释会被重构带走，文档不会 |

### 2 运行态（在关键路径上，最怕漂移与不可预测停顿）

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `运行内核/` 8 个 crate（`装载入口` · `统一注册表` · `定长数据槽` · `内存分配器` · `通知通道` · `实例状态` · `调用调度` · `调用留痕`） | **Rust** | 漂移 + 停顿 | `repr(C)` 显式 · `Result` 不可忽略 · 无 GC · 无隐式转换 |
| `跨语言适配/适配器实现/` | **Rust** | 漂移 + 停顿 | 全平台唯一的跨边界收口，在关键路径上 |
| `跨语言适配/资源网关口/` | **Rust** | **被绕过 + 停顿** | 它要执行超时 · 配额 · 拒绝 · 留痕，且**必须挡在关键路径上**——Python 做不到确定性，也容易被绕过 |
| `对外接口面/调用接口面/` | **Rust**（`std::net` 手写 HTTP） | 停顿 + 协议层混入业务判断 | 在关键路径上；零第三方依赖 |

### 3 生成物（禁手写）

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `跨语言适配/语言绑定/` | **生成物**（由 `契约声明/` 生成） | 手写必漂 | 各语言各取所需；不手写就不漂 |
| `构建装配/制品产物/` | **生成物**（二进制 + 说明） | 手改 | 禁手改，要改改源 |
| 一切汇总表 / 索引 / 指纹 / 完整性摘要 | **生成物**（落 `构建装配/制品产物/`，或文件头标 `生成物`） | 手改 | 同上 |
| `编译产物`（`.能力包件`） | **容器（段头 + 段类型号）+ WASM 码段** | 不跨系统 | WASM 是所有系统都有载入器的唯一字节码（见 `能力包件.md`） |
| `原生源格式`（`.程序文本`） | **可读文本**（UTF-8 行式） | 人/agent 读不了、改不动 | 它是「用户能看到、能手动编辑」的直接落点（见 `程序文本格式.md`） |

### 4 不进制品（可用便利换开发速度）

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `构建装配/形态装配/`（声明生成器） | **Python（仅标准库）** | 改规则要重编译 | 不进制品；改完直接跑 |
| `构建装配/一键验证/`（闸 2） | **Python（仅标准库）** | 同上 + 要秒级 | `json` / `concurrent.futures` 现成；32 核并发一行搞定 |
| `对外接口面/声明编写面/`（校验器） | **数据 + Python 校验** | 改校验规则要快 | 面只做结构校验，不做业务 |
| `测试验证/契约一致性/` | **Python（仅标准库）** | 要扫源码**而不编译** | 纯静态解析；不启动进程、不编译 |
| `测试验证/端到端测试/` | **Python** | 要真跑通整链 | 复用接口面的 HTTP 面（起服务 + 发请求） |
| `开发工具/` | **Python（仅标准库）** | 不参与运行、不进制品 | 便利换速度；它与内核的边界由「不许被内核 import」守住 |

### 5 测试（**不许另立一套**）

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `测试验证/单元测试/` | **各 crate 自带的 `#[cfg(test)]`**（Rust） | 与被测不同生共死 | **就地测**：测试与实现同文件、同一次编译、同一批改动。**不另立一个测试节点去重复测一遍**——那是两条腿 |
| （Python 侧单元测试） | **各模块自带 `--自测` 档**（Python） | 同上 | 同形做法：`一键验证.py --自测`、`生成声明.py --检查` |

**注意**：`测试验证/单元测试/` 这个目录**不是**「放测试代码的地方」，而是「记录哪些节点自带单元测试」的索引位。测试代码**跟着实现走**（Rust 的 `#[cfg(test)]`、Python 的 `--自测`），不搬到这个目录来。搬过来就要跨目录同步，那就是两条腿。

### 6 胶水（只做第一步，逻辑一律进上层）

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `构建环境/进入.sh` · `自检.sh` | **shell（sh）** | 任何机器都要能起 | 无依赖；它必须是「第一步」 |
| `构建环境/` 里的生成物（`构建缓存/` · `cargo/` · `python/`） | **生成物，不进版本库** | 被当成源 | `.gitignore` 挡住；它只是缓存 |
| `.cargo/config.toml` · `rust-toolchain.toml` · `Cargo.toml` · `Cargo.lock` | **配置（TOML）** | 环境漂移 | 钉工具链 · 钉产物落点 · 钉离线；改这里 = 改环境 |
| `构建装配/上线切换/` | **shell（只做胶水）** | 起不来 | 同上 |
| `前端呈现/命令行界面/` | **shell（胶水）+ 调接口面的 HTTP** | 再造一套逻辑 | CLI 只是 HTTP 客户端的壳；**逻辑一律在接口面**，CLI 里 0 处判断 |

### 7 前端（纯 UI，零逻辑）

| 落点 | 形态 | 最怕什么 | 为什么这个形态最不怕 |
|---|---|---|---|
| `前端呈现/网页应用/` | **无构建步骤的原生 ES 模块**（HTML + CSS + JS，接口面同源托管） | **多一条构建链就多一处漂移** | 零工具链、零依赖、零锁文件 ⇒ 没有构建链可以漂移；改完刷新即生效 |
| `前端呈现/桌面应用/` | **同一个网页应用 + 一个壳**（不重写 UI） | 两套 UI 就是两条腿 | 桌面壳只是「换个窗口装同一个网页」；重写一套 UI 就是第二条腿 |
| （前端渲染热点，将来若真出现） | **编译到 WASM 的那份** | 帧率 | 只对热点用，不把整站搬过去 |

|---|---|---|---|

## 一之二 三条例外（工具链强制，不算「选择」）

| 例外 | 谁强制 |
|---|---|
| Cargo 包名必须 ASCII | cargo 只接受 `[A-Za-z0-9_-]` |
| shell **标识符一律 ASCII**（变量名 · 函数名 · heredoc 定界符） | `sh` / `bash` 不认非 ASCII 标识符。**实测三种变体**：① 函数名 `用法() {` ⇒ `` `用法': not a valid identifier `` ② 变量赋值 `腿=x` ⇒ `` 腿=x: command not found `` ③ **变量展开后紧跟中文字符** ⇒ `"$leg（分支"` 被当成变量名的一部分、展开成乱码（须写 `"${leg}（分支"`）。三条都是我在同一个脚本里先后撞到的——**文档原来只写了「变量名」，漏了后两条** |
| 导出的 ABI 符号用 ASCII | 它是外部协议边界，别的语言要按名字绑 |
| **Rust 模块要用 `#[path = "中文名.rs"]`** | rustc 拒绝自动加载非 ASCII 文件名的模块（`E0754`）。文件名仍用中文，只在 `mod` 声明处显式写出路径 |
| **非 ASCII 文件扩展名（若某个工具链不接受）** | 例如打包器 / 某语言的文件识别。**登记成例外，不许为此改回英文扩展名** |

**其余标识符一律中文**（变量 · 函数 · 类型 · 目录 · 文件）。

## 二 为什么不是「全 Rust」

全 Rust 会把三件事做坏：

1. **声明数据被写死进代码**。声明是数据，写成 Rust 源码就等于「要改声明得重编译」——而声明是给面、给验证面、给别的语言读的。
2. **验证面变得又慢又难改**。判据是会被反复改的东西，改一次重编译一次，是纯浪费；而 Python 改完直接跑。
3. **脚本变重**。环境入口必须是「任何机器都能起的第一步」，Rust 需要先有工具链，鸡生蛋。

**为什么 UI 壳不用 Vue/TypeScript**（这一条是按判据改过的，不是随手选）：第一节那条判据问的是「**这个落点最怕什么**」。UI 壳是纯 UI、非主线，它最怕的不是「迭代慢」，是**多一条构建链就多一处漂移**——`node_modules`、锁文件、构建产物版本，每一样都要另立一套「环境」，而本仓的环境纪律是**只有两个环境、装在一个文件夹里**（第四节）。原生 ES 模块没有构建步骤，诉求匹配得更准。将来若真出现「非 Vue 不可」的界面复杂度，那是一个**新的落点**，按判据单独评估，不是现在替它先交学费。

**反过来，为什么内核不能是 Python**：内核最怕漂移与不可预测停顿，而这两条正是动态语言的软肋。

## 四 两个环境，一个文件夹

| 环境 | 钉什么 | 落点 |
|---|---|---|
| **Rust** | `rust-toolchain.toml` 钉版本 · 零第三方依赖 · 离线 · 产物只落 `构建环境/构建缓存/` | `构建环境/进入.sh` |
| **Python** | 仓库内 venv · **只用标准库** · 版本与 Rust 一同在自检里核 | `构建环境/python/` |

**只有这两个环境。** 任何新形态若要引入第三个工具链（node / jdk / go toolchain …），先按第一节判据回答「这个落点最怕什么」，再连带回答「为什么不能用已有两个环境里的一个」——答不出来就不许引入。

判据：**任何一个环境缺了或版本不对，自检立刻红。** 不许「碰巧能跑」——碰巧能跑是漂移的另一种形式。

## 五 硬判据

1. **同一件事不许有两种形态。** 判据是**职责**不是节点：两个部分在做同一件事却用了两种形态，即为缺陷（这是「不保留旧腿」在多语言下的形态）。**不同诉求的部分用不同形态是正常的，不是违规。**
1b. **形态的选择要能说出诉求。** 说不出「这个落点最怕什么」就说明形态是随手选的——随手选的形态必然漂移。
2. **形态边界要能机器判定**：内核 crate 里出现 Python 调用、或开发工具里出现 Rust 编译依赖，都是违规。
3. **不进制品的形态不受制品约束**：Python 工具不进 `构建装配/制品产物/`，所以它可以用标准库的便利换开发速度。
4. **进制品的形态必须零第三方依赖**：Rust crate 一律只用 `std`。
