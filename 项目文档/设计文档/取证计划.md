## §1 对照样本：同一程序改一处

### 1.1 要什么
**一对真 `.e`（或 `.ec`）**：同一程序、**只改一处**（改一个可读的名字，或一个常量值，或加一条语句），两版都必须是参照实现产出的真容器。
形态是**一条能指认的规则**：「改哪一处 → 哪一段字节动」。不是「一个数」，也不是「一张表」。

### 1.2 从哪取
- **首选（不需人）**：在**扩充后的语料**里扫。入口 = `/tmp/易语言源码/`（1444 件）**＋** §5 从 85 个 `help/*.chm` 解出的 1743 件；做法 = 按 basename 分组 → 逐字节 `cmp` → 只留「差异字节数少、且差异集中在少数区间」的成对件。
  - **实测（读数 R3，退出码 0）**：现有 1444 件里 **0 对**「改一处」样本 —— 同名近量级（差 <2%）只有 3 对，最小一对（`俄罗斯方块.e`）逐字节仍差 **73220** 字节 ⇒ **不是**「改一处」。
  - ⇒ 需在 §5 扩充后的语料上**重跑同一条扫描**（入口与命令见 R3）。
- **次选（需人）**：**需华哥提供：同一程序的改前 / 改后两份真 `.e`（只改一处，如某变量名 `参中字节`→`令牌类别`，或某常量值 `1`→`2`）。**
- **已封死的路**：跑参照实现看输出 —— 本项目硬约束「黑盒不许运行」，**指不出**任何合规的替代入口。

### 1.3 取到之后怎么判（逐条比，照对照表已用的口径）
1. 两版各跑 `python3 开发工具/取证/声明记录区反解.py --样本 <每份>`，两版都必须**解析出程序段**（退出码 0）；
2. 逐字节 `cmp` 出**差异区间**；
3. 把差异区间与 `声明记录区实测.md` §三 的「记录级可证」切分对齐：
   - 差异**只落在某一张表的记录上**（例如只有串记录动）⇒ 那张表的边界被指认 ⇒ **闭分区边界**；
   - 差异落在令牌的 `号`/`参中字节`/`令牌类别` 上 ⇒ 该字段语义被指认 ⇒ **闭令牌语义**；
4. **可证伪**：若两次不同改动动到同一段，假设当场推翻 ⇒ 判「不成立」。
- 对得上 → 闭；对不上 → 写明**差在哪**（差在粒度、差在位置、还是差在「样本本身不是改一处」）。

### 1.4 现在就能跑的读数（已跑）

**实得（退出码 0）**：同名件组 **19** 组 · 候选对 **31** 对；再按「差 <2%」过滤只剩 **3 对**；逐字节 `cmp` 最小一对差 **73220** 字节。
⇒ **分区边界与令牌语义现在「未判」**（**没有**对照样本，**不是**「取不到」—— 扩充语料后可重跑，或由华哥给样本）。

## §3 e.exe 静态逆向：语句操作码表

### 3.1 要什么
**一张表**：语句字节码的**完整操作码表** —— 哪些字节是操作码、每个操作码后跟几个字节、什么类型（操作数宽度表）。
现状（`声明记录区实测.md` §二 形状 2 / §七 待办 4）：只实测到 `37 1A` / `37 18` + u32 长度 + 文本；其余字节（`36 1D` · `36 21` · `38` · `39 xx` · `16` · `52`）**只知「出现过」，无宽度表**。

### 3.2 从哪取
- **主路（不需人，但要工具与工时）**：**静态逆向参照实现二进制**。参照实现的编译器 / IDE 在 `/tmp/易语言源码/e.exe`（3,345,920 B，`coff-i386`）与 `/tmp/易语言源码/tools/link.dll`（`coff-i386`）。
  - 入口（**已实测可用**）：`objdump -f /tmp/易语言源码/e.exe`（退出码 0）⇒ 可 `objdump -d` 反汇编、可 `nm` 看符号。
  - 做法：以**已实测的 6 个操作码**（`0x37 0x36 0x38 0x39 0x16 0x52`）为锚，在 `.rdata`/`.data` 里找**以它们为下标的表**（每项 = 操作码 → 处理函数地址 / 操作数宽度）；找到即得**完整**表。
  - **已排除的伪入口（实测，避免重走）**：
    - `sdk/cpp/elib/`（EDK 头）里**没有**容器/操作码定义 —— `lang.h` 仅 20 行、`container.h` 是 MFC 宏（`grep -i opcode|操作码` 0 命中）；
    - 老仓调研件 `｜-易程序容器格式.md` **不比本文多出任何字节**（`声明记录区实测.md` §十一.2（3）逐字节表：交集 `37 1A/36 1D/38/39/52/16`，老仓**无** `36 21`/`37 18`，且老仓自列「完整指令集未证实」）⇒ 老仓**闭不了**此项；

- **辅路（不需人、便宜、只能加固不能全闭）**：§5 扩语料后重跑操作码普查 —— 能扩宽「出现过」的字节集与宽度线索，但**归纳不出「完整」**。

### 3.3 取到之后怎么判
- 逆向得到表 ⇒ 逐条比：表里每个操作码的**宽度**必须能解释实测字节流（拿 `第一个程序.e` / `超级按钮.e` 的尾部语句区做逐字节回放：按表走一遍，必须不越界、且落在记录边界上）。全过 ⇒ **闭操作码表**；对不上 ⇒ 写明**差在哪几个操作码**。
- 仅靠辅路 ⇒ 只能写「又多了 N 个操作码样本」，**不许**写「操作码表已闭」。
