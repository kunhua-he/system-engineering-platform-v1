## 一 三条根

这三条是其余一切原则的来源。与宪法冲突时改原则，不改宪法。

### 根一 · 核心只放唯一物

**唯一物 = 全平台恰好一个、且换掉它所有调用方都得改的东西。**（适配器 · 连接器 · 注册表 · 分配器 · 槽 · 通知通道 · 留痕汇 · 装载入口 · 契约源）

唯一物不承载业务，只承载**机制**；机制不随业务变 ⇒ 它的语义天然稳定。
**核心不是「写得稳」，是「里面只有唯一物」。**

**入核五问**（新节点入核前五问必须全过；任一指向外围，它就必须留在外围）：
① 全平台恰好一个？ ② 换掉所有调用方要改？ ③ 认识任何**具体**的扩展/能力/语言/格式/域？ ④ 做「这种情况怎么办」的判断？ ⑤ 裁掉它平台是「某个功能没了」还是「不成立」？

**老仓的病根正是这三类非唯一物进了核心**：策略（做判断）· 通用工具（谁都能用）· 某一版实现的细节（实现一变契约跟动）。

### 根二 · 一切变化赶到外围

新能力 · 新语言 · 新契约版本 · 新扩展 —— **四类变化都不许碰内核**：

- 新能力 = 加扩展 + 加声明（底座不认识任何扩展）；
- 新语言 = 接同一个适配器，绑定由契约生成；
- 新版本 = **号不复用** + 未命中返回空 + 三种旁路演进；
- 新部署形态 = 编排器那一层的事。

**判据（可数）**：加一个能力，使用角色**零改动**即可调到它。

### 根三 · 判据优先于代码

**规则没有判据就是纸。** 一条纪律如果只能靠人记，它一定会漂；漂了没人拦 ⇒ 修不完。
**最高判据**见 `项目文档/设计文档/判据的可信性.md`（三元读数 · 反向样本是判据的身份证 · 元判据）。

**禁止**：不许声称一个不存在的判据（实测教训：`自检.sh` 曾被声称「查控制台」，实测不查）。

## 二 由三条根推出的原则

| 原则 | 一句话 | 来源 |
|---|---|---|
| **一劳永逸六条** | 内核不天天修 = ①核心只放唯一物 ②每个唯一物有唯一主人 ③**边界表达力足够** ④规则有判据（纸面=0）⑤号不复用+标识符不可变 ⑥冻结边界内部自由；**其中 ③ 是唯一的外部风险** | 根一 + 根二 |
| **冻结边界、内部自由** | 冻结的不是实现，是别人已经依赖的形状；**内部实现可以随时改**（改内部不要求旁路登记，改边界才要求） | 根一 |
| **号不复用 + 已发布标识符不可变** | 号删了作废不回收；标识符一旦公布，含义永不改写（要改就新建一个号，旧号进 `作废号表.json`） | 根二 |
| **一个原语** | 跨边界只有一条路（定长槽 + 按号取用 + 未命中返回空）；**每新增一个原语都是永久承诺**，抵抗新增 | 根一 |
| **机制与策略分离** | 核心给机制，不给策略；「这种情况怎么办」一律在外围 | 根一 |
| **不产生第二条腿** | 同一件事只许一处实现；被取代的旧实现直接删（不保留兼容壳 / 旧名别名） | 根一 + 根三 |
| **标识符表达角色** | 命名要说清「它是什么」，不是「它在第几个」；**停用序数代称**（序数代称字）；无义单字名（西文单字母 · `出`/`加` 这类泛指动词）改完整名；确需序号时用**阿拉伯数字后缀挂在角色名后**（`参数2`）或**位置词**（`首/次` · `前段/后段` · `左值/右值`） | `2026-09-27_命名规范.md` |
| **写为什么，不写现在是什么** | 设计文档写「为什么」；「现在是什么」由判据/代码回答（复述必漂） | `项目文档/哲学.md` §三 |
| **精炼第一** | 返回与落盘，能一句说完就不写三句；删掉这句读的人会做错事吗？不会 ⇒ 删 | `项目文档/哲学.md` §一 |

## 三 强制台账（四态；**目标 = 0 个 ⚠️**）

口径照老仓《哲学总账》，四态**永不共用一个词**：

- **✅ 机器强制**：有判据**且**被必经路径（案例门禁 / 一键验证 / 编译期）真实调用
- **🟡 半强制**：有判据，但门禁未接线 / 只报告不阻断
- **🔵 人工强制**：无机器判据，但有**明确**的强制者（须写明是谁）
- **⚠️ 纸面规则**：既无判据也无人工强制点 —— **这是本台账要消灭的东西**

| 原则 / 宪法条 | 强制点 | 状态 |
|---|---|---|
| 一个唯一入口（宪法 1） | 判据⑪ 唯一腿 · 唯一监听 · 拓扑相邻表 | ✅ |
| 一份静态契约清单（宪法 2） | 生成物 + 判据⑩ | ✅ |
| 定长槽 + 类型标签在槽内（宪法 3） | 类型 + 案例「空槽」判据 | ✅ |
| 所有权单向（宪法 4） | 类型 + 判据⑪-2a（`平台_释放值`）+ 归还槽值 | ✅ |
| 双向通知通道（宪法 5） | 生命周期样本（3 条反向样本） | 🟡（通知口已接，端到端未跑） |
| 按号取用、未命中返回空（宪法 6） | 统一注册表占位项 + 案例「空槽」 | ✅ |
| 号段只增不复用（宪法 7） | 作废号表 + `声明校验.rs::判不与作废号冲突` | 🟡（段相交口径 · 三空间无门） |
| 一套源码多形态（宪法 8） | 形态装配 + 构建指纹 | 🟡 |
| 语言不是边界（宪法 9） | 判据⑪（适配器唯一） | ✅ |
| 底座不认识任何扩展 | **判据⑯** | ✅ |
| 核心只放唯一物 | **无判据**（入核五问未立判据） | ⚠️ |
| 冻结边界、内部自由 | **无判据**（改内部无需登记这条没有判据） | ⚠️ |
| 号不复用 + 标识符不可变 | 仅错误码有（裁决二）；能力号/通知号/类型标签/段类型号/命令编号**无通则判据** | ⚠️ |

## 四 怎么用

1. **每问「这个能不能进核心」** ⇒ 先过入核五问（根一）。
2. **每问「内核要不要改」** ⇒ 先问「变化能不能赶到外围」（根二）。
3. **每立一条纪律** ⇒ 同时给判据，或写明谁在人工强制；**给不出就写进台账的 ⚠️，不许当它已成立**。
4. **每次收口** ⇒ 读一遍 §三，⚠️ 只许减少。
