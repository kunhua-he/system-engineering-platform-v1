# ZIP归档支持库

ZIP字节归档：列出成员、读取指定成员和生成单成员归档；不写文件系统，不接受绝对成员路径或上跳路径；最多1000成员，压缩输入输出65536字节，成员实际解压65536字节；支持Stored和Deflate，拒绝损坏或不可支持的加密。

- 3401 列出成员：归档字节 → 类型标签100。
- 3402 读取成员：归档字节、成员路径 → 类型标签5。
- 3403 生成单成员：成员路径、成员内容 → 类型标签5。

调用经唯一HTTP能力入口；必须与本包声明的参数行序一致。纯CPU或网络I/O同步执行，典型4KiB输入估计微秒至毫秒（未实测），网络延迟另计；不承诺GPU加速。资源超限拒绝，不截断成成功。
