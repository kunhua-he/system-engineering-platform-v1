# JSON数据支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 20 个接口。

## 5218 · 裁剪响应

```json

 "编号": 5218,
 "命名值": {
  "载荷JSON": "",
  "选择路径": "",
  "最大条目数": "",
  "最大字节数": "",
  "信封键JSON": "",
  "元数据键": "",
  "数据键": ""
 }
}
```

**这个接口干什么**

按点分路径选中、按每层列表条目数与序列化字节预算裁剪响应载荷，并把截断标记、选中路径、各路径省略条数写进元数据键；信封键原样复制，不改变机器契约。载荷至4194304字节、深度64；条目数与字节数给空文本表示不限。

**参数**

- 载荷JSON · 文本 · 必填 — 待塑形的响应载荷 JSON 文本
- 选择路径 · 文本 · 必填 — 点分路径如 data.items；空文本表示不选中
- 最大条目数 · 文本 · 必填 — 整数文本；每层列表最多保留项数；空文本表示不限，0 表示裁空
- 最大字节数 · 文本 · 必填 — 整数文本；塑形结果序列化上限；空文本表示不限
- 信封键JSON · 文本 · 必填 — JSON 数组文本，选中后原样复制的顶层键名
- 元数据键 · 文本 · 必填 — 写入塑形元数据的顶层键名；空文本表示不写元数据
- 数据键 · 文本 · 必填 — 承载选中值的顶层键名；空文本按 data 处理

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
