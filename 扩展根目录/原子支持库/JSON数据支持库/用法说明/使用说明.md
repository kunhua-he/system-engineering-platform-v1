# JSON数据支持库

## 职责和引擎

JSON文本规范化、RFC6901指针取值、取文本与固定字段摘要；输入65536字节、深度64、指针4096字节。

独立扩展，锁文件钉住第三方引擎，不给底座增加第三方依赖；部署运行只装载正式制品，不依赖老项目源码。

## 调用

- 5201 `规范化JSON`：参数按顺序为JSON文本（均为文本标签4），返回标签4。
- 5202 `按指针取值`：参数按顺序为JSON文本、选择指针（均为文本标签4），返回标签4。
- 5203 `按指针取文本`：参数按顺序为JSON文本、选择指针（均为文本标签4），返回标签4。
- 5204 `提取摘要`：参数按顺序为JSON文本（均为文本标签4），返回标签103。

错误条件与编号以本包能力声明、错误码表为准。缺参、错型不得忽略。

通过引擎RawValue逐层装配对象与列表，保留与引擎私有数字标记同名的普通对象键，不允许对象被静默转成数字。

JSON Pointer按RFC6901处理，空指针取根，~0为~、~1为/；路径不存在与值为null区分。取值返回JSON文本，取文本只接受原值为字符串；大整数保留数字文本。重复键按引擎取最后值，不保证保留原空白或对象键序；输入限65536字节、深度64、指针4096字节。
