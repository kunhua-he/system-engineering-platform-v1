# XML文本支持库

## 边界

读取UTF-8 XML的根名、按文档顺序拼接的正文或结构摘要JSON；不做XSD验证，不冒充任意XML往返转换。拒绝DTD、自定义实体、多根和未闭合文档；支持CDATA、五种预定义实体和数字引用。深度64、事件最多2000。

## 调用契约

- 4701 `取根名称`：顺序参数为XML文本，输入均为文本标签4，返回UTF-8文本标签4。
- 4702 `提取文本`：顺序参数为XML文本，输入均为文本标签4，返回UTF-8文本标签4。
- 4703 `取结构摘要JSON`：顺序参数为XML文本，输入均为文本标签4，返回UTF-8文本标签4。

JSON文本是字符串表示，不冒充任意动态槽。参数、返回和错误码以本包声明为准。

## 资源与成本

纯CPU同步能力；不调用GPU、不启动外部引擎，不读取老项目或业务数据。典型输入按4KiB文本估计，业务计算预估微秒至毫秒级；随文本长度、字段数和算法变化。预估不是实测，实测在整批统一HTTP验收后记录。冷启动、热传参、业务执行分开计时。

入口单个文本最多65536字节，最终输出最多65536字节；本库另有限制时以上述边界为准。长期进程生命周期由统一执行器管理，能力不自行建立第二调度器。

按引擎事件读取XML1.0/1.1，不声称完整标准符合性验证；声明编码只接受UTF-8，属性实体也校验，无声明按XML1.0。
