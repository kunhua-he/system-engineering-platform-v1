# 图片文字识别支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 1 个接口。

---

## 6201 · 识别图片文字

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6201,
 "命名值": {
  "图片路径": ""
 }
}
```

**这个接口干什么**

macOS Apple Silicon原生Vision中英文OCR；PNG/JPEG普通图片绝对路径，文件至20MiB、单边至4096像素、输出至65536字节；返回JSON文本，空白图片成功返回空文字和空文字块；坐标原点左下，归一化。同步本机计算，热调用约0.3秒；部署时须预热一次（构建脚本默认预热），未预热的首次调用报识别超时（可重试），超5秒报识别超时。不支持PDF、Word、PPT及多页；不是隔离沙盒。

**参数**

- 图片路径 · 文本 · 必填 — 网关所在机器可读的PNG或JPEG普通文件绝对路径；不截断原图、不按cwd解释相对路径

**返回**

返回类型：文本。

返回内容：返回JSON文本，空白图片成功返回空文字和空文字块

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
