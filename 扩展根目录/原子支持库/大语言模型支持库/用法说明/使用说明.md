# 大语言模型支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

**日常只用 2519 一次对话**，其余是它内部拆开的零件。共 19 个接口。

## 2519 · 一次对话 ★

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2519,
 "命名值": {
  "消息列表": {
   "类型标签": 100,
   "值": [
    {
     "类型标签": 101,
     "值": {
      "role": {
       "类型标签": 4,
       "值": "user"
      },
      "content": {
       "类型标签": 4,
       "值": "你好"
      }
     }
    }
   ]
  },
  "系统提示词": "",
  "温度": 0.7,
  "最大令牌数": 2048,
  "模型类型": "LLM文本模型",
  "模型引用": "",
  "等待毫秒": 60000
 }
}
```

**这个接口干什么**

把拉起、等就绪、申请许可、连接、提交、取结果、清理串成一个能力：一个请求就能对话。模型没起会自动拉起并复用；等待上限内没生成完就回任务句柄，用 2503 取结果。

**参数**

- 消息列表 · 列表 · 必填 — 对话消息，元素是 {role, content} 对象。纯文本可以直接在这里给一句话
- 系统提示词 · 文本 · 必填 — 角色设定，可空。长期不变的内容放这里命中前缀缓存
- 温度 · 双精度 · 必填 — 随机程度，默认 0.7
- 最大令牌数 · 整数 · 必填 — 生成上限，默认 2048。推理模型给 300 以上
- 模型类型 · 文本 · 必填 — 五个词之一：LLM文本模型 / VLM看图模型 / EM向量模型 / Rerank重排模型 / ASR语音识别模型。必填非空
- 模型引用 · 文本 · 必填 — 模型文件绝对路径。留空 = 用该类型的默认模型（不用记路径）
- 等待毫秒 · 整数 · 可选 — 同步等结果的上限，默认 60000。等到了直接回内容；等不到回任务句柄，用 2503 取。封顶 110000（全平台单项超时 120000，要留传回时间）

**返回**

```json
{
 "任务句柄": 0,
 "内容": "我是通义千问，一个由通义实验室研发的超大规模语言模型，能够理解并生成多种语言的文本，提供包括回答问题、创作、逻辑推理、编程等在内的多样化服务，致力于通过人工智能技术为人类提供高效、可靠的解决方案。",
 "已完成": true,
 "服务句柄": 900001,
 "状态": "已完成"
}
```

（上面的样例是现场调出来的）

**备注**

- 模型没起会自动拉起，起了直接复用，不重起进程
- 模型在内存里约 1 秒返回，冷启动约 3 秒
- 同样的前缀第二次快四成（实测 0.67 → 0.44 秒）：长期不变的内容放最前面，历史只追加不改写
- 等不到就回任务句柄，用 2503 接着取（只有超长生成会遇到）
- 没人用 15 分钟自动退出内存，下次要用自动回来

## 2512 · 拉起模型服务

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2512,
 "命名值": {
  "模型引用": "/Users/hekunhua/Documents/AI模型/文本模型/Qwen3-8B-Q4_K_M.gguf",
  "可执行文件": "/opt/homebrew/bin/llama-server",
  "启动参数": "-m {模型文件} --host 127.0.0.1 --port {端口} -c 8192 --no-webui",
  "监听端口": 0,
  "就绪路径": "",
  "模型类型": "LLM文本模型",
  "闲置超时秒": 900,
  "载入超时秒": 30
 }
}
```

**这个接口干什么**

经底座唯一入口拉起模型进程：可执行文件 + 空格分隔的启动参数 + 监听端口（0=自动分配）+ 就绪路径（空=按类型默认）+ 模型类型；端口已有服务在听则拒绝（孤儿来源）。返回服务句柄，就绪另调 2515。

**参数**

- 模型引用 · 文本 · 必填 — 模型文件绝对路径（推荐，会校验存在）或纯 model 名
- 可执行文件 · 文本 · 必填
- 启动参数 · 文本 · 必填
- 监听端口 · 整数 · 必填 — 传 0 = 由底座在 40000-49999 分配空闲端口（状态里读回）；启动参数里用 {端口} 占位会被替换
- 就绪路径 · 文本 · 必填 — 留空按模型类型取默认（文本/看图/向量/重排 → /health；语音 → /）
- 模型类型 · 文本 · 必填 — 必须从五个词里选一个：LLM文本模型 / VLM看图模型 / EM向量模型 / Rerank重排模型 / ASR语音识别模型
- 闲置超时秒 · 整数 · 可选 — 连着这么多秒没人真正使用（申请推理许可）就自动退出内存，下次要用再载入。默认 900 秒。不建议传 0（永不自动退）：那等于回到一直占着内存，要常驻请给长值如 3600
- 载入超时秒 · 整数 · 可选 — 载入最多允许多久，超了状态转「载入失败」并由巡检收掉进程。实测本机最大模型(18.8G)热载入 3.2 秒，按双倍留余量默认 30 秒，载入卡死时半分钟内就能发现。0 = 不限

**返回**

返回类型：句柄。

**备注**

- 拉起立刻返回句柄，不等载入。状态用 2514 查
- 看图模型必须带 --mmproj 视觉投影层，少了上游只报「上游失败」，看不出缺什么。2519 已按模型名自动推
- 闲置超时秒不建议传 0（永不退），要常驻给长值如 3600
- 拉起前会算内存预算，不够报 2506 资源受限

## 2513 · 释放模型服务

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2513,
 "命名值": {
  "服务句柄": 900001,
  "强制": false
 }
}
```

**这个接口干什么**

先 SIGTERM、短暂等待、仍在再 SIGKILL；真=确认进程已不在（不是信号已发），假=进程仍在跑，条目保留待重试。**幂等**：句柄本来就不在（从没起过/已被别人释放）也回真。`强制`=真时不管进程退没退一律摘除，用于进程彻底卡死时解封句柄与端口。

**参数**

- 服务句柄 · 句柄 · 必填
- 强制 · 逻辑型 · 必填 — 假=常规释放，进程不退就保留条目待重试；真=不管退没退一律摘除（解封句柄与端口，可能留下孤儿进程）

**返回**

```json
true
```

（上面的样例是现场调出来的）

**备注**

- 幂等：句柄本来就不在也回真
- 强制=真是不论退没退一律摘除条目，卡死时的逃生口，代价是可能留孤儿进程

## 2515 · 等待模型就绪

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2515,
```

**这个接口干什么**

轮询端口是否在听：就绪回真；超时回假；进程在就绪前退出回 2509 拉起失败（不把起不来当没起来）。

**返回**

```json
true
```

## 2516 · 申请推理许可

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2516,
 "命名值": {
  "服务句柄": 900001,
  "等待毫秒": 3000,
  "租约毫秒": 5000
 }
}
```

**这个接口干什么**

申请一次推理的独占许可：无人持有即刻授予并回许可句柄；有人持有则排队，等待毫秒用完报 2511。租约与等待上限都是本扩展自己定的 5 秒（一次推理的持有上限，不是平台预算）——持有超租约的许可在下一次申请时被回收。许可是「一次推理」独占，不是「一个进程」独占，常驻服务待命不占许可。

**参数**

- 服务句柄 · 句柄 · 必填 — 要独占 GPU 的模型服务句柄
- 等待毫秒 · 整数 · 必填 — 等不到就排队；超过这个毫秒报 2511。上限 3000（留出传回时间，不把许可等待拖成一次长挂）
- 租约毫秒 · 整数 · 必填 — 持有上限；传 0 用默认 5000。本扩展的上限就是 5000，超过按 5000 收

**返回**

```json
{
 "许可句柄": 800004
}
```

（上面的样例是现场调出来的）

**备注**

- 同模型内排队（共享显存与 KV 缓存），不同模型并行（各独立进程）

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄至 64 个、任务至 64 个，超出返回 2506 资源受限
- 连接与流内停顿各五秒上限（本扩展网络层）；模型整体生成时长不受这五秒限制
- 任务与句柄只在当前扩展实例内有效，不承诺跨重启
