# 进程执行支持库

## 边界

有界进程执行任务：提交返回任务句柄，读取回状态与输出，取消即杀进程组，释放回收条目；单命令预算最长六百秒、单路输出至 1MiB，超出按截断标记；默认走 macOS 沙箱（全盘只读、仅工作目录与私有临时目录可写），无沙箱时明确失败，可显式选择直跑。

## 调用契约

- 2601 `提交执行`：参数为执行参数字典（标签101，键：命令 / 工作目录 / 超时秒数 / 沙箱），返回任务句柄标签7。
- 2602 `读取执行`：参数为任务句柄标签7，返回结构标签103（状态 / 退出码 / 标准输出 / 错误输出 / 标准输出已截断 / 错误输出已截断 / 耗时毫秒 / 已完成 / 资源在途）。
- 2603 `取消执行`：参数为任务句柄标签7，返回逻辑标签3。
- 2604 `释放执行`：参数为任务句柄标签7，返回逻辑标签3。

沙箱模式：macOS `sandbox-exec`，全盘只读，仅工作目录、`/private/tmp`、`/private/var/folders` 与 `/dev/null` 可写；本机无沙箱执行器时明确失败（错误码 2605），调用方可显式传「直跑」。

## 资源与成本

每条命令一个工作线程；任务表上限 16 条，单路输出上限 1MiB（超出按截断标记），完成后结果保留 10 秒；单命令预算最长 600 秒，超出按超时终止并杀进程。本库不建立第二调度器，长期生命周期由统一执行器管理。
