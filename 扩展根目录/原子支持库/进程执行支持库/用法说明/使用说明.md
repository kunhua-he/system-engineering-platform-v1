# 进程执行支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 4 个接口。

---

## 2601 · 提交执行

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2601,
 "命名值": {
  "执行参数": {
   "类型标签": 101,
   "值": {}
  }
 }
}
```

**这个接口干什么**

有界进程执行任务：提交命令、工作目录与预算，返回任务句柄；默认沙箱全盘只读、仅工作目录与私有临时目录可写。

**参数**

- 执行参数 · 对象 · 必填 — 字典：命令 / 工作目录 / 超时秒数 / 沙箱（沙箱或直跑）

**返回**

返回类型：任务句柄。

返回内容：返回任务句柄

---

## 2602 · 读取执行

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2602,
 "命名值": {
  "任务句柄": {
   "类型标签": 7,
   "值": 1
  }
 }
}
```

**这个接口干什么**

读取任务状态与输出；未退场时已完成为假、资源在途为真，取消中或超时处理中不冒充终态；所属进程组退出并回收后返回已取消、超时或已完成及输出。

**参数**

- 任务句柄 · 任务句柄 · 必填 — 提交执行返回的任务句柄

**返回**

返回类型：生成结构。

返回字段：状态（文本）、已完成（逻辑型）、资源在途（逻辑型）（读源码确认，见 进程执行支持库/src/进程任务管理.rs::读取执行）

返回内容：返回已取消、超时或已完成及输出

---

## 2603 · 取消执行

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2603,
 "命名值": {
  "任务句柄": {
   "类型标签": 7,
   "值": 1
  }
 }
}
```

**这个接口干什么**

请求取消并返回请求已接受；工作线程终止已登记的所属进程组，确认退出与管道回收后才呈现已取消；未退场仍资源在途。

**参数**

- 任务句柄 · 任务句柄 · 必填 — 提交执行返回的任务句柄

**返回**

返回类型：逻辑型。

返回内容：返回请求已接受

---

## 2604 · 释放执行

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2604,
 "命名值": {
  "任务句柄": {
   "类型标签": 7,
   "值": 1
  }
 }
}
```

**这个接口干什么**

请求取消并丢弃结果；未退出的任务仍保留归属与任务额度，确认所属进程组和工作线程退出后回收条目。

**参数**

- 任务句柄 · 任务句柄 · 必填 — 提交执行返回的任务句柄

**返回**

返回类型：逻辑型。

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
