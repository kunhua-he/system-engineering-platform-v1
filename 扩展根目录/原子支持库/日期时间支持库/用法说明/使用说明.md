# 日期时间支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 5 个接口。

---

## 2301 · 规范化日期

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2301,
 "命名值": {
  "日期文本": ""
 }
}
```

**这个接口干什么**

规范化RFC3339为UTC；格式化保留输入固定偏移；按格式解析必须包含可确定的时区，不猜本机时区。格式长度最多1024字节，非法格式明确失败，不抛异常；不附带时区数据库。

**参数**

- 日期文本 · 文本 · 必填

**返回**

返回类型：文本。

## 2304 · 取当前时间

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2304,
 "命名值": {
  "时区偏移分钟": ""
 }
}
```

**这个接口干什么**

取当前时刻：时区偏移分钟为 -1440..=1440 的整数文本（北京时间为 480），返回该时区的 RFC3339 秒级时间文本（带偏移）。

**参数**

- 时区偏移分钟 · 文本 · 必填

**返回**

返回类型：文本。

返回内容：返回该时区的 RFC3339 秒级时间文本（带偏移）

## 2305 · 计算间隔

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2305,
 "命名值": {
  "起始文本": "",
  "结束文本": "",
  "单位文本": ""
 }
}
```

**这个接口干什么**

计算两个 RFC3339 时刻的间隔：单位只收 秒/毫秒/分钟/小时/天，返回该单位下的整数文本；结束早于起始返回负值，不足一个单位向下取整。

**参数**

- 起始文本 · 文本 · 必填
- 结束文本 · 文本 · 必填
- 单位文本 · 文本 · 必填

**返回**

返回类型：文本。

返回内容：返回该单位下的整数文本

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
