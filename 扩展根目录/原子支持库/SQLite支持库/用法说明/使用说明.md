# SQLite支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 2 个接口。

---

## 5101 · 执行事务

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 5101,
 "命名值": {
  "数据库路径": "",
  "语句列表": {
   "类型标签": 100,
   "值": []
  }
 }
}
```

**这个接口干什么**

执行事务；绝对路径、每调用独立连接，具体边界见使用说明。

**参数**

- 数据库路径 · 文本 · 必填
- 语句列表 · 列表 · 必填

**返回**

返回类型：整数。

---

## 5102 · 只读查询

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 5102,
 "命名值": {
  "数据库路径": "",
  "查询语句": ""
 }
}
```

**这个接口干什么**

只读查询；绝对路径、每调用独立连接，具体边界见使用说明。

**参数**

- 数据库路径 · 文本 · 必填
- 查询语句 · 文本 · 必填

**返回**

返回类型：生成结构。

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
