# 编解码支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 10 个接口。

---

## 4001 · 编码文本

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4001,
 "命名值": {
  "文本内容": "",
  "编码名": ""
 }
}
```

**这个接口干什么**

WHATWG字符编码转换；编码名称显式传入，如UTF-8、GBK、UTF-16LE；输出真实字节集，解码回UTF-8文本；不允许不可表示字符的静默替换，不承诺GB18030-2022全覆盖；输入输出65536字节。

**参数**

- 文本内容 · 文本 · 必填
- 编码名 · 文本 · 必填

**返回**

```json
"56S65L6L5YaF5a65"
```

（上面的样例是现场发请求调出来的）

**返回**


## 4301 · 标准编码

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4301,
 "命名值": {
  "原文": ""
 }
}
```

标准编码使用RFC4648填充；网址安全编码无填充。解码结果必须为UTF-8文本；不是任意二进制解码。编码输入最多49152字节、输出65536字节。

**参数**

- 原文 · 文本 · 必填

**返回**


- 原文 · 文本 · 必填

**返回**


## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
