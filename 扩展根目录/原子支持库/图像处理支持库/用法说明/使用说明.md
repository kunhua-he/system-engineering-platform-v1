# 图像处理支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 11 个接口。

---

## 6501 · 分析图像文件

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6501,
 "命名值": {
  "图像base64": ""
 }
}
```

**这个接口干什么**

解码图像并统计格式、宽高、模式、像素数与平均颜色；输入字节至64MiB、单边至20000、总像素至1亿；返回JSON文本。

**参数**

- 图像base64 · 文本 · 必填 — 图像字节的 base64 文本

**返回**

返回类型：文本。

返回内容：返回JSON文本

## 6503 · 生成占位图

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6503,
 "命名值": {
  "宽度": "",
  "高度": "",
  "占位类型": "",
  "背景颜色": "",
  "前景颜色": "",
  "文本": ""
 }
}
```

**这个接口干什么**

按宽高与占位类型生成 PNG，返回图像base64与尺寸；文本非空时画一条示意横线。

**参数**

- 宽度 · 文本 · 必填 — 像素宽，1 至 20000
- 高度 · 文本 · 必填 — 像素高，1 至 20000
- 占位类型 · 文本 · 必填 — solid 纯色 / checker 棋盘 / gradient 渐变
- 背景颜色 · 文本 · 必填 — 十六进制 RRGGBB 或 RRGGBBAA
- 前景颜色 · 文本 · 必填 — 十六进制 RRGGBB 或 RRGGBBAA
- 文本 · 文本 · 必填 — 非空时画示意横线；文本本身不入图

**返回**

返回类型：文本。

返回内容：返回图像base64与尺寸

## 6511 · 判定画面起伏

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6511,
 "命名值": {
  "图像base64": "",
  "标准差下限": ""
 }
}
```

**这个接口干什么**

按红绿蓝三通道与亮度的标准差判图像有没有画面起伏，返回各通道标准差、均值与判定依据；纯色图判定为无起伏。

**参数**

- 图像base64 · 文本 · 必填 — 图像字节的 base64 源文本
- 标准差下限 · 文本 · 必填 — 判有起伏的标准差阈值，0 至 255 的十进制文本，空串取 2.0

**返回**

返回类型：文本。

返回内容：返回各通道标准差、均值与判定依据

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
