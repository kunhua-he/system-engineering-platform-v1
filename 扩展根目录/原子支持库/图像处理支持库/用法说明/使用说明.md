# 图像处理支持库 · 使用说明

全部能力都是**字节进字节出**：图像以 base64 文本传入，产物以 base64 文本返回；需要落盘的调用方自行写文件。
所有参数都是文本槽，路径式能力不提供 —— 能力不绑死路径，也不做任意路径写入。

## 上限

- 输入图像字节：64 MiB
- 单边：20000 像素；总像素：1 亿
- 单参数文本：88 MB（base64 后的图像文本）

## 6501 分析图像文件 / 6502 识别图像格式

参数：图像base64。
6501 返回 `{格式, 宽度, 高度, 模式, 像素数, 平均颜色{红,绿,蓝}, 字节数}`；
6502 返回 `{格式, 宽度, 高度, 模式}`。格式按内容判定，与扩展名无关。

## 6503 生成占位图

参数：宽度、高度、占位类型、背景颜色、前景颜色、文本。
占位类型：`solid` 纯色 / `checker` 棋盘 / `gradient` 纵向渐变；颜色写 `RRGGBB` 或 `RRGGBBAA`（可带 `#`）。
返回 `{图像b64, 格式, 宽度, 高度, 字节数}`；「文本」非空时画一条示意横线，**不做字体渲染**。

## 6504 缩放图像 / 6505 转置图像

6504 参数：图像base64、目标宽、目标高（重采样固定 Lanczos3）。
6505 参数：图像base64、转置方式（`fliph` / `flipv` / `rotate90` / `rotate180` / `rotate270`，也认中文）。
两者都返回 `{图像b64, 宽度, 高度, 字节数}`（PNG）。

## 6506 合成图像

参数：底图base64、叠加base64、偏移x、偏移y。偏移可为负，超出底图范围的部分裁掉，按叠加图 alpha 混合。

## 6507 重编码图像

参数：图像base64、目标格式、质量（1 至 100，空表示编码器默认）。

## 6508 计算图像哈希组

参数：图像base64。返回 `{平均哈希, 差异哈希, 感知哈希}`，十六进制串（平均 16 位、差异 16 位、感知 64 位）。
感知哈希是 17 列 × 16 行差异位的放大版，**不是 DCT pHash**；只用于同源缩放的粗筛。

## 6509 转置修正

参数：图像base64。按 EXIF 方向转正后重新编码（JPEG/WebP 保持原格式，其余回 PNG）。

## 6510 透明背景合成

参数：图像base64、背景颜色。把透明/半透明像素合成到给定背景上，输出不透明 PNG。

## 错误码

- 6501 参数不合法：个数、写法、取值不合契约（含空串的必填参数、非法 base64）
- 6502 解码失败：字节不是可解码图像或内容损坏
- 6503 写出失败：编码失败或产出为空（可重试）
- 6504 格式不支持：目标格式不在可编码名单内
- 6505 尺寸超限：超过单边 20000 或总像素 1 亿

## 6511 判定画面起伏

**做什么**：判一张图「有没有画面起伏」（海报/封面是否为纯色空图、截图是否全白），给各通道标准差与均值。

**参数**：`图像base64`（必填）、`标准差下限`（十进制文本，空串取 2.0，范围 0–255）。

**返回**：
```
{"有起伏":true,"判定依据":"通道最大标准差45.21 亮度标准差44.87 下限2.00","标准差下限":"2.00","像素总数":518400,
 "通道标准差":{"红":"52.3100","绿":"48.2000","蓝":"47.9000","亮度":"44.8700"},
 "通道均值":{"红":"128.5000","绿":"131.2000","蓝":"130.9000","亮度":"130.5000"}}
```

**判定口径**：任一通道标准差 **或** 亮度标准差 ≥ 下限即算有起伏。
只看亮度会漏「彩色分块但亮度平」的图，所以四个标准差取最大。

**边界**：像素数 0 ⇒ `6502 解码失败`；> 4000 万像素 ⇒ `6505 尺寸超限`；下限不是数字或超 0–255 ⇒ `6501 参数不合法`。
