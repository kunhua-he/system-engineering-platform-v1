# 网络请求支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 9 个接口。

---

## 2401 · 获取文本

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2401,
 "命名值": {
  "请求地址": ""
 }
}
```

**这个接口干什么**

有界HTTP客户端；只接受HTTP或HTTPS，不自动重定向，不继承环境代理，TLS校验开启；全程预算取平台单项超时的一半，响应最多65536字节，非2xx返回明确错误。允许调用方显式访问内网，非出站安全过滤器。

**参数**

- 请求地址 · 文本 · 必填

**返回**

返回类型：文本。

返回内容：返回明确错误

## 2405 · 提交网络请求

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 2405,
 "命名值": {
  "请求参数": {
   "类型标签": 101,
   "值": {}
  }
 }
}
```

**这个接口干什么**

字典：地址必填；方法GET、请求头字典、请求体字符串或JSON、超时秒(0,5]默认5、最大字节数1至4194304默认2097152、允许回环默认假、仅校验默认假。SSL验证只能真，重定向只能假，代理不支持且明确拒绝。返回当前扩展实例内的任务句柄；完成后结果保留十秒。

**参数**

- 请求参数 · 对象 · 必填

**返回**

返回类型：任务句柄。

返回内容：返回当前扩展实例内的任务句柄

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
