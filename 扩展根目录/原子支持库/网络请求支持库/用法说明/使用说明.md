# 网络请求支持库

有界HTTP客户端；只接受HTTP或HTTPS，不自动重定向，不继承环境代理，TLS校验开启；全程预算取平台单项超时的一半，响应最多65536字节，非2xx返回明确错误。允许调用方显式访问内网，非出站安全过滤器。

- 2401 获取文本：请求地址 → 类型标签4。
- 2402 提交JSON文本：请求地址、JSON文本 → 类型标签4。
- 2403 获取字节：请求地址 → 类型标签5。
- 2404 下载文件：请求地址、输出路径 → 类型标签4。

调用经唯一HTTP能力入口；必须与本包声明的参数行序一致。纯CPU或网络I/O同步执行，典型4KiB输入估计微秒至毫秒（未实测），网络延迟另计；不承诺GPU加速。资源超限拒绝，不截断成成功。
