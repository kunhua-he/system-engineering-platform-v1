# 办公文档支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 15 个接口。

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6116,
 "命名值": {

 }
}
```

**这个接口干什么**

检查外部转换器可用性：textutil（系统自带）与 LibreOffice（PATH、应用目录或 LIBREOFFICE_BIN）；提供者名传 all 表示全部（平台不收空串实参，空串会被判参数不合法）；返回 JSON 文本，值形如 {"textutil":"可用","libreoffice":"LibreOffice 25.8…"}，不可用记「不可用」。不安装、不改配置，只探测。

**参数**

- 提供者名 · 文本 · 必填 — all / textutil / libreoffice；查全部传 all，不传空串

**返回**

返回类型：文本。

返回内容：返回 JSON 文本，值形如 {"textutil":"可用","libreoffice":"LibreOffice 25.8…"}，不可用记「不可用」

## 6117 · 转换办公文件

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6117,
 "命名值": {
  "输入路径": "",
  "目标格式": "",
  "超时秒": "",
  "输出目录": ""
 }
}
```

**这个接口干什么**

经 LibreOffice 无头模式转换办公文件：输入路径与输出目录均为绝对路径，目标格式如 pdf/docx/xlsx，超时秒到点杀进程（含子进程），成功返回 JSON {输出路径,字节数,格式}；同一时刻只允许一个转换，其余排队；输出超过 67108864 字节回 6103。

**参数**

- 输入路径 · 文本 · 必填 — 绝对路径的源文件
- 目标格式 · 文本 · 必填 — 如 pdf/docx/xlsx，不带点
- 超时秒 · 文本 · 必填 — 整数文本，1 至 5；传 0 取 5（空串平台不收）
- 输出目录 · 文本 · 必填 — 绝对路径，不存在则创建

**返回**

返回类型：文本。

返回内容：返回 JSON {输出路径,字节数,格式}

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
