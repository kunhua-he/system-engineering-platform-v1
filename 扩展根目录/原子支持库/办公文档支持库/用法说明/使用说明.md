# 办公文档支持库

纯计算部分：不读外部文件、不走网络、不依赖第三方 crate。

## 6110 求值公式

- 参数：`公式文本`（四则运算 `+ - * /`、括号、数字、变量名）、`变量文本`（JSON 对象，值只接受数值）。
- 返回：数值文本；整数不带小数点（`47`），小数按最短表示（`47.5`）。
- 失败：`6101 参数不合法`（参数个数/JSON 结构不对）、`6102 计算失败`（公式非法、变量缺失、除零）、`6103 内容不合法`（公式超 4096 字元、变量超 256 个）。
- 不做单元格引用、不做函数调用；需要引用请调用方先把单元格取值放进变量表。

示例：`公式文本 = "(单价*数量)-折扣"`，`变量文本 = {"单价":12.5,"数量":4,"折扣":3}` → `47`。

## 6111 解析标记块

- 参数：`Markdown源文本`（上限 256 KiB）。
- 返回：JSON 文本 `{"块":[{"类型":...,"层级":...,"文本":...,"语言":...}]}`。
- 类型集合：`标题`（带 `层级` 1–6）、`段落`、`列表项`、`代码块`（带 `语言`，围栏未闭合时按到末尾收口）、`引用`、`分隔线`。
- 空行忽略；缩进不保留；不认识的行归 `段落`。

示例输入：

```text
## 标题
- 第一条
```

输出：

```json
{"块":[{"类型":"标题","层级":2,"文本":"标题"},{"类型":"列表项","文本":"第一条"}]}
```

## 6112 解析DOCX

- 参数：`DOCX文件路径`（本机可读的 .docx 绝对路径）。
- 返回：JSON 文本 `{"段落":[{"样式":"...","文本":"..."}],"表格":[[["单元格"]]],"段数":N,"表数":M}`。
- 抽取方式：解 zip 取 `word/document.xml`，先摘表格区（`<w:tbl>`…`</w:tbl>`），再把剩余正文按 `</w:p>` 切段；段落样式取 `<w:pStyle w:val="...">`，文字取所有 `<w:t>` 拼接并反转义。
- 失败：`6103 内容不合法`（不是 zip、缺 `word/document.xml`、正文不是 UTF-8）。

## 6113 生成DOCX

- 参数：`内容文本`（JSON：`{"段落":[{"文本","样式"?}],"表格":[[["单元格"]]]}`）、`输出路径`（.docx 绝对路径）。
- 返回：JSON 文本 `{"输出路径":"...","字节数":N}`。
- 产出最小可用包：`[Content_Types].xml` + `_rels/.rels` + `word/document.xml`，Word / textutil 可直接打开。
- 失败：`6101 参数不合法`（内容不是合法 JSON）、`6104 写出失败`（路径不可写）。
