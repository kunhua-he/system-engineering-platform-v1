# 压缩支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 2 个接口。

---

## 3201 · 压缩文本

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 3201,
 "命名值": {
  "输入文本": ""
 }
}
```

**这个接口干什么**

外部系统zlib引擎；文本压成大写十六进制，解压回UTF-8，输入及解压最多65536字节，不接路径。

**参数**

- 输入文本 · 文本 · 必填 — 显式UTF-8文本

**返回**

返回类型：文本。

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
