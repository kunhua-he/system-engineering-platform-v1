# PostgreSQL支持库

本包封装系统libpq；外部仍走V1唯一HTTP能力入口，不依赖数据库访问模块的研究源码。

## 冻结能力与所有权

| 编号 | 名称 | 参数（按顺序） | 返回 |
|---|---|---|---|
| 5401 | 打开连接 | 连接文本：类型4 | 类型6不透明句柄，真实PGconn存活，不是连接串登记 |
| 5402 | 只读查询 | 连接编号：类型6；查询语句：类型4 | 类型4 JSON文本，字段为列名列表、行列表 |
| 5403 | 执行事务 | 连接编号：类型6；事务语句：类型4 JSON字符串数组 | 类型1已提交语句数 |
| 5404 | 释放连接 | 连接编号：类型6 | 类型1整数1；该连接已调用PQfinish |

5402每次在同一连接上执行BEGIN READ ONLY、单条查询、COMMIT。列值按PostgreSQL文本协议返回字符串或JSON null，不伪称数值、二进制自动类型保真；重复列名按列序列表保留。空结果行列表为空。

5403在同一连接锁内执行BEGIN、逐条语句、COMMIT；失败显式ROLLBACK，回滚失败或连接协议失效则摘除句柄并PQfinish，不把部分成功算提交。SQL采用PQsendQueryParams单命令扩展协议，多语句被服务端拒绝；事务控制语句不在允许的首关键字内，不能提前COMMIT。事务返回的是语句数，不是修改行数。

调用方负责5404；释放和卸载都由唯一连接所有者析构触发PQfinish；重复释放、卸载前旧句柄均报5414。无隐式重连、无连接池、无后台保活。卸载与调用互斥；在途时回延迟释放应答，成功卸载后清空所有本包连接。新装载不复用旧句柄序号。

## 接入及范围

- 能力号5401–5404、错误码5411–5417冻结；开工时已核当前全部正式分支包声明、作废号表与规则库基线，无正式占用。失败树未跟踪实现不是登记，本次未读取、复制或修改失败树。
- 运行需要libpq；构建需要pg_config。build.rs读取pg_config库目录并由Cargo正常链接，不修改底座依赖。
- 连接文本使用libpq连接串或URI，但必须显式指定Unix套接字绝对目录、数字IP host或数字IP hostaddr；不支持主机名DNS、多主机、服务文件隐式主机或环境隐式主机。连接参数最多8192字节，不接受NUL。认证配置依libpq；不要把真实凭证写进验收材料。
- 进程内宿主支持库执行链已实现；句柄只属于其产生的网关进程，不能跨网关、跨进程或跨卸载使用。HTTP类型6不是原池线协议对类型6的支持证明。未修改原池协议、组合模块或研究接缝；不承诺同一原生映像在同进程内被多个适配器装载时的装载单元隔离。
- 全包最多32个连接；表锁采用非阻塞互斥，忙时回5415，不排队等待。不做持久保存。随机起始号加单调递增，不泄漏PGconn地址。
- 查询首关键字只接受SELECT、WITH、VALUES、TABLE；事务接受SELECT、WITH、VALUES、INSERT、UPDATE、DELETE、CREATE、ALTER、DROP、TRUNCATE。前导空白允许，前导注释不接受。这不是完整SQL分析器；只读严格按PostgreSQL READ ONLY定义，临时对象和有副作用的函数不等于无副作用沙盒。数据库权限仍由数据库角色决定，本包不提供多租户授权隔离。
- 单SQL文本最多65536字节；事务最多32句、合计65536字节。返回解码最多1024行、64列、单值65536字节、单元值合计262144字节。libpq在解码前接收完整结果，该上界不是服务器或libpq内存分配上界；不适合无限结果或流式查询。
- 连接和执行的异步轮询截止800毫秒；服务端statement_timeout=400毫秒、lock_timeout=200毫秒；错误回滚另有200毫秒。参数、错误传回仍受平台单项预算。用户SQL可改变会话设置，客户端截止仍生效；超时或传输异常会关闭连接，事务由PostgreSQL断连回滚。断连时提交确认可能丢失，因此5417表示结果未知，绝不可自动重试写事务。

## 错误码

| 码 | 失败条件与结果 |
|---|---|
| 5411 | 参数、NUL、主机地址、SQL首关键字或事务列表不合法；不执行事务 |
| 5412 | 建立连接失败或连接截止；失败PGconn已析构 |
| 5413 | 服务端语句失败；已回滚，连接可继续用（回滚失败改报5417） |
| 5414 | 无效、已释放、卸载前或不属于当前进程的句柄 |
| 5415 | 表锁忙、停止接收或连接数已达上限；不隐式替换其他连接 |
| 5416 | 结果解码上界超限；已回滚，连接可继续用 |
| 5417 | 协议/传输失败、客户端截止、COPY状态或回滚失败；句柄已失效，提交结果可能未知，需人工判定，不自动重试 |

所有错误码的可重试、可自愈、需人工旗标在初版均为false；调用方不能据此推断写操作安全重试。

## 复跑

在本工作树加载构建环境；所有Cargo调用必须指向本包manifest。

```sh
. 构建环境/进入.sh
# V1_LIBPQ_TEST_DSN必须指向调用方专用夹具；集成测试会创建formal_probe表。
cargo test --locked --offline --manifest-path 扩展根目录/原子支持库/PostgreSQL支持库/Cargo.toml
cargo clippy --locked --offline --all-targets --manifest-path 扩展根目录/原子支持库/PostgreSQL支持库/Cargo.toml -- -D warnings
```

验收材料/复跑验收.py自建并停止隔离PG实例，执行上述单测及真实HTTP；不读取业务库、不切换常驻网关。真实制品必须先经正式预构建与封包入口，HTTP取证使用正式装载链，不用单测替代HTTP。启动预算由上层调用方从现行硬顶常量传入，包内测试不反向导入构建层：

```sh
V1_START_BUDGET_MS=$("$V1_PY" -c 'from 构建装配.门禁.硬顶常量 import 效率目标毫秒;print(效率目标毫秒)')
"$V1_PY" 扩展根目录/原子支持库/PostgreSQL支持库/验收材料/复跑验收.py --仓根 "$PWD" --缓存根 "$HOME/.hermes/cache/scratch/libpq全新验收目录" --网关路径 "$PWD/构建装配/制品产物/3e7e4774fe9c-8b33d2fb2ae77987/网关" --启动预算毫秒 "$V1_START_BUDGET_MS"
```
