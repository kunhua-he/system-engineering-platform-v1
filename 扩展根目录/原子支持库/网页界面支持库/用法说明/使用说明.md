# 网页界面支持库

## 原理

HTTP参数 → 数据槽 → 本库生成面 → 成品HTML文本 → HTTP返回。

界面是原子能力：任何项目接入底座即得到同一套外观，不必各自携带 Vue、Element Plus 一类前端框架。
界面生成能力只按声明出 HTML，不读文件、不连业务网络、不存业务数据；排序、分页、选择等句柄状态仅在进程内暂存，供组件交互时重算。

`4928 渲染组件树` 是唯一组件声明入口；`4929 操作组件`、`4930 读组件状态`、`4931 释放组件句柄` 是围绕同一组件句柄的交互生命周期，不为窗口、表格或其他组件另开渲染能力。

## 视觉基准

样式全部内联在返回的HTML里，中性取值照抄 V3 前端（唯一真源 `src/视觉基准.rs`），需要改观感时由声明覆盖（饼图式外观对象，见下）：

- 业务区（Element Plus 观感）：主色 `#409eff`（hover `#337ecc`、浅底 `#ecf5ff`），成功 `#67c23a`、警告 `#e6a23c`、危险 `#f56c6c`、信息 `#909399`；页面底 `#f0f2f5`、卡片 `#fff`、边框 `#e4e7ed`；文字 `#303133` / `#606266` / `#909399` / 占位 `#c0c4cc`；圆角 4 / 8 / 12px。
- 桌面外壳（macOS 观感）：系统蓝 `#0a84ff`；窗口圆角 13px；控件圆角 6px、菜单 12px、弹层 14px、面板 16px。
- 字体：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`。

## 调用

只有一条：**4928 渲染组件树** —— 参数是一个 JSON 文本（`树定义原文`），里面是可递归嵌套的节点树。

```json
{
  "参数": {
    "树定义原文": "{\"整页\":true,\"页面标题\":\"示例\",\"根\":{\"类型\":\"列\",\"间距\":12,\"子\":[{\"类型\":\"标题\",\"文本\":\"文件清单\"},{\"类型\":\"表格\",\"列\":[\"名称\"],\"行\":[[\"a.txt\"]]}]}}"
  }
}
```

- 容器：行、列、网格、侧栏、分区、画布（可无限嵌套，深度与节点数有防爆上限）。
- 叶子：标题、文字、图标、表格、表单、输入、按钮、聊天流、原生片段、分隔条、悬浮层、窗口。
- 整页模式（`整页:true`）返回完整 HTML；否则返回片段，供窗口内容或局部刷新使用。
- 所有文本一律转义；表单容器与图标地址只认同源路径；颜色与背景按白名单校验。

## 边界与错误

- 4921 参数不合法；4922 内容不合法（JSON 解析失败、形状不符、颜色/尺寸/间距越界、枚举值不认识）；4923 资源受限（超上限）。
- 输入上限 1MB、输出上限 4MB（组件树比单件 HTML 大，这是本能力与其它能力不同的一处）。
- 树深度上限 32 层、节点上限 2000 个：超限明确回资源受限，不截断、不静默丢节点。

## 正式验证

用真实 HTTP 调 4928，断言返回状态、返回类型与正文关键字（含 `#409eff`、`13px` 等基准值），不以「/接口 200」代替。

### 4928 渲染组件树

一棵可递归嵌套的节点树 → HTML 片段。**这是唯一的通用拼装入口**：窗口内容、整页、面板都由它出，
4910 骨架 / 4914 侧栏 / 4926 区块组 都只是它的预置写法。

```json
{
  "参数": {
    "树定义原文": "{\"根\":{\"类型\":\"侧栏\",\"栏宽\":240,\"标题\":\"对话\",\"菜单\":[{\"名称\":\"新对话\",\"图标\":\"💬\",\"激活\":true}],\"子\":[{\"类型\":\"列\",\"间距\":12,\"子\":[{\"类型\":\"标题\",\"文本\":\"最近对话\"},{\"类型\":\"聊天流\",\"消息\":[{\"角色\":\"user\",\"内容\":\"你好\"}],\"空态文案\":\"还没有消息\"}]}]}}"
  }
}
```

**容器（可无限嵌套）**

| 类型 | 作用 | 专有字段 |
|---|---|---|
| `行` | 水平排列 | `水平对齐` `垂直对齐` |
| `列` | 垂直排列 | `水平对齐` `垂直对齐` |
| `网格` | 等分网格 | `列数`（1–24） |
| `侧栏` | 左栏 + 主区 | `栏宽` `标题` `菜单`（`名称`/`图标`/`激活`） |
| `分区` | 带标题的区块 | `标题` |
| `画布` | 绝对定位平面 | 子节点带 `左` `上` `宽` `高` |
| `悬浮层` | 覆盖整页的浮层，可按快捷键或声明切换显隐 | `标识`（字母数字/`-`/`_`/汉字，≤32）`初始隐藏` `快捷键`（≤8 字符） |
| `窗口` | 桌面内的应用窗口，标题栏可拖动、点一下置顶 | `标识`（同上）`标题` `初始隐藏` `标题栏背景` `标题栏文字颜色` `标题栏高`（24–64）`可关闭`（缺省 真）`可最小化`（缺省 假）`可最大化`（缺省 假）`可移动`（缺省 真） |

**叶子**：`标题` `文字` `图标`（`图形`/`名称`/`打开地址`/`显示名称`）`表格`（`列`+`行`）`表单`（`字段`+`值`）`输入` `按钮` `聊天流`（`消息`+`空态文案`）`分隔条` `原样`（`html` 不转义，上限 200KB）

**图标**：`图形` 写 emoji 或同源图片路径（`/静态资源/…`）；`打开地址` 只认同源路径，点击即跳转；`显示名称` 默认 真，写 假 则只出图形。

**链接**：`文字` 与 `侧栏` 菜单条目都能带 `打开地址`（同源路径），出 `<a>`；不带就出纯展示元素。

**显隐切换**（任何节点都能带）：`"切换显隐": "启动器"` —— 点击该节点切换同标识悬浮层的显隐；悬浮层写 `"快捷键": "F4"` 则由键盘开合。整页模式在需要时自动附一段通用脚本，没有这类声明就不出脚本。

**示例：桌面（菜单栏 + 图标 + 坞 + F4 启动器）**

```json
{"整页": true, "页面标题": "桌面", "根": {
  "类型": "画布", "宽": "100vw", "高": "100vh",
  "背景": {"类型": "图片", "资源": "/静态资源/壁纸/a.svg"},
  "子": [
    {"类型": "行", "左": 0, "上": 0, "宽": "100%", "高": 30, "内边距": "0 12px",
     "水平对齐": "两端", "背景": "#FAFAFC9E",
     "子": [{"类型": "文字", "文本": "品牌"},
            {"类型": "文字", "文本": "启动器", "切换显隐": "启动器"}]},
    {"类型": "图标", "左": "calc(100% - 120px)", "上": 60, "宽": 88, "高": 92,
     "图形": "📁", "名称": "文件", "打开地址": "/files"},
    {"类型": "悬浮层", "标识": "启动器", "快捷键": "F4", "背景": "#161A226B",
     "子": [{"类型": "网格", "列数": 7, "子": [{"类型": "图标", "图形": "📁", "名称": "文件", "打开地址": "/files"}]}]}
  ]}}
```

**表单相关**

| 类型 | 作用 | 字段 |
|---|---|---|
| `表单容器` | 出 `<form>`，子节点即表单控件 | `标识` `提交地址`（必须同源路径）`方式`（POST / GET） |
| `输入` | 单个输入框，带标签 | `种类`（文本框 / 密码框 / 数字框 / 邮箱）`名称` `标签` `占位文本` `必填` `自动填充` |
| `按钮` | 按钮，可声明为提交按钮 | `文字` `动作` `提交`（真 = type=submit）`表单`（目标表单标识）`样式`（主要 / 默认 / 成功 / 警告 / 危险） |

**整页**：树定义顶层加 `"整页": true` 与 `"页面标题"`，返回带文档头、基准样式的完整页面（不再是片段），调用方不必再拼文档头。

**通用属性**（任何节点都能带）：`宽` `高` `间距` `内边距` `背景` `圆角` `边框` `溢出` `最小高` `边框颜色`
（数字按 px，字符串原样如 `"100%"`）

**背景取值**

- 纯色：字符串，只接受 `#RGB` / `#RRGGBB` / `#RRGGBBAA`
- 线性渐变：`{"类型":"线性渐变","角度":135,"颜色节点":[{"颜色":"#000000","位置":0},{"颜色":"#ffffff","位置":100}]}`（2–16 个节点，位置 0–100 且递增）
- 图片：`{"类型":"图片","资源":"/静态资源/xxx.svg"}`（只接受同源路径，拒 `//`、`..`、协议头）

颜色与背景走白名单校验：不是颜色值、不是同一套渐变形状，一律回内容不合法，不回退成默认外观。

**防爆上限**：深度 32 层、节点 2000 个 —— 产品语义上嵌套不限层数，这两道闸只拦写坏的树。


### 容器内部外观（表格 / 侧栏菜单 / 对话气泡）

三类容器的内部观感各有一组可选外观对象，不写就按中性缺省；写了会被校验并挂成容器上的 CSS 变量，中性样式用变量兜底。

```json
{"类型": "表格", "列": ["名称"], "行来源": "文件数据",
 "表格外观": {"表头背景": "#FFFFFF", "表头文字颜色": "#909399", "单元格文字颜色": "#606266",
               "边框颜色": "#EBEEF5", "行悬停背景": "#F5F7FA", "字号": 14, "单元格内边距": "8px 12px"}}

{"类型": "侧栏", "菜单外观": {"栏底色": "#F1F5F9", "项文字颜色": "#303133", "激活背景": "#ECF5FF",
                               "激活文字颜色": "#409EFF", "项字号": 13, "项圆角": 6, "项内边距": "6px 8px"}}

{"类型": "聊天流", "行来源": "最新对话消息",
 "气泡外观": {"气泡背景": "#F5F7FA", "用户气泡背景": "#409EFF", "气泡文字颜色": "#303133",
               "用户气泡文字颜色": "#FFFFFF", "气泡圆角": 8, "字号": 14}}
```

- 颜色一律十六进制（带不带透明度都行）；`字号`/`项圆角` 是数字（px）；`单元格内边距`/`项内边距` 最多四段，每段数字带 `px`/`%`/`em`。
- 形状不对直接 `内容不合法`，不静默忽略、不截断。

### 悬停放大与筛选

```json
{"类型": "行", "放大": {"峰值": 1.58, "半径": 120}, "子": [
  {"类型": "图标", "图形": "/资源/系统界面/系统图标/文件管理.svg", "名称": "文件"}
]}

{"类型": "输入", "名称": "启动器搜索", "占位文本": "搜索应用", "筛选目标": "启动器应用区"}

{"类型": "列", "标识": "启动器应用区", "筛选区": "启动器应用区", "子": [
  {"类型": "按钮", "文字": "系统自带", "筛选分类": "系统自带", "可选中": true,
   "选中背景": "#FFFFFFDB", "选中文字颜色": "#141C2AEB"},
  {"类型": "图标", "图形": "/资源/系统界面/系统图标/文件管理.svg", "名称": "文件", "筛选值": "系统自带"}
]}
```

- `放大`：`峰值` 1.0–2.5、`半径` 20–400（px）；容器内 `.hs-tree-icon` 按鼠标横向距离做 cos² 衰减放大，邻居跟着让位。
- `筛选区` 是能被筛的那片容器；`筛选值` 让节点可被筛；输入框用 `筛选目标` 指向筛选区的标识按文字筛；按钮用 `筛选分类` 按 `筛选值` 相等筛，值为「全部」时不按分类筛。
- 三级（区 / 项 / 控件）都不写就不附脚本。
- 可选中不限于图标：按钮与文字也能 `可选中`，选中态可用 `选中背景`/`选中描边`/`选中文字颜色`。
- 控件（按钮/输入）的 `文字颜色`/`字号`/`字重`/`内边距` 也归声明，不必靠中性皮肤。

### 状态类开关（窗口聚焦 / 表格斑马 / 图标选中）

```json
{"类型": "窗口", "标识": "应用窗口_示例", "标题": "示例"}

{"类型": "表格", "列": ["名称"], "行来源": "文件数据",
 "斑马纹": true, "斑马纹色": "#FAFAFA", "表头固定": true, "最大高度": 560}

{"类型": "图标", "图形": "/资源/系统界面/系统图标/文件管理.svg", "名称": "文件",
 "可选中": true, "选中背景": "#0EA5E92E", "选中描边": "#7DD3FC75"}
```

- 窗口：不必声明任何开关就会有聚焦态 —— 点标题栏/开窗/最大化后该窗成为当前窗，其余窗的按钮转灰（`--hs-win-dim`，缺省 `#D6D6D6`）、阴影降到 `0 6px 20px rgba(0,0,0,.16)`。
- 表格：`斑马纹` 上偶数行底色（`斑马纹色`，缺省 `#FAFAFA`）；`表头固定` 配 `最大高度`（80–4000px）让容器滚动、表头吸顶。
- 图标：`可选中` 后才可被点选，同片区（画布或网格）只保留一个；选中色缺省是通用蓝。
- 三个开关都不写就不出对应行为，页面也不附多余脚本。

### 应用窗口

4928 的输入字节上限为 1048576，输出字节上限为 4194304；其余能力仍各限 65536。组件树的深度和节点上限仍为 32 / 2000，超限返回资源受限，不截断。


窗口放在 `画布` 里，`画布` 给它的 `左/上/宽/高` 就是初始位置和大小；图标或文字写 `"打开窗口": "<窗口标识>"` 即可开窗；`切换显隐` 仅用于悬浮层。

```json
{"类型": "画布", "宽": "100vw", "高": "100vh", "子": [
  {"类型": "窗口", "标识": "办公文档", "标题": "办公文档",
   "左": "calc(50% - 460px)", "上": 86, "宽": 920, "高": 620,
   "初始隐藏": true, "背景": "#FFFFFFF2", "圆角": 13, "阴影": "浮层",
   "边框": "1px solid", "边框颜色": "#0000001A",
   "标题栏背景": "#F6F7F9", "标题栏文字颜色": "#1D1D1F", "标题栏高": 38,
   "子": [{"类型": "文字", "文本": "窗口正文"}]}
]}
```

语义与变量：

- 开窗只显示 + 置顶（不会误关）；关窗只认标题栏 ✕。
- `可最小化: 真` 出「—」键，点一下收起为标题栏，再点还原；`可最大化: 真` 出「▢」键，点一下铺满画布、再点回到原位。
- `可移动: 真` 才能拖标题栏；为假时窗口固定，点它仍然置顶。
- 三个按钮缺省只出关闭，其余按变量决定；声明里不写就是缺省，JSON 不为默认值付字节。
- 拖拽移动的是画布给的定位外壳，不改变声明的初值；窗口出现时底座才附窗口脚本，没有窗口的页面不带脚本。

## 超级列表框

超级列表框仍是 `类型:表格`，不新增组件类型或能力号。表头、数据、排序、分页、选择、行列集合、编辑和事件全部复用 4928 渲染、4929 操作、4930 状态、4931 释放。

### 声明属性

- 数据结构：`列`、`行`；`报表列`作为 `列` 的同义声明字段。
- 表格属性：`列宽`、`列对齐方式`、`排序方式`、`可排序`/`表头可单击`、`选择模式`，以及兼容属性 `单一选择`、`整行选择`、`是否有检查框`。
- 外观属性：`无表头`、`显示表格线`、`标题自动换行`、`表列可拖动`、`平面滚动条`、`图标对齐方式`、`视图模式`、`自动排列图标`、`始终显示选择项`。
- 图标与行属性：`表头图片组`、`图片组`、`状态图片组`、`热点跟踪`、`手形指针`、`标注热点`、`标注非热点`、`__表项缩进`、`允许编辑`、`结束编辑文本`。
- 可排序表头常显 ▲/▼ 两个独立按钮，分别指定升序/降序；`列宽` 写像素即定死，写 `自适应` 由底座按全部行最宽内容算成固定像素，浏览器只贴不算，排序翻页不改宽。`换页` 写假即不分页、全部展示。
- `条目行高`：表行高度像素值（20–200）；不写则按内容行高。表头下沿拖动改整体行高，松手写回本字段。
- `列提示`：与列等长的文本数组，写到表头 `title`，鼠标悬停见表头提示。
- `图标间距`：图标视图（大图标/小图标）的项间距像素（0–40，缺省 8）。
- 表项提示经 `设置表项提示` 写入，落在行 `title`，长内容不用撑宽列也能看全。
- `勾选列`：真时在行首显示检查框；`检查框状态` 是与行等长的逻辑值或 0/1 数组，与行选择独立。
- `结束编辑文本` 是 4930 运行时只读结果；编辑操作支持 `批准:false` 拒绝进入或放弃改值。
- `图标对齐方式` 为 `上/左/中/右`；图片使用同源 URL/null；完整字段与 Web 映射边界见项目权威《表格参数与传参样张》。

### 4929 操作原子

- 行：`插入行`、`追加`、`删除行`、`全部删除`、`设置单元格`/`置标题`、`设置表项数值`/`置表项数值`、`设置表项图片`/`置图片`、`设置状态图片`/`置状态图片`、`设置表项缩进`/`置缩进数目`。
- 列与行高：`插入列`、`删除列`、`设置列标题`/`置列标题`、`设置列宽`/`置列宽`、`设置行高`/`置行高`、`设置列对齐`、`设置列图片`/`置列图片`、`移动列`。
- 提示：`设置表项提示`/`置表项提示`、`设置列提示`/`置列提示`。
- 拖动改宽：表头右沿拖动改单列列宽（40–2000），表头下沿拖动改整体行高（20–200），拖动中实时预览、松手写回；不改 `表列可拖动` 也能拖宽。

### 事件原子

`当前表项被改变`、`表项被激活`、`表头被单击`、`表项跟踪`、`左键单击表项`、`右键单击表项`、`开始编辑`、`结束编辑`、`检查框状态被改变`由公共引导脚本采集，统一经 `记录事件` 写入 4930 的 `最后事件`；底座不执行业务回调。

### 状态与错误

- `读组件状态`（4930）：除排序键、方向与页码外，表格会返回 `选中项`、`选中数`、`选中行序号`、`选中行`、`行数`、`列数`、`行`、`列`、`查询结果`和已声明的列/行状态；表项索引从 0 开始，保持原始数据顺序，不随排序或翻页改变。
