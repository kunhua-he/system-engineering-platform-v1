# 网页界面支持库

## 原理

HTTP参数 → 数据槽 → 本库生成面 → 成品HTML文本 → HTTP返回。

界面是原子能力：任何项目接入底座即得到同一套外观，不必各自携带 Vue、Element Plus 一类前端框架。
本库只做「按声明生成HTML」，不读文件、不连网络、不存状态。

## 视觉基准

样式全部内联在返回的HTML里，取值照抄 V3 前端（唯一真源 `src/视觉基准.rs`）：

- 业务区（Element Plus 观感）：主色 `#409eff`（hover `#337ecc`、浅底 `#ecf5ff`），成功 `#67c23a`、警告 `#e6a23c`、危险 `#f56c6c`、信息 `#909399`；页面底 `#f0f2f5`、卡片 `#fff`、边框 `#e4e7ed`；文字 `#303133` / `#606266` / `#909399` / 占位 `#c0c4cc`；圆角 4 / 8 / 12px。
- 桌面外壳（macOS 观感）：菜单栏 30px 材质 `rgba(255,255,255,0.08)`；Dock 高 66px、圆角 18px、底部留 12px、材质 `rgba(255,255,255,0.22)`；窗口圆角 13px、材质 `rgba(246,246,248,0.97)`；系统蓝 `#0a84ff`；控件圆角 6px、菜单 12px、弹层 14px、面板 16px。
- 布局：侧栏 240px 白底右侧边框，标题 20px 内边距 / 18px 字号 / 主色 / 字距 2px；菜单项高 48px，激活态浅主色底 + 主色字 + 右侧 3px 主色边；顶栏 60px 白底；内容区 24px 内边距。
- 字体：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`。

## 调用

- 4910 渲染页面骨架：页面标题文本、主题标识文本、区块定义原文。返回含内联样式的整页HTML。
  区块定义是JSON对象，形如 `{"区块":[{"类型":"标题栏","文本":"文件条目"},{"类型":"数据表格","列":["名称","扩展名"],"行":[["美业门店营收的七项修炼","pptx"]]}]}`。
  支持区块类型：标题栏、数据表格、表单、对话框、文字。
- 4911 渲染数据表格：列定义原文（形如 `["用户名","角色"]`）、行定义原文（形如 `[["admin","admin"]]`）。返回表格HTML片段。
- 4912 渲染表单：字段定义原文（形如 `[{"名":"用户名","标签":"用户名"}]`）、当前值原文（形如 `{"用户名":"admin"}`）。返回纵向表单HTML片段。
- 4913 渲染对话框：对话框标题文本、对话框内容文本、按钮定义原文（形如 `[{"标签":"确定","动作":"确认"}]`）。返回对话框HTML片段，按钮右对齐。
- 4914 渲染侧栏布局：侧栏标题文本、侧栏条目表原文（形如 `[{"名称":"文件清单","图标":"📁","激活":true}]`）、顶栏标题文本、区块定义原文（同4910的区块定义）。返回整页HTML：240px侧栏 + 60px顶栏 + 内容区，侧栏条目按 `激活` 高亮。
- 4915 渲染桌面外壳：品牌文本、桌面图标表原文（形如 `[{"名称":"文件清单","图标":"📁"}]`）、窗口标题文本、窗口内容原文、菜单条目表原文（形如 `[{"名称":"文件","条目":[{"名称":"关于","动作":"about"}]}]`）。返回整页HTML：30px菜单栏（顶层菜单悬停展开条目）+ 桌面图标网格 + 居中静态窗口（红黄绿三键为装饰）+ 66px Dock（取桌面图标前10个）。
  **窗口内容原文按HTML片段原样内嵌**（同一次请求里由本库 4911/4914 等能力生成的成品），其余参数一律转义；调用方不得把外部不可信文本塞进该参数。
- 4916 渲染输入控件：控件种类文本（文本框 / 密码框 / 数字框 / 下拉选择）、控件名称文本、控件配置原文（形如 `{"标签":"账号","缺省值":"","占位文本":"请输入账号","选项列表":["华世王镞","俏小喵"]}`）。返回单个控件HTML片段，标签在上。
- 4917 渲染按钮：按钮标签文本、按钮动作文本、按钮样式文本（主要 / 默认 / 成功 / 警告 / 危险）。返回单个按钮HTML片段；动作写进 `data-action`，点击行为由调用方脚本处理。

- 4918 渲染登录页：登录标题文本、登录副标题文本、登录配置原文（形如 `{"图标字形":"✦","账号占位文本":"请输入账号","密码占位文本":"请输入密码","按钮文本":"登 录","错误提示文本":"","提交地址":"/登录","账号字段名":"用户名","密码字段名":"密码","页脚提示文本":""}`）。返回整页HTML：渐变背景 + 420px 卡片 + 图标/标题/副标题 + 两输入框 + 全宽主按钮；错误提示非空时才输出红色条。
- 4919 渲染桌面菜单栏：品牌文本、应用名称文本、菜单条目表原文（形如 `[{"键":"启动器","名称":"启动器"}]`）、状态区条目表原文（形如 `[{"名称":"通知","徽标":"3"}]`）。返回菜单栏片段：左品牌/应用/菜单，右状态区/徽标/空时钟（时钟由 4923 脚本填）。
- 4920 渲染桌面图标区：图标分组表原文（形如 `[{"分类":"系统应用","图标":[{"键":"系统设置","名称":"系统设置","图标":"⚙"}]}]`）、选中图标键文本。返回图标层片段：每组一列、随分组序号右移 112px，选中项带 `is-selected`。
- 4921 渲染桌面图标坞：坞条目表原文（形如 `[{"键":"访达","名称":"访达","图标":"🗂"}]`）、运行中键表原文（形如 `["设置"]`）。返回 Dock 片段：固定图标 + 运行中指示点；条目里 `{"分隔":"真"}` 输出分隔条。
- 4922 渲染窗口：窗口编号文本、窗口定义原文（形如 `{"标题":"系统设置","内容原文":"<div/>","横坐标":120,"纵坐标":96,"宽度":760,"高度":520,"层级":100,"状态":"普通","活跃":true}`）。返回单窗口片段：标题栏三键 + 标题 + 内容区，`状态` 为「最小化」时带 `is-minimized`。
- 4923 渲染桌面交互脚本：脚本配置原文（形如 `{"窗口接口":"/接口/窗口"}`）。返回内联 `<script>`：双击图标开窗（向窗口接口取片段）、窗口拖动、点击激活并提升层级、三键关闭/最小化/最大化、Dock 点击切换、F4 开关启动器、时钟每 30 秒刷新。接口地址只保留路径字符，不以 `/` 开头即回落缺省值。
- 4924 渲染完整桌面：品牌文本、桌面配置原文（形如 `{"应用名称":"访达","菜单条目表":[],"状态区条目表":[],"坞条目表":[],"运行中键表":[],"壁纸值":"","窗口接口":"/接口/窗口"}`）、图标分组表原文、窗口列表原文（形如 `[{"标题":"系统设置","内容原文":"<div/>","横坐标":120,"纵坐标":96}]`）。返回整页桌面：壁纸 + 菜单栏 + 图标区 + 窗口层（`#hs-win-layer`）+ Dock + 交互脚本，一次成型。
- 4925 渲染启动器：面板标题文本、启动器配置原文（形如 `{"搜索占位文本":"搜索应用","应用条目表":[{"键":"系统设置","名称":"系统设置","图标":"⚙"}]}`）。返回默认隐藏的 `#hs-launchpad` 全屏磁贴面板，显示与搜索过滤由 4923 脚本处理。

- 4926 渲染区块组：区块定义原文（形如 `{"区块":[{"类型":"标题栏","文本":"文件清单"},{"类型":"数据表格","列":[],"行":[]}]}`）。返回区块片段（不套整页外壳），供窗口内容与局部刷新使用。

所有文本参数一律经过HTML转义后再输出；`<`、`>`、`&`、`"`、`'` 均按实体写出，不做白名单放行（4915 的窗口内容原文是唯一例外，见上）。

## 边界与错误

- 4921 参数不合法；4922 内容不合法（JSON解析失败、形状不符、区块类型/控件种类/按钮样式不认识）；4923 资源受限（超上限）。
- 表格至多64列、4096行；表单至多128字段；对话框至多8按钮；页面骨架与侧栏布局各至多64区块；侧栏条目至多64条；桌面图标至多64个；菜单条目至多16组。
- 输入与输出各限65536字节：整页HTML超过该上限会回资源受限，调用方应分区块取片段后再组装。
- 4910–4922 只生成静态HTML；4923 与 4924 会注入内联交互脚本（窗口拖动、开窗、三键、Dock 切换、启动器、时钟），脚本只访问本页 DOM 与配置里给出的窗口接口，不引外部资源；菜单条目的 `键` 以 `/` 开头时按普通链接跳转（如 `/logout`），键为「启动器」时打开启动器。业务页面的提交行为仍由调用方处理。

## 正式验证

用真实HTTP调用八个能力，断言返回状态、返回类型与正文关键字（含 `#409eff`、`66px`、`13px` 等基准值），不以「/接口 200」代替。

### 4927 渲染聊天消息流

把聊天记录排成气泡列表：用户靠右（角色写 `user` 或 `用户`）、助手靠左，内容纯文本转义，空数组出空态。

```json
{
  "参数": {
    "聊天定义原文": "{\"空态文案\":\"还没有消息\",\"消息\":[{\"角色\":\"user\",\"内容\":\"你好\",\"时间\":\"2026-11-01 10:00\"},{\"角色\":\"assistant\",\"内容\":\"在的，请说\",\"时间\":\"2026-11-01 10:01\"}]}"
  }
}
```

返回 HTML 片段：`.hs-chat` 容器 + `.hs-chat-msg.is-user/.is-assistant` 气泡，直接塞进窗口内容或区块。

### 4928 渲染组件树

一棵可递归嵌套的节点树 → HTML 片段。**这是唯一的通用拼装入口**：窗口内容、整页、面板都由它出，
4910 骨架 / 4914 侧栏 / 4926 区块组 都只是它的预置写法。

```json
{
  "参数": {
    "树定义原文": "{\"根\":{\"类型\":\"侧栏\",\"栏宽\":240,\"标题\":\"对话\",\"菜单\":[{\"名称\":\"新对话\",\"图标\":\"💬\",\"激活\":true}],\"子\":[{\"类型\":\"列\",\"间距\":12,\"子\":[{\"类型\":\"标题\",\"文本\":\"最近对话\"},{\"类型\":\"聊天流\",\"消息\":[{\"角色\":\"user\",\"内容\":\"你好\"}],\"空态文案\":\"还没有消息\"}]}]}}"
  }
}
```

**容器（可无限嵌套）**

| 类型 | 作用 | 专有字段 |
|---|---|---|
| `行` | 水平排列 | `水平对齐` `垂直对齐` |
| `列` | 垂直排列 | `水平对齐` `垂直对齐` |
| `网格` | 等分网格 | `列数`（1–24） |
| `侧栏` | 左栏 + 主区 | `栏宽` `标题` `菜单`（`名称`/`图标`/`激活`） |
| `分区` | 带标题的区块 | `标题` |
| `画布` | 绝对定位平面 | 子节点带 `左` `上` `宽` `高` |
| `悬浮层` | 覆盖整页的浮层，可按快捷键或声明切换显隐 | `标识`（字母数字/`-`/`_`/汉字，≤32）`初始隐藏` `快捷键`（≤8 字符） |
| `窗口` | 桌面内的应用窗口，带标题栏与关闭键，可拖动、点一下置顶 | `标识`（同上）`标题` `初始隐藏` `标题栏背景` `标题栏文字颜色` `标题栏高`（24–64）`显示关闭` |

**叶子**：`标题` `文字` `图标`（`图形`/`名称`/`打开地址`/`显示名称`）`表格`（`列`+`行`）`表单`（`字段`+`值`）`输入` `按钮` `聊天流`（`消息`+`空态文案`）`分隔条` `原样`（`html` 不转义，上限 200KB）

**图标**：`图形` 写 emoji 或同源图片路径（`/静态资源/…`）；`打开地址` 只认同源路径，点击即跳转；`显示名称` 默认 真，写 假 则只出图形。

**链接**：`文字` 与 `侧栏` 菜单条目都能带 `打开地址`（同源路径），出 `<a>`；不带就出纯展示元素。

**显隐切换**（任何节点都能带）：`"切换显隐": "启动器"` —— 点击该节点切换同标识悬浮层的显隐；悬浮层写 `"快捷键": "F4"` 则由键盘开合。整页模式在需要时自动附一段通用脚本，没有这类声明就不出脚本。

**示例：桌面（菜单栏 + 图标 + 坞 + F4 启动器）**

```json
{"整页": true, "页面标题": "桌面", "根": {
  "类型": "画布", "宽": "100vw", "高": "100vh",
  "背景": {"类型": "图片", "资源": "/静态资源/壁纸/a.svg"},
  "子": [
    {"类型": "行", "左": 0, "上": 0, "宽": "100%", "高": 30, "内边距": "0 12px",
     "水平对齐": "两端", "背景": "#FAFAFC9E",
     "子": [{"类型": "文字", "文本": "品牌"},
            {"类型": "文字", "文本": "启动器", "切换显隐": "启动器"}]},
    {"类型": "图标", "左": "calc(100% - 120px)", "上": 60, "宽": 88, "高": 92,
     "图形": "📁", "名称": "文件", "打开地址": "/files"},
    {"类型": "悬浮层", "标识": "启动器", "快捷键": "F4", "背景": "#161A226B",
     "子": [{"类型": "网格", "列数": 7, "子": [{"类型": "图标", "图形": "📁", "名称": "文件", "打开地址": "/files"}]}]}
  ]}}
```

**表单相关**

| 类型 | 作用 | 字段 |
|---|---|---|
| `表单容器` | 出 `<form>`，子节点即表单控件 | `标识` `提交地址`（必须同源路径）`方式`（POST / GET） |
| `输入` | 单个输入框，带标签 | `种类`（文本框 / 密码框 / 数字框 / 邮箱）`名称` `标签` `占位文本` `必填` `自动填充` |
| `按钮` | 按钮，可声明为提交按钮 | `文字` `动作` `提交`（真 = type=submit）`表单`（目标表单标识）`样式`（主要 / 默认 / 成功 / 警告 / 危险） |

**整页**：树定义顶层加 `"整页": true` 与 `"页面标题"`，返回带文档头、基准样式的完整页面（不再是片段），调用方不必再拼文档头。

**通用属性**（任何节点都能带）：`宽` `高` `间距` `内边距` `背景` `圆角` `边框` `溢出` `最小高` `边框颜色`
（数字按 px，字符串原样如 `"100%"`）

**背景取值**

- 纯色：字符串，只接受 `#RGB` / `#RRGGBB` / `#RRGGBBAA`
- 线性渐变：`{"类型":"线性渐变","角度":135,"颜色节点":[{"颜色":"#000000","位置":0},{"颜色":"#ffffff","位置":100}]}`（2–16 个节点，位置 0–100 且递增）
- 图片：`{"类型":"图片","资源":"/静态资源/xxx.svg"}`（只接受同源路径，拒 `//`、`..`、协议头）

颜色与背景走白名单校验：不是颜色值、不是同一套渐变形状，一律回内容不合法，不回退成默认外观。

**防爆上限**：深度 32 层、节点 2000 个 —— 产品语义上嵌套不限层数，这两道闸只拦写坏的树。

### 应用窗口

4928 的输入字节上限为 1048576，输出字节上限为 4194304；其余能力仍各限 65536。组件树的深度和节点上限仍为 32 / 2000，超限返回资源受限，不截断。


窗口放在 `画布` 里，`画布` 给它的 `左/上/宽/高` 就是初始位置和大小；图标或文字写 `"打开窗口": "<窗口标识>"` 即可开窗；`切换显隐` 仅用于悬浮层。

```json
{"类型": "画布", "宽": "100vw", "高": "100vh", "子": [
  {"类型": "窗口", "标识": "办公文档", "标题": "办公文档",
   "左": "calc(50% - 460px)", "上": 86, "宽": 920, "高": 620,
   "初始隐藏": true, "背景": "#FFFFFFF2", "圆角": 13, "阴影": "浮层",
   "边框": "1px solid", "边框颜色": "#0000001A",
   "标题栏背景": "#F6F7F9", "标题栏文字颜色": "#1D1D1F", "标题栏高": 38,
   "子": [{"类型": "文字", "文本": "窗口正文"}]}
]}
```

语义：开窗只显示 + 置顶（不会误关）；关窗只认标题栏那个 ✕；拖拽只认标题栏，移动的是画布给的定位外壳，不改变声明的初值。窗口只在页面里出现时底座才附拖拽脚本，没有窗口的页面不带脚本。
