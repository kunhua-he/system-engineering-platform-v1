# 网页界面支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 4 个接口。

---

## 4928 · 渲染组件树

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4928,
 "命名值": {
  "树定义原文": ""
 }
}
```

**这个接口干什么**

把一棵可递归嵌套的组件树渲染成HTML片段或整页：容器（行、列、网格、侧栏、分区、画布）任意嵌套，叶子出标题、文字、图标、表格、表单、输入框、按钮、聊天流与原生片段；表格支持逐列宽度、对齐、文本/数值/日期排序、单选/多选/整行选择、勾选框与分页；悬浮层与任何节点都能声明切换显隐（可带快捷键）；窗口容器在桌面内开窗，标题栏可拖动、点窗口自动置顶；关闭/最小化/最大化与可移动都是声明变量（缺省只出关闭、可移动），开窗只加不切换；整页模式按需附通用脚本；表单容器与图标地址只认同源；颜色与背景按白名单校验；深度32层、节点2000个为防爆上限。

**参数**

- 树定义原文 · 文本 · 必填

**返回**

返回类型：文本。

## 4929 · 操作组件

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4929,
 "命名值": {
  "组件句柄": 1,
  "操作名": "",
  "参数原文": ""
 }
}
```

**这个接口干什么**

按组件句柄执行统一操作；表格支持行列增删改查、选择与独立检查、图片缩进、编辑、排序分页、保证显示和事件记录。返回当前片段与句柄组，纯事件记录不重绘；句柄无效报4924。

**参数**

- 组件句柄 · 句柄 · 必填 — 渲染组件树时签发的组件句柄
- 操作名 · 文本 · 必填 — 通用组件操作或表格专用原子方法；完整方法及参数见使用说明
- 参数原文 · 文本 · 必填 — JSON对象；行列方法传行序号或列序号及对应值，查询结果从4930读取；事件传事件名及行列上下文

**返回**

返回类型：文本。

返回内容：返回当前片段与句柄组，纯事件记录不重绘

## 4930 · 读组件状态

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4930,
 "命名值": {
  "组件句柄": 1
 }
}
```

**这个接口干什么**

读取组件实例状态；表格回传排序页码、行列数据、选中原始行、检查状态、图片缩进、查询结果、只读结束编辑文本及最近32条事件记录。

**参数**

- 组件句柄 · 句柄 · 必填 — 渲染组件树时签发的组件句柄

**返回**

返回类型：文本。

## 4931 · 释放组件句柄

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4931,
 "命名值": {
  "组件句柄": 1
 }
}
```

**这个接口干什么**

释放一个组件句柄；不存在返回假，幂等。页面卸载或会话结束时调用，组件实例用完即弃、不常驻。

**参数**

- 组件句柄 · 句柄 · 必填 — 要释放的组件句柄

**返回**

返回类型：逻辑型。

返回内容：返回假，幂等

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
