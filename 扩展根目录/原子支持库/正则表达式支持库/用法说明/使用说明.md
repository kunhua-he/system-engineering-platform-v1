# 正则表达式支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 4 个接口。

---

## 4401 · 提取匹配

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4401,
 "命名值": {
  "表达式": "",
  "原文": ""
 }
}
```

**这个接口干什么**

Unicode正则匹配、字面替换及分割；模式4096字节、文本和输出65536字节、匹配或片段最多1000。

**参数**

- 表达式 · 文本 · 必填
- 原文 · 文本 · 必填

**返回**

```json
[
 "示例"
]
```

（上面的样例是现场发请求调出来的）

## 4404 · 解析区间

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4404,
 "命名值": {
  "区间文本": "",
  "模式": ""
 }
}
```

**这个接口干什么**

解析区间：集合模式把「1-5,7,10~12」展开为升序去重的数值列表；范围模式只收单段，返回起始与结束（单值即首尾相等）。空文本与全非法段按无效返回，模式非法或数值越界给 4401，超限给 4403。

**参数**

- 区间文本 · 文本 · 必填
- 模式 · 文本 · 必填

**返回**

返回类型：生成结构。

返回内容：返回起始与结束（单值即首尾相等）

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
