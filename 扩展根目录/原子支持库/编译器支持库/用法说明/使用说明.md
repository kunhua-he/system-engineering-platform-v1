# 编译器支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 8 个接口。

## 1101 · 词法分析

**请求参数模板**（把值改成你的就能直接发）

```json
{

 "命名值": {

```

**这个接口干什么**

**参数**

- 程序文本 · 文本 · 必填 — 我们的程序文本（原生格式）：UTF-8 · 行式 · 换行写出 LF（读入认 CRLF）· 缩进 4 个半角空格 · 关键字以 `.` 开头（少数不带点：`返回` `置入代码`）· 注释 `'` 至行尾（不含行尾换行）· 文本字面量写出全角引号（读入认半角）· 常量 `#名字` · 运算符全角（`＝` `＋` `÷`）· 界符半角（`( ) [ ] , . & { }`）· 逗号间的空实参是有意义的位次。文本里写名字，结构里存号

**这个接口干什么**

## 1104 · 生成容器

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 1104,
 "命名值": {
  "容器结构": ""
 }
}
```

**这个接口干什么**

把容器结构写成 .e 容器字节。**这是 .e 导入导出（互操作）那条路，不是原生路**——原生路的产物是我们的程序文本。入参是本库的容器结构边界编码（字节集），出参是 .e 容器字节（字节集）。判据：① 生成(反解(x)) == x 逐字节相同；② **本能力回填既有段集时接受 `6`/`7`，但 V1 自身构造的新段一律不取 `6`/`7`** —— 参照实现写侧不产生这两个号（写段例程 15 处 `push <类型标签>` 独缺类型 6；易语言侧取证），产出参照实现不会产出的形状会让互操作路出现单侧形状。

**参数**

- 容器结构 · 字节集 · 必填 — 本库的容器结构边界编码（段表：校验和 · 段类型 · 段名 · 数据）

**返回**

返回类型：字节集。

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
