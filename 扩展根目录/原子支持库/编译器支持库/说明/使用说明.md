# 编译器支持库 · 使用说明

上级：`扩展根目录/原子支持库/` ／ 能力号段：1101–1199

## 怎么用

后端是能力，走调用接口面调；前端是纯 UI，只做「取文本 → 调能力 → 显示」。

| 想做什么 | 调哪个号 |
|---|---|
| 只检查语法 | 1101 → 1102 |
| 检查类型与命令是否存在 | 1101 → 1102 → 1103 |
| 出一份产物 | 1106（一步到底） |
| 把已有产物读回来 | 1105 |
| 看错误说明 | 1107 |

## 错误怎么读

所有错误都是**结构化段位**（不是字符串）。段位编法见 `契约声明/格式说明.md` 第五节，每一条都在 `契约声明/错误码表/` 登记了「归属 · 可重试 · 可自愈 · 需人工」四项。
