.判断开始 (消息 ＝ 1)  ' 请求装填表项数据
    ' ----关于返回值 若以下看不懂emmm 那就 是装载一次就不管的数据 返回 1  要实时更新的 数据全部跟随数据源就返回 0 当数据源变更时 发送重画消息   有部分静态数据的就返回 -1  ----
    ' 警告 取项目数据 元素数据 会触发此事件  故本事件内 不能再调用 获取项目数据命令 以免造成死循环
    .判断开始 (参数4 ＝ 0)  ' 在装填数据时 需要将 项目数据全部装填(通常如此)
        返回 (1)  ' 返回>0的值 若本次装载后 本项目数据不需要二次更新时 返回 > 0 的值 则之后本项目不在触发此事件

        ' 另 当在本事件外有更改 下次更新模式(本参返回值)时  可通过发送消息 设定自定义值
        返回 (0)  ' 返回0 下次还是走到这里

    .判断 (参数4 ＝ -1)  ' 小于0时  代表项目数据已经全部装载过一次 可根据需求 设定部分动态值 静态数据维持不变


        ' 返回值功能同上
