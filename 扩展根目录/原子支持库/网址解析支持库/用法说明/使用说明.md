# 网址解析支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 4 个接口。

---

## 4201 · 规范化网址

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4201,
 "命名值": {
  "网址文本": ""
 }
}
```

**这个接口干什么**

按URL Standard解析与相对地址合并，不发起网络请求。查询参数输出字符串键值对数组JSON文本，保留重复键及顺序；表单查询语义中加号解为空格，与URI组件解码区分。

**参数**

- 网址文本 · 文本 · 必填

**返回**

```json
"https://example.com/a?b=1"
```

（上面的样例是现场发请求调出来的）

## 4204 · 提取外部标识

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4204,
 "命名值": {
  "输入文本": "",
  "来源类型": ""
 }
}
```

**这个接口干什么**

按来源类型从网址或标识文本中取出规范外部标识，返回JSON文本。边界判定用长度与后继字符手写实现，不依赖正则前瞻（本平台正则引擎不支持lookahead）。

**参数**

- 输入文本 · 文本 · 必填 — 网址、裸标识或含标识的文本
- 来源类型 · 文本 · 必填 — 闭合枚举：youtube / arxiv

**返回**

返回类型：文本。

返回内容：返回JSON文本

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
