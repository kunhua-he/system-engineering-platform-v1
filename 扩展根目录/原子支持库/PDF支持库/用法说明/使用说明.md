# PDF支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 5 个接口。

---

## 6601 · 检测PDF加密页数

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6601,
 "命名值": {
  "文件路径": ""
 }
}
```

**这个接口干什么**

读取PDF总页数、是否加密与可否打开；文件至512MiB、页数至20000；加密文档只报加密不尝试解密；返回JSON文本。同步本机计算，热调用约0.05秒。

**参数**

- 文件路径 · 文本 · 必填 — 网关闭机器可读的PDF普通文件绝对路径；不按cwd解释相对路径

**返回**

返回类型：文本。

返回内容：返回JSON文本

## 6602 · 渲染PDF页面

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6602,
 "命名值": {
  "文件路径": "",
  "页序号": "",
  "输出路径": "",
  "倍率": ""
 }
}
```

**这个接口干什么**

把指定页按倍率渲染成PNG落盘，返回输出路径、宽高与字节数；倍率0.1至8、单边至20000像素、总像素至1亿；页序号从0开始；不修改源PDF。

**参数**

- 文件路径 · 文本 · 必填 — PDF绝对路径
- 页序号 · 文本 · 必填 — 从0开始的整数文本，须小于总页数
- 输出路径 · 文本 · 必填 — PNG落盘绝对路径，父目录不存在则创建；同名覆盖
- 倍率 · 文本 · 必填 — 相对72dpi的缩放，0.1至8；空串取2.0

**返回**

返回类型：文本。

返回内容：返回输出路径、宽高与字节数

## 6603 · 提取PDF页内嵌图

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6603,
 "命名值": {
  "文件路径": "",
  "页序号": ""
 }
}
```

**这个接口干什么**

提取指定页内嵌JPEG图像并以base64返回，同时给出内嵌图数量；非JPEG编码（原始像素流等）如实列在未提取字段，不伪造像素；单图至24MiB、总量至80MiB、每页至64个XObject；支持嵌套Form递归至4层。

**参数**

- 文件路径 · 文本 · 必填 — PDF绝对路径
- 页序号 · 文本 · 必填 — 从0开始的整数文本

**返回**

返回类型：文本。

返回内容：返回，同时给出内嵌图数量

## 6604 · 校验PDF文件

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6604,
 "命名值": {
  "文件路径": ""
 }
}
```

**这个接口干什么**

校验PDF可解析性，返回是否合法、PDF版本、页数与加密状态；只读不修改；用于入库前把关，不替代完整合规校验。

**参数**

- 文件路径 · 文本 · 必填 — PDF绝对路径

**返回**

返回类型：文本。

返回内容：返回是否合法、PDF版本、页数与加密状态

## 6605 · 提取PDF文本

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6605,
 "命名值": {
  "文件路径": "",
  "页参数": ""
 }
}
```

**这个接口干什么**

逐页取 PDF 文本（PDFKit），返回页数、取页数、总字符数与每页 {页序号,字符数,文本}；all 取全部页、最多 2000 页；加密或扫描件取不到正文时如实报空串，不做 OCR 猜测；单次输出至 80MiB。

**参数**

- 文件路径 · 文本 · 必填 — PDF 绝对路径
- 页参数 · 文本 · 必填 — all 取全部页，或 0 起的单页序号

**返回**

返回类型：文本。

返回内容：返回页数、取页数、总字符数与每页 {页序号,字符数,文本}

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
