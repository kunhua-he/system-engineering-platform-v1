# PDF支持库

macOS Apple Silicon 原生 PDFKit 封装，路径式只读操作，不修改源文件。

## 能力（6601-6604）

- **6601 检测PDF加密页数**（文件路径）→ `{页数, 加密, 可打开}`
- **6602 渲染PDF页面**（文件路径, 页序号, 输出路径, 倍率）→ `{输出路径, 宽, 高, 字节数, 页序号, 倍率}`
- **6603 提取PDF页内嵌图**（文件路径, 页序号）→ `{内嵌图数量, 图像列表[{名称,编码,base64,字节数}], 未提取[]}`
- **6604 校验PDF文件**（文件路径）→ `{合法, 版本, 页数, 加密}`

## 错误码（6601-6608）

| 码 | 名称 | 可重试 |
|---|---|---|
| 6601 | 参数不合法 | 否 |
| 6602 | 文件不可读 | 否 |
| 6603 | 格式不支持（非PDF/加密打不开） | 否 |
| 6604 | 资源超限 | 否 |
| 6605 | 运行平台不支持 | 否 |
| 6606 | 处理失败 | 否 |
| 6607 | 处理超时 | 是 |
| 6608 | 页序号越界 | 否 |

## 上限

文件 512MiB、页数 20000、渲染倍率 0.1-8、单边 20000 像素、总像素 1 亿、每页 XObject 64、单图 24MiB、总量 80MiB。

## 部署要求

`PDF处理` 原生执行体必须与网关同目录（制品根），漏带时所有能力报 6605。首次冷启动约 1 秒，建议构建时预热。

## 不做什么

不加密、不合并、不拆分、不编辑页面内容；加密 PDF 只报 `加密:true`，不尝试绕过密码。
