# 技能执行支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 1 个接口。

## 8301 · 准备技能执行

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 8301,
 "命名值": {
  "执行参数": ""
 }
}
```

**这个接口干什么**

校验技能包并产出受控执行计划。查六件套完整性（SKILL.md/契约.json/工作流.json/scripts/验证声明.json/依赖.json）、入口脚本范围（canonicalize 后必须仍在该技能 scripts/ 内）、脚本静态安全边界（禁 subprocess/os.system/os.popen/os.spawn/os.exec/os.fork/pty.spawn/shell=True/eval(/exec(/__import__/importlib/ctypes/sys.modules/runpy/pickle.loads）与调用方给的禁止导入前缀；把参数写成临时文件，返回可直接提交给进程执行支持库 2601 的执行计划。**只校验只出计划，不起进程**。约 0.01 秒。

**参数**

- 执行参数 · 文本 · 必填 — JSON 文本：技能根目录（绝对路径）/ 能力标识（分类.技能名）/ 参数（字典）/ 项目根目录 / 禁止导入前缀（数组）/ 解释器（可空，空则 /usr/bin/python3）/ 超时秒数（可空，默认 120，范围 0.2-600）

**返回**

返回类型：文本。

返回内容：返回可直接提交给进程执行支持库 2601 的执行计划

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
