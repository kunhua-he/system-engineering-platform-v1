# 进程归属支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 2 个接口。

---

## 6401 · 判定进程归属

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6401,
 "命名值": {
  "进程表JSON": "",
  "归属登记JSON": "",
  "保护参数JSON": ""
 }
}
```

**这个接口干什么**

先证明归属再谈可清理：进程表＋归属登记＋保护参数 ⇒ 可清理／受保护／未核实三张表。归属登记两组都空即 6414（安全判据，绝不放行清理）。

**参数**

- 进程表JSON · 文本 · 必填 — 进程快照数组，元素 {"pid":123,"父pid":1,"命令行":"…"}
- 归属登记JSON · 文本 · 必填 — {"端口":[40118],"路径":["/…/模型目录"]}；两组都空 ⇒ 6414
- 保护参数JSON · 文本 · 必填 — {"保护端口":[43110],"保护程序":["launchd"]}；空串 = 全默认

**返回**

返回类型：文本。

## 6402 · 读取进程表

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6402,
 "命名值": {
  "筛选参数JSON": ""
 }
}
```

**这个接口干什么**

只读系统进程表：返回 pid／父pid／命令行，可按可执行名或命令行子串筛选。不做归属判定、不杀进程、不碰 launchctl —— 判定交 6401，回收交调用方。

**参数**

- 筛选参数JSON · 文本 · 必填 — {"可执行名":"llama-server","命令行含":"--port"}；空串 = 不筛选（返回全表）。可执行名按 basename 精确匹配，命令行含按子串匹配，两者同给取交集

**返回**

返回类型：文本。

返回内容：返回 pid／父pid／命令行，可按可执行名或命令行子串筛选

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
