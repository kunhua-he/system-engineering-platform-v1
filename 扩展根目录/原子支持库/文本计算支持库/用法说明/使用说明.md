# 文本计算支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 4 个接口。

---

## 6301 · 多重集对账

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6301,
 "命名值": {
  "源文本": "",
  "派生文本": "",
  "选项文本": ""
 }
}
```

**这个接口干什么**

按条目计次对账：返回 判定／源条数／派生条数／缺失表／多余表，重复段落按出现次数判定（集合比对会把重复段落当等值，这是原技能缺陷的根因）。

**参数**

- 源文本 · 文本 · 必填 — 基准原文；按行切分后逐条计数
- 派生文本 · 文本 · 必填 — 待对账的派生文本；与源文本同一套切分口径
- 选项文本 · 文本 · 必填 — JSON 对象文本；空串=全默认 {忽略空白:false,忽略大小写:false,按行切分:true}，未知键忽略

**返回**

返回类型：文本。

返回内容：返回 判定／源条数／派生条数／缺失表／多余表，重复段落按出现次数判定（集合比对会把重复段落当等值，这是原技能缺陷的根因）

## 6302 · 筛选时间窗行

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6302,
 "命名值": {
  "日志文本": "",
  "起始时刻": "",
  "结束时刻": "",
  "前缀长度": 19
 }
}
```

**这个接口干什么**

按真实时刻筛选日志行：起始/结束为闭区间，命中行给出 行号／时刻／正文，并回报无法解析行数；超过 50000 命中即截断并在 截断 字段为真。

**参数**

- 日志文本 · 文本 · 必填 — 多行日志；每行行首是时刻
- 起始时刻 · 文本 · 必填 — 窗口起点，格式 YYYY-MM-DD HH:MM:SS（闭区间）
- 结束时刻 · 文本 · 必填 — 窗口终点，格式同起始时刻，必须不早于起始
- 前缀长度 · 整数 · 可选 — 行首取多少字符作时间戳（必填，10..=32；网关不接受空槽入参，必须显式给值）。默认 19

**返回**

返回类型：文本。

## 6801 · 查询人格上下文

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6801,
 "命名值": {
  "主体标识": "",
  "岗位标识": "",
  "场景": "",
  "as_of": "",
  "known_at": ""
 }
}
```

**这个接口干什么**

以主体标识、岗位标识、可空场景、as_of和known_at构造只读GET请求，查询外部人格上下文；时点按RFC3339解析并在请求前转UTC，响应必须是原生JSON对象。

**参数**

- 主体标识 · 文本 · 必填 — 主体标识文本
- 岗位标识 · 文本 · 必填 — 岗位标识文本
- 场景 · 文本 · 必填 — 场景文本，可为空
- as_of · 文本 · 必填 — 带时区的RFC3339时点文本，内部转UTC
- known_at · 文本 · 必填 — 带时区的RFC3339时点文本，内部转UTC

**返回**

返回类型：文本。

## 6802 · 格式化可注入上下文

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6802,
 "命名值": {
  "上下文JSON文本": ""
 }
}
```

**这个接口干什么**

接收不超过65536字节的上下文JSON对象，只注已确认事实与观察，排除待确认、争议和矛盾内容，并保留证据边界与禁止推断，返回Markdown文本。

**参数**

- 上下文JSON文本 · 文本 · 必填 — 上下文JSON对象文本，最多65536字节

**返回**

```json
"# 可注入上下文\n"
```

（上面的样例是现场发请求调出来的）

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
