# 文件支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 24 个接口。

## 3101 · 取文件摘要

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 3101,
 "命名值": {
  "路径": ""
 }
}
```

**这个接口干什么**

读一个真实文件，返回字节数·行数·SHA-256；算法与行数口径内部固定，不给调用方选。

**参数**

- 路径 · 文本 · 必填 — 要读取的文件的绝对路径（文本）；相对路径一律拒（3004），不按服务进程 cwd 解析

**返回**

返回类型：生成结构。

返回内容：返回字节数·行数·SHA-256

## 3124 · 受控创建提交

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 3124,
 "命名值": {
  "受控工作区": "",
  "提交说明": "",
  "文件清单": ""
 }
}
```

**这个接口干什么**

仅在工作区通过全套校验后，按显式文件清单 `git add` 并提交。清单 1 至 100 项工作区相对路径，逐项解析为真实普通文件；暂存区与清单必须逐项完全相等才 commit，多一项少一项都拒绝且不提交。提交后回读 HEAD 与工作区状态，工作区不干净一律拒绝为成功。

**参数**

- 受控工作区 · 文本 · 必填 — 绝对路径的受控 Git 工作区根目录，须通过 v1-d4- 前缀、owner 标记与共用 git 目录校验
- 提交说明 · 文本 · 必填 — 非空、至 200 字符、不含换行与 NUL 等控制字符
- 文件清单 · 文本 · 必填 — JSON 字符串数组，1 至 100 项工作区相对路径；拒绝对路径、上跳、空串与 NUL

**返回**

返回类型：文本。

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
