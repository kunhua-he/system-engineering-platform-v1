# 数值计算支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 9 个接口。

---

## 1324 · 四舍五入

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 1324,
 "命名值": {
  "待处理数值": 0,
  "小数位": 0
 }
}
```

**这个接口干什么**

四舍五入到指定小数位。

**参数**

- 待处理数值 · 双精度 · 必填 — 要处理的数值
- 小数位 · 整数 · 可选 — 保留小数位。默认 0

**返回**

```json
{
 "结果": 1,
 "小数位": 0
}
```

（上面的样例是现场发请求调出来的）

## 1332 · 分位数

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 1332,
 "命名值": {
  "数值列表": {
   "类型标签": 100,
   "值": []
  },
  "百分位": 0,
  "小数位": 0
 }
}
```

**这个接口干什么**

线性插值百分位数（保证单调 P50≤P95≤P99≤max）；返回 分位数值/样本数/最小/中位/最大。

**参数**

- 数值列表 · 列表 · 必填 — 数值列表（整数或浮点数组），如 [1, 2, 3]
- 百分位 · 双精度 · 必填 — 0~1，如 0.95
- 小数位 · 整数 · 必填 — 结果保留小数位

**返回**

返回类型：生成结构。

返回内容：返回 分位数值/样本数/最小/中位/最大

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
