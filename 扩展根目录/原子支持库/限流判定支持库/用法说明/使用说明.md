# 限流判定支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 2 个接口。

---

## 6101 · 令牌桶判定

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6101,
 "命名值": {
  "桶容量": 0,
  "每秒补充": 0,
  "当前令牌数": 0,
  "上次补充时间": 0,
  "现在": 0,
  "取用数量": 0
 }
}
```

**这个接口干什么**

无状态令牌桶判定；参数时间为同一单调时钟秒值，容量及取用量为正整数，补充速率非负，令牌在容量内；返回放行和新状态，不持有业务来源或后台资源。

**参数**

- 桶容量 · 整数 · 必填
- 每秒补充 · 双精度 · 必填
- 当前令牌数 · 双精度 · 必填
- 上次补充时间 · 双精度 · 必填
- 现在 · 双精度 · 必填
- 取用数量 · 整数 · 必填

**返回**

返回类型：生成结构。

返回内容：返回放行和新状态，不持有业务来源或后台资源

## 6102 · 登录限速判定

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6102,
 "命名值": {
  "当前失败次数": 0,
  "最大失败次数": 0
 }
}
```

**这个接口干什么**

无状态失败计数阈值判定，次数非负，最大次数为正；达到上限返回逻辑真即锁定。存储和窗口由调用方负责。

**参数**

- 当前失败次数 · 整数 · 必填
- 最大失败次数 · 整数 · 必填

**返回**

返回类型：逻辑型。

返回内容：返回逻辑真即锁定

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
