# 网页解析支持库

HTML5静态解析，不执行脚本、不联网；提供标题、正文、CSS选择文本和属性列表，剔除正文的脚本及样式；输入输出65536字节，选择器4096字节，最多1000项。

- 4801 提取标题：HTML文本 → 类型标签4。
- 4802 提取正文：HTML文本 → 类型标签4。
- 4803 选择文本：HTML文本、CSS选择器 → 类型标签100。
- 4804 选择属性：HTML文本、CSS选择器、属性名 → 类型标签100。

调用经唯一HTTP能力入口；必须与本包声明的参数行序一致。纯CPU或网络I/O同步执行，典型4KiB输入估计微秒至毫秒（未实测），网络延迟另计；不承诺GPU加速。资源超限拒绝，不截断成成功。
