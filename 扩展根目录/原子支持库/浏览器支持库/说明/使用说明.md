# 浏览器支持库

Chrome DevTools 协议封装的无头浏览器，返回整数会话句柄按句柄复用；不做屏幕坐标模拟，不接管已登录的个人浏览器。

## 能力（7001-7006）

- **7001 创建会话**（临时根目录）→ 整数句柄本身（纯值，不套 JSON）
- **7002 导航**（会话句柄, 地址）→ `{地址, 标题, 加载状态}`
- **7003 读页面**（会话句柄, 读法, 选择器）→ 文本 / html / `{标题, 地址}` / `{找到, 文本, 标签, 属性, 可见}`
- **7004 操作元素**（会话句柄, 选择器, 动作, 值）→ `{选择器, 动作, 结果}`
- **7005 截图**（会话句柄, 输出路径）→ `{句柄, 输出路径, 字节数}`
- **7006 关闭会话**（会话句柄）→ `{句柄, 已关闭}`

## 错误码（7001-7012）

7001 参数不合法 / 7002 会话不存在 / 7003 启动失败 / 7004 连接失败 / 7005 协议不符 / 7006 指令失败 / 7007 元素未找到 / 7008 资源超限 / 7009 处理超时 / 7010 写出失败 / 7011 平台不支持 / 7012 处理失败。

## 会话口径

- 句柄是**底座进程内**整数，进程重启即失效；一个句柄对应一个浏览器进程加一个标签。
- 同时最多 8 个会话，超了报 7008；关闭会话必杀进程并清临时目录。
- 浏览器按 Chrome → Chromium → Edge 顺序探测，都没有报 7011，不假装能用。
- 调试端口由 `--remote-debugging-port=0` 动态分配，不占固定端口。

## 典型用法

先 7001 拿句柄，再 7002 导航，7003 读文本/元素，7004 填值并点击，7005 截图，最后 7006 关闭。导航与指令都有超时上限，不会无限等。
