# 浏览器支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 6 个接口。

---

## 7001 · 创建会话

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 7001,
 "命名值": {
  "临时根目录": ""
 }
}
```

**这个接口干什么**

起一个无头浏览器并开一个新标签，返回**整数会话句柄（纯值，不套 JSON）**。临时根目录传空串则落系统临时目录，传值必须是绝对路径。会话生命周期归底座，会话上限按可用内存动态计算。首次启动约 1 秒，之后每次约 0.3 秒。

**参数**

- 临时根目录 · 文本 · 必填 — 浏览器用户数据目录的候选根；空串落到系统临时目录，非绝对路径报参数不合法

**返回**

返回类型：文本。

返回内容：返回**整数会话句柄（纯值，不套 JSON）**

## 7002 · 导航

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 7002,
 "命名值": {
  "会话句柄": "",
  "地址": ""
 }
}
```

**这个接口干什么**

在会话里打开 http/https/file 网址，等 document.readyState 到 complete（最多 20 秒），返回地址、标题和加载状态。不支持 javascript:/data: 等协议。约 0.3–2 秒。

**参数**

- 会话句柄 · 文本 · 必填 — 创建会话返回的整数句柄，按文本传
- 地址 · 文本 · 必填 — http/https/file 开头的网址

**返回**

返回类型：文本。

返回内容：返回地址、标题和加载状态

## 7003 · 读页面

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 7003,
 "命名值": {
  "会话句柄": "",
  "读法": "",
  "选择器": ""
 }
}
```

**这个接口干什么**

读法四选一：文本=body.innerText；html=文档 outerHTML；标题地址=只取标题和当前地址；元素=按 CSS 选择器取文本、标签名、属性表、是否可见。

**参数**

- 会话句柄 · 文本 · 必填 — 整数句柄
- 读法 · 文本 · 必填 — 文本 / html / 标题地址 / 元素
- 选择器 · 文本 · 必填 — 读法为 元素 时必填的 CSS 选择器，其他读法传空串

**返回**

返回类型：文本。

## 7004 · 操作元素

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 7004,
 "命名值": {
  "会话句柄": "",
  "选择器": "",
  "动作": "",
  "值": ""
 }
}
```

**这个接口干什么**

动作四选一：点击（先 focus 再 click）；填值（写 value 并派发 input+change 事件）；悬停（派发 mouseover）；滚入（scrollIntoView 居中）。元素不存在报元素未找到，不做屏幕坐标模拟。

**参数**

- 会话句柄 · 文本 · 必填 — 整数句柄
- 选择器 · 文本 · 必填 — CSS 选择器
- 动作 · 文本 · 必填 — 点击 / 填值 / 悬停 / 滚入
- 值 · 文本 · 必填 — 填值时的文本，其他动作传空串

**返回**

返回类型：文本。

## 7005 · 截图

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 7005,
 "命名值": {
  "会话句柄": "",
  "输出路径": ""
 }
}
```

**这个接口干什么**

整页截图为 PNG 落盘，返回句柄与字节数；输出路径必须是绝对路径。约 0.2 秒。

**参数**

- 会话句柄 · 文本 · 必填 — 整数句柄
- 输出路径 · 文本 · 必填 — PNG 落盘绝对路径

**返回**

返回类型：文本。

返回内容：返回句柄与字节数

---

## 7006 · 关闭会话

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 7006,
 "命名值": {
  "会话句柄": ""
 }
}
```

**这个接口干什么**

杀掉该会话的浏览器进程并清临时目录，句柄随即失效；对已关闭句柄再关闭报会话不存在。

**参数**

- 会话句柄 · 文本 · 必填 — 整数句柄

**返回**

返回类型：文本。

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
