# 模板渲染支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 3 个接口。

---

## 4901 · 渲染JSON上下文

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4901,
 "命名值": {
  "模板文本": "",
  "上下文JSON文本": ""
 }
}
```

**这个接口干什么**

MiniJinja简单变量插值，仅允许变量名及点分路径，不允许控制语句、过滤器或算术表达式；上下文明确为JSON对象文本，不加载文件、不注册外部函数；缺变量报错，燃料100000，输入输出65536字节，先有界写入，不先展开巨大输出；非HTML自动转义引擎。

**参数**

- 模板文本 · 文本 · 必填
- 上下文JSON文本 · 文本 · 必填

**返回**

返回类型：文本。

## 4903 · 渲染网页页面

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 4903,
 "命名值": {
  "模板文本": "",
  "上下文JSON文本": ""
 }
}
```

**这个接口干什么**

按页面定义渲染完整HTML：允许循环、条件与过滤器，变量名可用中文（内部翻译为ASCII标识符后再渲染），输出按HTML自动转义；上下文为JSON对象文本；不加载文件、不注册外部函数；缺变量报错，燃料100000，输入输出65536字节，先有界写入，不先展开巨大输出。 ★ 边界（2026-11-02 裁决）：结构化界面一律走 4928「渲染组件树」；本能力只保留「整页模板字符串替换」这一窄用途（模板里手写 HTML 骨架、本能力只做变量/循环/条件替换），不得再往上叠加界面语义（容器/组件/状态/外观）。

**参数**

- 模板文本 · 文本 · 必填
- 上下文JSON文本 · 文本 · 必填

**返回**

返回类型：文本。

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
