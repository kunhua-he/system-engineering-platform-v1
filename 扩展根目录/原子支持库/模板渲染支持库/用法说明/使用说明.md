# 模板渲染支持库

MiniJinja简单变量插值，仅允许变量名及点分路径，不允许控制语句、过滤器或算术表达式；上下文明确为JSON对象文本，不加载文件、不注册外部函数；缺变量报错，燃料100000，输入输出65536字节，先有界写入，不先展开巨大输出；非HTML自动转义引擎。

- 4901 渲染JSON上下文：模板文本、上下文JSON文本 → 类型标签4。
- 4902 提取变量名：模板文本 → 类型标签100。
- 4903 渲染网页页面：模板文本、上下文JSON文本 → 类型标签4（HTML文本）。允许 `{% for %}` 循环、`{% if %}` 条件与过滤器；模板变量名与上下文键名可直接写中文，实现内部统一翻译为 ASCII 标识符后再交给模板引擎；输出按 HTML 自动转义（`{{ 值 }}` 会转义 `<` `>` `&` 等，需原样输出时用 `{{ 值 | safe }}`）；缺变量仍报错，不静默填空。典型用途：V4 页面定义渲染，一个页面一次调用。

调用经唯一HTTP能力入口；必须与本包声明的参数行序一致。纯CPU或网络I/O同步执行，典型4KiB输入估计微秒至毫秒（未实测），网络延迟另计；不承诺GPU加速。资源超限拒绝，不截断成成功。
