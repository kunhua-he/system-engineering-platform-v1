# 代码解析支持库 使用说明

六条原子能力，服务 V3 代码解析消费方（HTML/JS/PHP/Python/通用五组解析器与内容包、知识库链）。

## 能力

| 编号 | 名称 | 入参（顺序） | 返回 |
|---|---|---|---|
| 6305 | 解码文本 | 原始字节(5)、编码名(4) | `{文本,编码}` |
| 6306 | 载入切块规则 | 规则文件路径(4)、强制重载(1) | 规则JSON文本 |
| 6307 | 重载切块规则 | 规则文件路径(4) | 规则JSON文本 |
| 6308 | 按规则切块 | 内容(4)、文件格式(4)、规则文本(4) | `{块列表,单元数,格式化}` |
| 6309 | 解析代码字节 | 原始字节(5)、文件格式(4)、编码名(4) | `{格式化,编码,块列表,资源列表,单元数}` |
| 6310 | 解析代码文件 | 文件路径(4)、扩展名(4)、编码名(4) | 同 6309 |

## 边界

- 单次输入上限 1048576 字节（与消费方规则 max_bytes 同口径），超限报 6323。
- 解码按显式 WHATWG 编码名；BOM 存在时以 BOM 为准并如实回报实际编码；不可解码报 6322，不静默替换。
- 切块规则 JSON：`切分模式` ∈ regex / python_ast / html；regex 与 python_ast 需 `单元模式表`（正则，逐条可编译），html 单元模式表可空。
- 块类型：代码块（单元切块）、标题块（html 标签行）、文本块（其余）；`块列表[].文本` 按序拼接（空行分隔）可还原原文。
- 资源列表恒为空表，占位给消费方；行起始/行结束为 1 起闭区间。
- 支持格式（6309/6310 内置规则）：html htm js ts jsx tsx php py java go c cpp cs rb rs sh sql。
- 文件类能力只读；路径必须绝对且为普通文件。

## 真实调用例

```bash
curl -fsS -H 'Content-Type: application/json' "$V1_URL/接口/调用" -d '{"编号":6309,"值":[{"类型标签":5,"值":"<base64字节槽>"},{"类型标签":4,"值":"py"},{"类型标签":4,"值":"utf-8"}]}'
```

## 错误码

6321 解析参数不合法 · 6322 解析内容不合法 · 6323 解析资源受限 · 6324 解析规则不可读（可自愈：重读）。
