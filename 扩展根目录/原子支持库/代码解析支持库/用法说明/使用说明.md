# 代码解析支持库 API

**请求地址**（全部接口共用这一个，靠请求体里的 `编号` 选能力）

```http
POST http://127.0.0.1:43110/接口/调用
Content-Type: application/json
```

请求体固定两层：`编号` 选接口，`命名值` 放该接口的参数。

**返回信封**（全部接口统一；信封外层另带 `耗时微秒` 与 `契约身份`）

```json
{"成功": true,  "值": …}
{"成功": false, "错误": {"码": 2506, "名称": "资源受限", "可重试": true}}
```

共 6 个接口。

---

## 6305 · 解码文本

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6305,
 "命名值": {
  "原始字节": "",
  "编码名": ""
 }
}
```

**这个接口干什么**

按显式编码把字节解成文本：BOM存在时以BOM为准并如实回报实际编码；不允许静默替换，解不了报6322；输入至1048576字节。

**参数**

- 原始字节 · 字节集 · 必填 — 待解码字节；编码由 编码名 显式给出
- 编码名 · 文本 · 必填 — WHATWG编码名，如UTF-8、GBK、UTF-16LE；BOM存在时以BOM为准

**返回**

返回类型：文本。

## 6306 · 载入切块规则

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6306,
 "命名值": {
  "规则文件路径": "",
  "强制重载": 0
 }
}
```

**这个接口干什么**

读切块规则JSON文件并校验后返回规则对象文本；同路径缓存命中且文件未变直接返回；强制重载非0强制重读；失败不覆盖已有缓存。

**参数**

- 规则文件路径 · 文本 · 必填 — 切块规则JSON的绝对路径
- 强制重载 · 整数 · 必填 — 非0时忽略缓存强制重读文件

**返回**

返回类型：文本。

返回内容：返回规则对象文本

**请求参数模板**（把值改成你的就能直接发）

 "编号": 6307,

- 规则文件路径 · 文本 · 必填 — 切块规则JSON的绝对路径；总是重读文件

**返回**

返回类型：文本。

返回内容：返回

## 6308 · 按规则切块

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6308,
 "命名值": {
  "内容": "",
  "文件格式": "",
  "规则文本": ""
 }
}
```

**这个接口干什么**

按规则JSON把源码文本切块：切分模式 regex/python_ast 按单元模式行锚定切块（注释与字符串区间不切），html 按标签行与空行分块；返回 块列表（块类型/文本/行起始/行结束）、单元数、格式化；非空内容至少回一块，不静默丢内容。

**参数**

- 内容 · 文本 · 必填 — 源码全文；UTF-8文本
- 文件格式 · 文本 · 必填 — 扩展名（可带点、大小写不敏感），如 py、html
- 规则文本 · 文本 · 必填 — 切块规则JSON对象文本；须含 切分模式 与该模式的必备字段

**返回**

返回类型：文本。

返回内容：返回 块列表（块类型/文本/行起始/行结束）、单元数、格式化

## 6309 · 解析代码字节

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6309,
 "命名值": {
  "原始字节": "",
  "文件格式": "",
  "编码名": ""
 }
}
```

**这个接口干什么**

解码字节后按内置规则切块：返回 格式化/编码/块列表/资源列表（恒空表占位）；文件格式不在支持清单（html htm js ts jsx tsx php py java go c cpp cs rb rs sh sql）报6321；输入至1048576字节。

**参数**

- 原始字节 · 字节集 · 必填 — 源码原始字节
- 文件格式 · 文本 · 必填 — 扩展名（可带点、大小写不敏感）
- 编码名 · 文本 · 必填 — WHATWG编码名；BOM存在时以BOM为准

**返回**

返回类型：文本。

返回内容：返回 格式化/编码/块列表/资源列表（恒空表占位）

## 6310 · 解析代码文件

**请求参数模板**（把值改成你的就能直接发）

```json
{
 "编号": 6310,
 "命名值": {
  "文件路径": "",
  "扩展名": "",
  "编码名": ""
 }
}
```

**这个接口干什么**

只读读取源码文件后按内置规则切块；文件至1048576字节；返回与 解析代码字节 同构；路径不存在或不是普通文件报6324。

**参数**

- 文件路径 · 文本 · 必填 — 源码文件绝对路径；只读
- 扩展名 · 文本 · 必填 — 扩展名（可带点、大小写不敏感）；与路径后缀不一致时以本参为准
- 编码名 · 文本 · 必填 — WHATWG编码名；BOM存在时以BOM为准

**返回**

返回类型：文本。

返回内容：返回与 解析代码字节 同构

---

## 公共约束

- 参数必须全传：没有真默认值的一个都不能省，漏了返回 400 缺参数「X」
- 复合参数（列表/对象）要逐层带 {"类型标签": N, "值": …} 标签，标量给裸值
- 句柄类资源有上限，超出返回 2506 资源受限
- 全部接口共用同一个地址，靠 `编号` 分流，没有第二个入口
- 任务与句柄只在扩展实例内有效，不承诺跨重启
