## 一 定位

| `前端呈现/网页应用/` | **网页版编译器** | 无构建步骤的原生 ES 模块（HTML + CSS + JS），手写 CSS |
| `前端呈现/桌面应用/` | 同一个网页应用 + 一个 WKWebView 壳 | 一个 Swift 文件 + 一个 shell 启动脚本，**不含任何 UI** |

## 二 怎么起

**形态一：接口面同源托管（设计里的形态，已实现）** —— `接口面形状.md` §五 定案：静态件由接口面进程托管、同源。
实测 `GET /` 回 `200`（落点 `对外接口面/调用接口面/src/静态件.rs`；静态根 `前端呈现/网页应用`，仓内别处一律 `404`）。
**这是首选形态**：同源 ⇒ 无 CORS、无第二个端口，也不违判据 ⑪「对外监听恰好 1 处」。

**形态二：起一个静态服务（只验页面本身）**

```sh
cd 前端呈现/网页应用 && python3 -m http.server 8080 --bind 127.0.0.1
```

页面能加载，但 `fetch("/接口")` 会打到静态服务上、被当文件找、回 404（POST 回 501）。
页面把这段原文原样摆出来并说明原因，标题条「连接状态」写「网关连不上（HTTP 404）」——**不是崩，是如实报**。

**形态三：仓外同源反代（取证用，住 `/tmp`，不进仓）** —— 路径以 `/接口` 开头转给真网关，其余从仓根静态托管。
留作接口面不可用时的取证手段。

**桌面壳**：`sh 前端呈现/桌面应用/启动.sh`（从 `契约声明/常量表.json` 现读端口；`swift 壳.swift <URL>` 解释执行）。

## 三 三条硬约束（违反了就是返工）

### 1 零业务逻辑 —— 不许解析契约、不许生成代码、不许做校验

`接口面形状.md` §五 第 1 条。落成四条做法：**不看键名**（`呈现.js` 只按值的类型摆）· **成功失败也按值的类型扫** ·
**判定在后端**（敲了不合法的东西原样发出去，由后端回 400）· **唯一的「编码」是 `JSON.stringify`**（把程序文本编码成 JSON 字面量）。

**自检**：`sh 前端呈现/网页应用/自检.sh`，**脚本一字未改**，按 `判据的可信性.md` 第五节成对做
（违规词命中 0 + 反向样本必须报红 + 正向样本必须通过）。

> **一个必须知道的副作用**：违规词里有 `验证`。所以本目录源码里**不许出现 `测试验证`** ——
> 案例区的仓内相对路径只写在本页与报告里，不写进前端源码。口径：违规词只该禁「**声称**做了验证」
> 这个动作，不该禁路径字符串 —— **尚未施工**，施工前这条副作用还在。

### 2 同源相对路径 —— 端口不许写死

端点只写路径、不写主机与端口。浏览器会把非 ASCII 路径编码成 `/%E6%8E%A5%E5%8F%A3`，接口面已做百分号解码。

**实测撞到的一个真问题**：模块文件名不许与端点前缀同前缀 —— 按前缀分流的同源反代会把 `/接口.js`
当接口请求转给接口面、回 404，页面模块全挂。所以 fetch 封装叫 `取接口.js`。

### 3 无构建步骤 + 视觉落在 CSS 上

`<script type="module">` 直接引 `.js`。不许 `package.json` / `node_modules` / CDN 外链 / UI 组件库；
不许用 JS 堆 DOM 骨架来堆视觉。**每个源文件 ≤ 400 行**（自检第六节数这件事）。

### 4.3 字号与行距

**全站 `宋体 9pt`**（CSS 写 `9pt`，计算样式读回 `12px`）。依据两条，互相印证：

- 反解：对话框字体实测 3 种，其中 **`宋体 9pt` 占 50 个**（`界面实测.md` §三）。
- 截图：菜单栏 / 编辑区 / 面板的**汉字步距实测 12 像素**（一个全角汉字占 12 像素 ⇒ 12px 字号 ⇒ 9pt）；
  菜单栏文字墨迹高 11 像素、编辑区 12 像素。

**行距也是量的**：编辑区文字行起点差 **21 像素**（本页 `line-height: 21px`）；左栏 14 像素；底部区 12 像素。

**平台实际选中的字面**（CDP `CSS.getPlatformFontsForNode`，不是看 CSS 源码）：macOS 上 `宋体` 无此字面，
落到 **`Songti SC`**（`STSongti-SC-Regular`）—— 菜单栏助记字、对话框按钮、编辑区三处实测一致。
族链 `宋体 → SimSun → Songti SC → STSong → MS Song → serif` 只在 `样式.css` 里写一份。

### 4.5 对话框：56 个里进 18 个

**进前端的判据**（两条都要满足）：① 有**可达命令** —— 能从菜单 127 的某个命令 id 走到；② 属于**工具选项 / 查找替换 / 编译设置 / 调试 / 编辑跳转**这几类（主界面主线）。
逐个对照写在 `对话框表.js` 每条记录的 `依据` 字段里，页面上的读数行也会摆出来。

合计 **18 个 / 281 个控件**。18 个的 id / 标题 / 控件数 / 可达命令，以及 **38 个不进的**按类理由与逐条 id，都写在 `对话框表.js` 每条记录的 `依据` 字段里（页面上的读数行也摆出来）。**进前端之后**只摆样子、**不接动作**（是「资源里长什么样」的读数，不是能用的对话框）；坐标单位是**对话框单位**，按 **1 单位 = 1 像素**摆，**不做像素折换**（见 §六 第 1 条）。

## 六 缺口与定不下来的（如实登记，不假装覆盖了）

1. **对话框单位按 1:1 摆（已裁 · 别再去找折换系数）** —— 资源的 x/y/cx/cy 是**对话框单位**（DLU），折换要 Windows 下 `宋体 9pt` 的字体度量，本平台**量不到**。**裁决**：按 **1 单位 = 1 像素**摆（口径「单位 1:1，像素尺寸非 1:1」）；那个系数**本仓不存在**，后人**不必再找**。

2. **案例库面板已接 §七 端点** —— `GET /接口/案例`（列案例 · 每项带最新回执）与 `POST /接口/案例/跑` 已在左栏「程序」格接上，错误码 `9002` / `9003` 如实显示。案例根是**相对网关「工具根」**的 `测试验证/案例`；口径见 `构建装配/上线切换/形状.md` §四「部署事实注入」。**注意**：制品里那份 `网关` 是旧二进制，**重建制品前装载它仍读不到案例库**。

3. **`<textarea>` 会把 CRLF 归一成 LF** —— 浏览器行为，与 `程序文本格式.md`「写出恒 `\n`；读入同时认 CRLF 与 LF」方向一致，不算缺陷；但**编辑器不保证逐字节搬运 CRLF**。

4. **`1105` 用文本槽调用回了个非零槽标志** —— `成功:true` 而 `值:[{类型标签:4294967295,值:1135}]`。调用侧与实现侧的槽语义对不上，**前端只摆不判**，登记待裁。

5. **「载入语料」这一路已撤，正路已通** —— 原 6 条语料入口两条都站不住（取不到 + 破硬边界），**已撤**。**正路**是 `POST /接口/程序文本`（读 / 写已在左栏「程序」格接上）：后端按**调用方自带的路径**真读 / 真写，失败逐种各一码 `9008`–`9012`。

6. **控制台 0 条这条判据不在 `自检.sh` 里** —— 本页的控制台读数是**另用 CDP 量的**，没进判据集。缺什么：把控制台读数并进自检，或者别在口径里声称它查。

7. **前端接线两条已裁（2026-09-27，别再翻）**：① **不许读 `案例标识` 键做「点案例行即跑」**（前端零业务逻辑、不看键名；跑案例的标识由输入框给）；② **9 个旁路端点路径**照抄冻结件（`取接口.js` 里的路径常量），**不改成**从 `GET /接口` 实时取（与既有 4 个冻结端点写法保持同一种）。

## 七 与既有件矛盾的事实（原样报出，不替哪一侧圆）

1. **文字与控件取自反解，分栏与配色取自截图** —— `界面实测.md` §七 §十 的结论（资源里没有窗体定义、没有配色表）**对资源反解仍成立**，但**运行态截图里有这两样**。
