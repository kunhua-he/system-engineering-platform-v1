## 二 怎么起

**形态一：接口面同源托管（设计里的形态）** —— `接口面形状.md` §五 说静态件由接口面进程托管、同源。
**实测还没实现**：接口面只实现四个端点，请求 `/` 回 `404`。把 `前端呈现/网页应用/` 挂在接口面根上即可。

**形态二：起一个静态服务（只验页面本身）**

```sh
cd 前端呈现/网页应用 && python3 -m http.server 8080 --bind 127.0.0.1
```

页面能加载，但 `fetch("/接口")` 会打到静态服务上、被当文件找、回 404（POST 回 501）。
页面把这段原文原样摆出来并说明原因，标题条「连接状态」写「网关连不上（HTTP 404）」——**不是崩，是如实报**。

**形态三：仓外同源反代（取证用，住 `/tmp`，不进仓）** —— 路径以 `/接口` 开头转给真网关，其余从仓根静态托管。

**桌面壳**：`sh 前端呈现/桌面应用/启动.sh`（从 `契约声明/常量表.json` 现读端口；`swift 壳.swift <URL>` 解释执行）。

## 三 三条硬约束（违反了就是返工）

### 1 零业务逻辑 —— 不许解析契约、不许生成代码、不许做校验

`接口面形状.md` §五 第 1 条。落成四条做法：**不看键名**（`呈现.js` 只按值的类型摆）· **成功失败也按值的类型扫** ·
**判定在后端**（敲了不合法的东西原样发出去，由后端回 400）· **唯一的「编码」是 `JSON.stringify`**（把程序文本编码成 JSON 字面量）。

**自检**：`sh 前端呈现/网页应用/自检.sh`，**脚本一字未改**，按 `判据的可信性.md` 第五节成对做
（违规词命中 0 + 反向样本必须报红 + 正向样本必须通过）。

> **一个必须知道的副作用**：违规词里有 `验证`。所以本目录源码里**不许出现 `测试验证`** ——
> 案例区的仓内相对路径只写在本页与报告里，不写进前端源码。`项目文档/未完成事项.md` 第 161 条已裁
> 「违规词只该禁『声称做了验证』这个动作，不该禁路径字符串」，**尚未施工**；施工前这条副作用还在。

### 2 同源相对路径 —— 端口不许写死

四个端点只写路径、不写主机与端口。浏览器会把非 ASCII 路径编码成 `/%E6%8E%A5%E5%8F%A3`，接口面已做百分号解码。

**实测撞到的一个真问题**：模块文件名不许与端点前缀同前缀。最初这个 fetch 封装叫 `接口.js`，
浏览器请求的是 `/接口.js`；按前缀分流的同源反代把它当接口请求转给接口面、回 404，页面模块全挂。
已改名 `取接口.js`。

### 3 无构建步骤 + 视觉落在 CSS 上

`<script type="module">` 直接引 `.js`。不许 `package.json` / `node_modules` / CDN 外链 / UI 组件库；
不许用 JS 堆 DOM 骨架来堆视觉。**每个源文件 ≤ 400 行**（自检第六节数这件事）。

## 五 各块接什么（现在的真实读数）

| 块 | 接什么 | 现在真实回什么 |
|---|---|---|
| **编辑器** | 无端点。纯文本区 + 从语料只读载入 | 载入示例得真语料字符数；`<textarea>` 会把 CRLF 归一成 LF（见 §六 第 5 条） |
| **编译** | 逐级 `POST /接口/调用`：`1101 → 1102 → 1103 → 1106`，再 `1107` | 四步**全失败**，一律 `HTTP 200` + `成功:false` + `码 1 提供者未载入`（保留项） |
| **运行/结果** | **不接** | 照实写「编译还没实现，所以运行也没有」，**没有假按钮** |
| **案例库** | **没有端点可接** | 如实显示缺口 + 一个通用同源只读口 |
| **支持库/能力** | `GET /接口` · `GET /接口/能力/<编号>` | `200`；能力清单 1201 条；契约带参数表行序 · 类型标签 · 可抛错误码 |
| **导出目标** | **没有导出端点** | 五种出口的落点与现状照实摆 + 一个真调探针（调编译链） |
| **对话框布局** | **不接** | 18 个布局逐像素摆出来 + 每个的可达命令与依据 |
| **调试** | `POST /接口/调用` · `POST /接口/声明` | 调用 `200`；声明 `200` + `成功:false` + `校验[…]` |
| **菜单栏** | 编译族 12 个命令 id 走真编译链，其余写「未接线」 | 见下 |

**菜单栏为什么不是「每个项都能用」**：命令的实现不在资源里 —— 资源里只有 id 与文字，
没有 id → 命令 的映射表（`界面实测.md` §八 第 4 条：那张表在 `.text` 里）。
所以只有**平台真有端点**的那一族接线：**编译族 12 个 id** 通向同一条编译动作，走冻结的编译链；
其余 **169 项**点了写一条真实读数：「命令 `0x…` · 快捷键 … · 未接线 —— 死在这一步：本前端只有 4 个冻结端点」。
资源里带 `MF_GRAYED` 的那 1 项（`最近文件`）照它的做派**点不动**（`aria-disabled`），不是「点了没反应」。

## 六 缺口与定不下来的（如实登记，不假装覆盖了）

1. **对话框单位的像素折换系数给不出** —— 资源的 x/y/cx/cy 是**对话框单位**（DLU）。DLU → 像素要 Windows 下
   `宋体 9pt` 的字体度量（`tmAveCharWidth` / `tmHeight`），本平台量不到（不运行 `.exe`，也没有 Windows）。
   所以本页按 **1 单位 = 1 像素**摆：**单位 1:1，像素尺寸非 1:1**。缺什么才能定：Windows 下那套字体度量，或一张已知尺寸的对照截图。

2. **截图顶部那条带是标题条还是菜单栏，像素侧定不了** —— 见 §四.4 末尾。缺什么：人眼确认一眼。

3. **接口面不托管静态文件** —— 设计里写「静态文件由接口面进程托管、同源」，实测请求 `/` 回 `404`。
   网页应用因此**没有同源的家**。**补法在 `对外接口面/调用接口面/`，不在前端。**

4. **案例库面板接不上** —— 冻结的端点只有四个，**没有读案例目录的路、也没有写回执的路**。
   缺什么：一个读案例的端点 + 一个写回执的端点，且两者形状要先冻结。

5. **`<textarea>` 会把 CRLF 归一成 LF** —— 浏览器行为，不是本页写的代码。与 `程序文本格式.md`
   「写出恒 `\n`；读入同时认 CRLF 与 LF」方向一致，不算缺陷；但**编辑器不保证逐字节搬运 CRLF**。

6. **`GET /接口` 的「端口来源」指向一个不存在的位置** —— 那句话写 `契约声明/平台声明.json`，
   实测该文件**没有**该字段，端口唯一来源是 `契约声明/常量表.json`。接口面逐字照抄冻结件，**原样报出**。

7. **`1105` 用文本槽调用回了个非零槽标志** —— `成功:true` 而 `值:[{类型标签:4294967295,值:1135}]`。
   调用侧与实现侧的槽语义对不上，**前端只摆不判**，登记待裁。

8. **前端这条判据还没进 `构建装配/一键验证/`** —— 前端没有构建步骤、不需要生成物，
   但「前端 0 处解析/生成/校验」目前只在 `自检.sh` 里跑。缺什么：把它并进一键验证的判据集。

9. **「载入示例」的清单是本页写死的** —— 浏览器没法列目录（列目录要么靠端点、要么靠读服务端目录页，
   两条都不在冻结的四个端点里）。缺什么：一个「列语料」的端点。

10. **控制台 0 条这条判据不在 `自检.sh` 里** —— 实测 `自检.sh` 不查控制台输出
    （`项目文档/未完成事项.md` 第 163 条）。本页的控制台读数是**另用 CDP 量的**，没进判据集。
    缺什么：把控制台读数并进自检，或者别在口径里声称它查。
