## 二 怎么起

**形态一：接口面同源托管（设计里的形态，已实现）** —— `接口面形状.md` §五 定案：静态件由接口面进程托管、同源。
实测 `GET /` 回 `200`（落点 `对外接口面/调用接口面/src/静态件.rs`；静态根 `前端呈现/网页应用`，仓内别处一律 `404`）。
**这是首选形态**：同源 ⇒ 无 CORS、无第二个端口，也不违判据 ⑪「对外监听恰好 1 处」。

**形态二：起一个静态服务（只验页面本身）**

```sh
cd 前端呈现/网页应用 && python3 -m http.server 8080 --bind 127.0.0.1
```

页面能加载，但 `fetch("/接口")` 会打到静态服务上、被当文件找、回 404（POST 回 501）。
页面把这段原文原样摆出来并说明原因，标题条「连接状态」写「网关连不上（HTTP 404）」——**不是崩，是如实报**。

**形态三：仓外同源反代（取证用，住 `/tmp`，不进仓）** —— 路径以 `/接口` 开头转给真网关，其余从仓根静态托管。
留作接口面不可用时的取证手段。

**桌面壳**：`sh 前端呈现/桌面应用/启动.sh`（从 `契约声明/常量表.json` 现读端口；`swift 壳.swift <URL>` 解释执行）。

## 三 三条硬约束（违反了就是返工）

### 1 零业务逻辑 —— 不许解析契约、不许生成代码、不许做校验

`接口面形状.md` §五 第 1 条。落成四条做法：**不看键名**（`呈现.js` 只按值的类型摆）· **成功失败也按值的类型扫** ·
**判定在后端**（敲了不合法的东西原样发出去，由后端回 400）· **唯一的「编码」是 `JSON.stringify`**（把程序文本编码成 JSON 字面量）。

**自检**：`sh 前端呈现/网页应用/自检.sh`，**脚本一字未改**，按 `判据的可信性.md` 第五节成对做
（违规词命中 0 + 反向样本必须报红 + 正向样本必须通过）。

> **一个必须知道的副作用**：违规词里有 `验证`。所以本目录源码里**不许出现 `测试验证`** ——
> 案例区的仓内相对路径只写在本页与报告里，不写进前端源码。`项目文档/未完成事项.md` 第 161 条已裁
> 「违规词只该禁『声称做了验证』这个动作，不该禁路径字符串」，**尚未施工**；施工前这条副作用还在。

### 2 同源相对路径 —— 端口不许写死

端点只写路径、不写主机与端口。浏览器会把非 ASCII 路径编码成 `/%E6%8E%A5%E5%8F%A3`，接口面已做百分号解码。

**实测撞到的一个真问题**：模块文件名不许与端点前缀同前缀 —— 按前缀分流的同源反代会把 `/接口.js`
当接口请求转给接口面、回 404，页面模块全挂。所以 fetch 封装叫 `取接口.js`。

### 3 无构建步骤 + 视觉落在 CSS 上

`<script type="module">` 直接引 `.js`。不许 `package.json` / `node_modules` / CDN 外链 / UI 组件库；
不许用 JS 堆 DOM 骨架来堆视觉。**每个源文件 ≤ 400 行**（自检第六节数这件事）。

### 4.3 字号与行距

**全站 `宋体 9pt`**（CSS 写 `9pt`，计算样式读回 `12px`）。依据两条，互相印证：

## 五 各块接什么

**本表只写「接什么」**（落点，不漂）；「现在回什么」是会漂的读数 —— 由页面上的探针与 CDP 实测实时给，

没有 id → 命令 的映射表（`界面实测.md` §八 第 4 条：那张表在 `.text` 里）。
所以只有**平台真有端点**的那一族接线：**编译族 12 个 id** 通向同一条编译动作，走冻结的编译链；
其余 **169 项**点了**问后端**：`POST /接口/菜单命令`（§七 旁路端点，体 `{"编号":"0x…"}`），
把后端的**结构化回执**摆到「提示」栏 —— 此刻后端一律回 `9001 端点未实现`，本页**如实显示**，
不自己编一句「未接线」。菜单读数（最底那条状态条）也照真读数写「已问后端 · HTTP 几 · 成功/失败」。

## 六 缺口与定不下来的（如实登记，不假装覆盖了）

1. **对话框单位的像素折换系数给不出** —— 资源的 x/y/cx/cy 是**对话框单位**（DLU）。DLU → 像素要 Windows 下
   `宋体 9pt` 的字体度量（`tmAveCharWidth` / `tmHeight`），本平台量不到（不运行 `.exe`，也没有 Windows）。
   所以本页按 **1 单位 = 1 像素**摆：**单位 1:1，像素尺寸非 1:1**。缺什么才能定：Windows 下那套字体度量，或一张已知尺寸的对照截图。

2. **截图顶部那条带是标题条还是菜单栏，像素侧定不了** —— 见 §四.4 末尾。缺什么：人眼确认一眼。

3. **案例库面板已接 §七 端点（本腿收口）** —— `GET /接口/案例`（列案例 · 每项带最新回执）与
   `POST /接口/案例/跑`（跑案例 · 带回执）已在左栏「程序」格接上，回执与错误码 `9002` / `9003` 如实显示。
   案例根是**相对网关「工具根」**的 `测试验证/案例`。**网关从制品目录起时该目录不存在 ⇒ 恒回 `9002`**
   —— 这一条已由协调方修掉（2026-09-27）：`启动网关` 新增 `--工具根` 口，`上线切换.py::起实例` 按**仓根**
   注入 `--静态根` 与 `--工具根`（cwd 仍是制品目录，扩展那条路靠它）。实测：`GET /` = 200、
   `GET /接口/案例` = 成功（案例根 `测试验证/案例`）。口径见 `构建装配/上线切换/形状.md` §四「部署事实注入」。
   **注意**：制品里那份 `网关` 是旧二进制，**重建制品前装载它仍读不到案例库**。
   通用同源只读口保留在「程序」格的折叠块里（它读静态件，不是端点）。

4. **`<textarea>` 会把 CRLF 归一成 LF** —— 浏览器行为，不是本页写的代码。与 `程序文本格式.md`

## 七 与既有件矛盾的事实（原样报出，不替哪一侧圆）

1. **文字与控件取自反解，分栏与配色取自截图** —— `界面实测.md` §七 §十 的结论（资源里没有窗体定义、没有配色表 ⇒ 不能复刻）

   ⇒ 页面写的就是真路径。

   `扩展装载/扩展根声明.json` 的种类表，不是 §四 给的。两处需对齐。

4. **编译链各步的真实状态必须由探针给，不能从文档读** ——
   **前端只摆不判**：按页面上那条探针的真读数报「死在第几步」，**本页不复述码**。缺口本身见
   `项目文档/未完成事项.md` §一 语言那一条。

5. **`未完成事项.md` 第 162 条（窄视口主区被压成 1px）** ——
   客户区给了 240 像素下限、行高全固定，`1100×800` 与 `1426×755` 两档实测都压不下去。
