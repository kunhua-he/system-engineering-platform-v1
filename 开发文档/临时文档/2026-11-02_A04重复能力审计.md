## 逐组判定

### 组1 图像 6501 / 6502 —— 建议合并
`图像处理支持库/src/图像处理.rs`
- `识别格式实现`（6402 注释行，实为 6502）与 `分析图像实现`（6501）同走 `b64解码 → 解码字节 → dimensions`，`格式判定`/`模式名` 共用；
- 6502 输出 = 6501 输出的严格子集（少 `像素数`/`平均颜色`/`字节数`）。6502 无独立逻辑，是 6501 的结果裁剪。
- 判定：**6502 并入 6501**，保留 6501。零调用方，无破坏。
- 副作用提示：源码注释写 6401/6402、`静态声明.rs` 号段 6501–6599，注释与号段存在编号漂移（只读记录，不改）。

### 组2 解码 6305 / 4001 —— 方向相反，真重复在 6305 与 4002
- 4001 = 文本→字节（`encode`，含 UTF-16LE/BE 手工码元）；6305 = 字节→文本（`Encoding::decode`，BOM 优先并回报实际编码）。反向操作，**不构成别名**。
- 同向真重复：`编解码支持库/字符编解码/业务实现.rs` 的 4002 `解码字节` 用 `decode_without_bom_handling`、不回报编码；`代码解析支持库/文本解码.rs` 的 6305 用 `decode`、BOM 优先。同底座 `encoding_rs`，参数与回报口径不同。
- 6305 同时是代码解析库的内部步骤（`代码解析支持库/src/业务实现.rs::解码或失败` 直接调），属"内部步骤上提为能力"。
- 判定：**保留 4001**；**6305 并入 4002**（BOM 口径作为参数），不要并入 4001。

### 组3 过滤 6301 / 6302 / 5205 / 5206 —— 建议保留
- 6301 多重集对账（按行计次，BTreeMap 计数，特色是重复段落计数而非集合等值）、6302 时间窗行（`时间窗筛选.rs` + `时刻解析.rs`，闭区间 + 50000 截断）语义互异，无共用实现。
- 5205 与 5206 共用同一谓词 `单项命中`（`JSON数据支持库/src/业务实现.rs::单项命中`），但结果形态不同：5205 返回首个命中项文本（无命中空串）、5206 返回命中项组成的新数组。5205 可由 5206+取首项派生，但契约返回形态不同，合并会破坏 2 处测试样本。
- 判定：**四件全保留**；5205 记为"可派生但不必合并"。

### 组4 摘要四件 5204 / 5212 / 5213 / 5219 —— 建议保留
- 5204 提取摘要：返回复合值(103)，含 类型名称/成员数量/规范文本；是唯一被组合模块库装配的能力。
- 5212 展平结构条目：`展平条目递归`，与 5211 展平字典分属不同递归（条目列表 vs 扁平对象），非别名。
- 5213 规范化条目指纹：行拼装 + SHA-256，独立实现。
- 5219 压缩描述字段：委托 `响应塑形实现::执行压缩描述字段`，递归折叠指定字段空白，与 5204 的"规范文本"口径不同（不重排、不取类型）。
- 判定：**四件全保留**，无薄封装。

### 组5 业务混入 6801 / 6802 —— 保留能力，迁族
- 6801 查询人格上下文：构造只读 GET、RFC3339 转 UTC（`人格上下文.rs`）；6802 格式化可注入上下文：纯本地 JSON→Markdown，过滤争议/矛盾并保留证据边界。二者不互为别名、无共用解析。
- 真正的问题是**族归属**：两件业务语义能力挂在通用 `文本计算支持库`（与 6301/6302 同库，`静态声明.rs` 号段 6301–6302 + 6801–6802 挤在一个库）。
- 判定：**能力保留，建议迁出为独立库/独立号段**（如人格上下文支持库），不要在 6801/6802 之间合并。

### 组6 转换外露 6116 / 6117 / 6118 / 6119 —— 建议保留
- `办公文档支持库/src/格式转换.rs`：6117 与 6118 共享 `校验路径/校验格式/解析超时/跑转换/收产物/等待子进程`，差异只在命令行（`--headless --convert-to` vs `-convert -output`）与 6117 独有全局 `转换锁` + 临时 UserInstallation。不是互相别名。
- 6116 检查提供者走 `办公转换器()/文本转换器()`（与 6117/6118 同一个 `找转换器` 私有函数），是前置探测而非转换内部步骤：**6117/6118 不调用 6116**（各取各的程序路径）。保留为公共前置即可。
- 6119 检查页面结构读 pptx 页清单/关系（`页面结构.rs` 368 行），完全独立。
- 判定：**四件全保留**。

## 汇总

- 建议合并 2 件：6502 → 6501；6305 → 4002。
- 建议保留 16 件：6501、4001、6301、6302、5205、5206、5204、5212、5213、5219、6801、6802、6116、6117、6118、6119。
- 附一条非合并建议：6801/6802 迁出 `文本计算支持库`。
