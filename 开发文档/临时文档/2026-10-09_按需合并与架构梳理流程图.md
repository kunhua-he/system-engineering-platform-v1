# 完整闭环（临时）

## 闭环

```mermaid
flowchart TD
    A[异步子代理完成任务] --> B[登记到反馈表]
    B --> C[主会话验收汇报]
    C --> D[正常推进项目]
    C --> E[同时看反馈表]
    E --> F{情况属实?}
    F -- 否 --> G[主会话给判词：非问题/待核]
    F -- 是 --> H[放异步子代理维修]
    H --> C
    D --> I[子代理本地提交]
    I --> J[主会话合并到主线]
    J --> K[推远端]
```

## 五步

```text
1. 子代理完成任务 → 登记信息到反馈表
2. 主会话验收汇报 → 正常推进项目，同时看反馈表
3. 主会话直接查询，核实是否属实
4. 属实 → 直接放异步子代理维修
5. 正常/小任务：子代理提交本地 → 主会话合主线 → 推远端
```

## 边界

```text
反馈表：唯一入口；判词由主会话给，不让提交方自判
维修回来：仍从第 1 步登记反馈
合并与推远端：由主会话做
未完成：保留现场，不清理
已完成：立即清理任务过程记录，保留代码/Git/正式规则
```
