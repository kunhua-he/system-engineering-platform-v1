## 五、命名纪律（2026-10-06修正后）

**合格标准**（结构检查，不是词源检查）：
1. **动词可数** + 结构固定：
   - `动作 + 对象`（如：`读配置`、`写日志`）
   - `对象 + 说明`（如：`配置文件`、`日志路径`）
2. **语义自解释**：不依赖上下文能看懂

**禁止形状**（4类）：
1. 单汉字名（`件`、`止`、`主`）
2. 泛名（`数据`、`信息`、`项`）
3. 序数代称（`一条`、`两个`、`第三项`）
4. 西文单字母（`x`、`i`、`f`）

**例外机制**：
- 外部强加的名字（标准库、DOM属性、协议字段）登记到 `命名例外` 表
- 不受纪律约束，但必须登记说明来源

**实测数据**：
- 老项目5190条待处理名字，**0条能靠核心词纯组合表达** ⇒ 推翻"15核心词+组合复用"思路
- V1当前：7919条合格名（全部来源=新定义），证明新纪律可行

**参考词表**：
- 约20~30个常用动词存在 `命名字典` 表，作为**校验用参考**
- 不是生成用封闭词表（不限制只能用这些词）

## 十三、开发流程

### 新功能开发
1. 检查号段分配（是否需要新能力号）
2. 登记新名到信息核心（`信息核心.py 登记 <名>`）
3. 实现代码（遵循文件行数、模块依赖规范）
4. 跑门禁（`python3 构建装配/一键验证/闸0.py`）
5. 更新本文档（架构变更必须同步）

### 命名纪律
1. 起名时自查：动作+对象、语义自解释、无禁止形状
2. 登记到信息核心（`信息核心.py 登记 <名>`）
3. 门禁验证（闸1会检查命名纪律）

### 数据库变更
1. 修改 `信息核心.db` 后
2. 执行 `v1_task 功能=6 记账源件`（记录变更）

### 推送前检查
```bash
python3 构建装配/一键验证/闸0.py  # 门禁必须全绿
python3 开发工具/代码地图.py 建    # 重建索引
git status                          # 确认变更范围
```
